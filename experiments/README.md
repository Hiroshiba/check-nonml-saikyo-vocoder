# 調査・実験の記録

記録は `experiments/YYYY-MM-DD/テーマ名/` にまとめます。日付は日本時間（Asia/Tokyo）です。同日の同じ問いに対する調査・議論・実験を一つのグループとし、条件や実装を変えて再実行した結果は `results/run-001/`、`run-002/` のように分けます。

| ファイル・場所 | 内容 |
|---|---|
| `experiment.json` | 日付、テーマ、要約、状態、記録文書と実行結果の一覧。公開一覧の入力 |
| `README.md` | 今回の問い、結論、判断できないこと、次の検証 |
| `research.md` | 確認した出典、確認範囲、資料の主張と今回の解釈 |
| `reviews/` | 提案・5人の議論・批評・応答・採否判断 |
| `results/run-NNN/` | 1回分の結果HTML、測定JSON、検証記録 |

複数日にまたがる継続テーマも、作業した日ごとに新しいグループを作ります。同じテーマ名を使い、`README.md` から前回を参照します。日をまたいだ実行は開始日のグループに置き、開始・終了日時とタイムゾーンを実行記録に残します。過去の開始時刻が不明な場合は推定時刻を埋めず、その限界を明記します。

調査のみの段階では `runs: []` で登録できます。再実行で過去の結果を上書きしません。失敗した実験も状態・理由・結果を残しますが、不採用の方式の実装は追加しません。共通の測定仕様・運用手順は `docs/`、再利用する参考資料は `research/`、比較コードは `vocoderbench/` に置きます。

## 新しい記録を追加する

1. 日付・テーマのディレクトリを作り、初回グループの `experiment.json` を参考に各項目を記入します。`id` は `日付-テーマ名`、`date` は親ディレクトリと同じ日付、`topic` はテーマ名にします。`notes` にはグループ内の実在するMarkdownを指定します。
2. 品質比較はまずGit管理外の `runs/` で行います。例：`uv run --locked python -m vocoderbench.reference --output runs/references-120`。準備と固定コーパスは [既存方式比較](../docs/REFERENCES.md) に従います。コードの動作確認を目的とした小規模実行は行いません。
3. 記録する結果一式を新しい `results/run-NNN/` に移し、`runs` に `id`、`date`、`title`、`path`、`recorded_at` を追加します。未選定を含む当時のベース情報・比較相手は、各 `results.json` の値を保存します。後から現在のベースに置き換えません。
4. 公開時に `python scripts/build_site.py` で一覧ページを生成します。欠落した結果・壊れた内部リンクは公開処理の入力エラーになります。PRでの予行実行は行いません。
5. 結果HTMLとJSON、説明・レビューを同じPRに入れます。ベース採用時の実装・削除についてはユーザー指示に従います。

一覧ページとテーマページはビルド時に生成し、測定HTML自体はGit管理します。公開方法は [GitHub Pagesの運用](../docs/PUBLISHING.md) を参照してください。

## 一覧の日時と順序

同じ比較に付随する診断・制御確認は、`experiment.json` の `supplements` へ `id`・`title`・`path`（`results/ID`）を登録する。各補助記録には `results.json` を必須とし、HTMLがあれば併せて公開する。テーマページと本報告から辿れるようにし、比較一覧の独立したカードにはしない。主比較の固定集合・平均へ補助集合を混ぜない。公開ファイルと内部リンクの検査は主比較と同じく行う。

一覧は実行結果ごとに一枚表示し、日付の見出しでは区切りません。`runs[].recorded_at`（UTCオフセット付きISO 8601）を新しい順に並べ、各レポートに日本時間の記録日時を表示します。同じグループの再実行も個別に並びます。ファイル名、更新時刻、checkout時刻は順序の根拠にしません。

新しい記録では結果を保存した時点の日時を指定します。過去の3件は初回記録commitの作成日時を転記し、`recorded_at_source`に根拠を残しました。測定開始・終了時刻を推測して埋めたものではありません。過去の結果HTML・JSONは変更せず、一覧用のメタデータだけを追加しています。
