# 雑音の窓・重ね合わせ・乱数を5案で切り分ける

HNM v2の解析を共用し、雑音合成だけを5通りに変えた。正式比較は同じLibriSpeech 120録音・40話者。実験時のHNM v2とWORLD（Harvest）を比較相手とする。日本語12録音と人工信号の制御確認は別の補助測定で、正式120録音の平均に混ぜない。

## 結論

[比較表と音声](results/run-001/index.html)を公開し、Dを **HNM v3** として採用した。帯域・平均包絡・音量誤差と予測MOSの小幅改善を優先し、明瞭性・スペクトル誤差の小さな系統的悪化を許容した。予測MOSは2.568417→2.576760、eSTOIは0.867162→0.866579。品質優越の確証ではない。[採用判断](reviews/adoption.md)に全候補の得失と追加制御確認を残す。旧v2の本体を置き換え、保存形式は互換を保った。

## 今回の問い

前回、雑音の音色と時間包絡を分離したv2は全帯域の包絡誤差を減らしたが、ささやきの一部で明瞭性と予測MOSが下がった。局所帯域の誤差増加が合成乱数を変えても起きるか、その観測から雑音合成のどこを変えると得失が生じるかを調べた。

| 案 | 変更する部分 | 主な解釈上の注意 |
|---|---|---|
| A | 元のパワーを使って重ね合わせ窓を重み付け | 時間操作で短い雑音を落とす可能性を制御測定で確認 |
| B | 合成窓を長くする | 16 kHzで実際のFFT長は64 ms |
| C | 合成窓を短くする | 16 kHzで実際のFFT長は16 ms |
| D | DC・Nyquistの端点配分を台形積分に合わせる | v2の離散和が普遍的に誤りという意味ではない |
| E | 内部ビンの振幅を固定し位相を一様乱数にする | 端点はGaussian乱数。v2と同じ乱数キャリアではない |

ベースの実際のFFT長は16 kHzで32 ms。事前の[調査](research.md)、[5人の往復議論](reviews/discussion.md)、[判断条件](reviews/criteria.md)に沿って比較した。候補の実装は採否確定までGit外に置き、仮説・ソースhash・全測定値を保存する。未採用候補の完全な再生成にはGit外のコードが必要になる。

## 補助測定から分かったこと

- [ささやきの8 seed診断](results/whisper-run-001/index.html)：全帯域10 ms包絡誤差はv2で32/32改善した。一方、jvs066のeSTOI低下は8/8で続いたが、選んだ低域区間の悪化は3/8だけだった。その区間を明瞭性低下の原因とは特定できない。
- [時間・音量制御](reviews/control-findings.md)：Aは単一フレームの雑音を時間半分へ縮めたとき、8/8で出力が完全に消えた。無加工再合成の平均値だけでは採用できない具体的な制御不具合である。
- [日本語12録音](results/jvs-run-001/index.html)：Cはささやき4録音のMOS/eSTOIが低下し、DはMOSが上がった。各発声4話者の未校正予測であり、日本語全体の品質順位ではない。

## 再現条件と測定の由来

音響計算は方式ごと8 seed、MOS/eSTOIはseed 0。発話内でseedを平均してから発話を平均する。原音・ベース・5候補でMOS840件を対象とし、WORLDの120件は別実行として加える。

MOSのうち214件は過去のLinux測定から引用した。原音108件・v2 106件について、float32入力のSHA、長さ、サンプルレート、評価器の全来歴、mos.pyのSHAが一致することを照合した。これを新たなWindows再測定とは数えない。残る原音・ベースと5候補は今回のWindows実行で測った。事前条件からの変更理由と実効条件は[実行記録](reviews/execution-adjustment.md)に残し、契約原本は保存した。

[再現監査](reviews/reproduction.md)では全5,760音響測定の成功と、以前のv2に対する34,560数値の一致（最大差約1.88×10⁻¹²）を確認した。[実行ドライバ原本](reviews/execution-sources.json)は候補合成コードではなく、今回使ったMOS分割実行・WORLD測定・引用監査・表示処理の記録である。

予測MOSは人間の新規聴取評定ではない。今回の再合成に対する独自校正は未実施。[既存評定データの重複台帳](../../../docs/mos-calibration-ledger.md)で、校正へ進む前に確認すべき資料を整理した。
