# 日本語の通常・ささやき・裏声による補助比較

雑音包絡を分離する候補について、英語120録音で見えた変化が、日本語の通常発声・ささやき・裏声にも現れるかを確認する。

この実験は、[固定120録音の正式比較](../noise-envelope/results/run-001/index.html)を親とする補助診断である。比較する方式は親と同じ自作HNM v1、雑音包絡候補、WORLD（Harvest）。12録音を120録音の集計に加えず、正式比較の100録音以上という要件を引き下げない。

## 固定条件

- JVSの取得済み4話者×通常・ささやき・裏声、計12録音。24 kHz、先頭最大6秒。
- 入力は `data/jvs_available_v1.json` の固定ID・PCM・ハッシュに照合。追加通信は行わない。
- 2つの自作方式は8雑音seed、WORLDは1回。計204合成を予定。
- MOSは原音と各方式のseed 0を同一の取得済みUTMOSv2で測る。計48値を予定。
- MOS・eSTOI・スペクトル・帯域・音量・時間包絡・変調・音高推定整合性・振幅上限を別に報告する。
- JVSの原音・加工音・合成配列はGitへ含めない。音声例は親実験で公開済みの英語例だけを参照・再掲する。

## 入口と検証

`uv run --locked --offline python -m vocoderbench.supplement --candidate-package /Git管理外の候補 --mos-cache /取得済みMOS --output runs/新しい補助実験`

補助入口は親120件の予定・完了・失敗数、全方式の組、MOS完了状態、manifest・方式・測定器・依存関係・WORLD・MOS重みのハッシュを確認してから計算する。途中経過と失敗は逐次保存する。親の採否を修正する機能は持たず、結果に基づく採否の判断は別記録に残す。

同じJVS話者でも発声間で同じ文とは限らず、発声だけの因果効果は推定しない。4話者の結果を日本語一般の品質保証としない。MOSは日本語・ささやき・裏声では未校正の予測値として扱う。

詳しい計画と入力・権利の範囲は [補助手順](../../../docs/JVS_SUPPLEMENT.md)、[固定コーパス](../../../docs/CORPUS.md)、[自動MOSの範囲](../../../docs/MOS.md) に記録する。
