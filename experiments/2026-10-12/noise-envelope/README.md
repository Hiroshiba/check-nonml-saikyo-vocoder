# 雑音包絡の分離と固定120音声での比較

[比較表と音声](results/run-001/index.html) ／ [採否](reviews/decision.md) ／ [事前条件](reviews/criteria.md) ／ [5人の往復議論](reviews/discussion.md)

候補は包絡の誤差を減らしたが、新しく振幅上限を超える条件が2組あり、今回は採用を見送った。唯一の現在ベースは自作HNM v1のままとする。WORLD（Harvest）は既存比較対象である。

従来は自然音声2区間の診断だったが、今回はLibriSpeech test-cleanの40話者・各3発話、合計120録音を比較前に固定した。各音声の先頭最大6秒を無加工で使用し、HNMは8 seed、WORLDは1出力を測定した。UTMOSv2による予測MOSは原音も含め480波形で実施した。eSTOI、時間包絡、変調、帯域・レベル、音高の整合性などを併記し、平均・悪い側5%・話者単位の信頼区間を保存した。

数値の詳細は [results.json](results/run-001/results.json)、集計は [summary.json](results/run-001/summary.json)、全反復と欠測の確認は [audit.json](results/run-001/audit.json) にある。実装・入力・評価器・採否条件の版とハッシュは同じディレクトリに保存した。人工刺激による[校正の読み方](reviews/calibration.md)は正式比較と区別する。

英語通常発声120録音は反復して使用する開発集合であり、未使用の最終評価集合ではない。取得済みの日本語12録音は今回未測定で、正式120件へ含めない。MOSの今回の再合成に対する人間評定での校正も未完了である。

不採用候補のソースはGitに含めず、変更仕様・ハッシュ・数値・音声を残す。そのため候補出力を公開リポジトリだけから完全に再生成することはできない。
