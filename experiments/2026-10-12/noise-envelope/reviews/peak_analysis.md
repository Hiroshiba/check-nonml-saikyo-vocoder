# 振幅超過の原因分析

固定120録音の正式比較で棄却した候補を、問題が出た録音1件の全8 seedで分解した。**新規超過は調波との加算ではなく、雑音単独で生じていた。** この記録は事後の原因分析であり、正式比較の代替や採否の再判定ではない。候補の不採用と現ベースの維持を変更しない。

対象は `librispeech_3575-170457-0034`（16 kHz、55,920標本）。元WAV、復号PCM、両方式のソースSHA-256を正式比較の記録と照合した。元音声の最大絶対振幅は0.848693848。両方式の解析パラメータは全項目で一致し、雑音PSDを0にした調波のみの出力も完全一致した。調波のみの最大絶対振幅は0.607549414だった。

超過の定義は正式比較と同じ `abs(sample) >= 1.0`。全16出力の最大値を正式記録との差0で再現し、各出力と「調波 H＋雑音 N」の差も全標本で0だった。表の超過標本数は、正式比較の「超過した録音・seedの組数」とは異なる。新規超過の組はseed 3と6の2組であり、標本では合計9個だった。

## 最大点で確認したこと

| 項目 | seed 3 | seed 6 |
|---|---:|---:|
| 候補最大点の時刻 | 2.3843125秒 | 2.3715625秒 |
| 同じ標本のベース出力 | +0.574454927 | +0.991945731 |
| 同じ標本の候補出力 | +1.050561758 | +1.003702393 |
| 調波 H | 0 | 0 |
| 交差項 2HN | 0 | 0 |
| ベースの期待雑音分散 | 0.198839295 | 0.283648741 |
| 候補の期待雑音分散 | 0.164531951 | 0.293616776 |
| 期待雑音標準偏差の候補／ベース比 | 0.909649356 | 1.017419372 |

新規超過9標本すべてでHと2HNは0だった。両方式・全8 seedの最大点も調波が0の区間にあった。候補の最大点付近±50 msでも調波のRMSはseed 3で0.000973、seed 6で0.001216にとどまり、雑音RMSはそれぞれ0.194496、0.212913だった。内部の有声・無声判定の最寄り境界からは最大点が約44.3 ms／31.6 ms離れている。ただし、この判定は自然音声の正解ラベルではない。

期待分散は、ベースでは各FFT雑音フレームの期待分散を窓の二乗で重ね、候補では解析PSDの積分パワーを標本時刻へ補間して求めた。FFTのDC・Nyquist端点も実装どおりに含めた。雑音合成窓の実長は512標本＝32 msで、解析窓20 msとは異なる。

seed 3は期待雑音分散が低下しているのに実現した瞬間振幅が増えており、期待パワーを一律に増やしたことだけでは説明できない。候補は重ね合わせ前に各フレームを単位期待パワーに直すため、重なるフレームの相対寄与が変わる。実際、seed 3の最大点に重なるフレームの解析雑音パワーは2.380秒の0.333975から2.390秒の0.013891へ急減している。**フレームの重み変更に伴う雑音の実現値の変化が次の切り分け対象**となる。ただし、各フレームの符号付き寄与の特定までは完了しておらず、どのフレームが超過を作ったかは断定しない。

PSDと窓重みからの補助的な帯域集計では、最大点での雑音期待分散は両方式とも99.6%以上が0〜300 Hzにあった。これは低域を次に調べる根拠であり、原音の低域が不要だという意味ではない。この帯域内訳は解析・合成のフレーム時刻を一致させる近似を用いており、浮動小数点の時刻差に伴う候補側のPSD補間を厳密には再現していない。追加の符号付きフレーム分解はこの一致条件を満たさず停止したため、次巡へ持ち越す。最大値、H・N・2HN、超過標本数、期待総分散の結論はこの補助近似に依存しない。

## 限界と次に確かめること

この録音は失敗を見た後に選んだ1件であり、性能改善の証拠には使わない。8 seedは同じ録音内の反復で、8人の独立した話者ではない。自然音声の周期成分・雑音成分の真値もなく、ここでいう成分は実装の分解である。ベース側にも既存の超過があり、候補だけの一般的な問題とは断定しない。

次巡では、解析と合成の時刻補間を厳密に再現した符号付きフレーム寄与を求め、単位化による重みの変化、低域の集中、時間包絡の急変を分ける。今回のピークに合わせた閾値変更、波形のクリッピング、ゲイン正規化、seed選別は行っていない。正式なベース・候補のコードも変更していない。

数値は [peak_analysis.json](../results/run-001/peak_analysis.json)、計測前に固定した対象・条件・コードSHAは [peak_specification.json](../results/run-001/peak_specification.json) に保存した。波形ファイルは作成していない。JSONには最大点と超過標本の値、±50 msの集計、近傍PSDパワー、全seedの同一時刻比較を含む。
