# 通常品質・音高編集の全120録音結果

[結果HTML](ordinary.html)は無編集71軸と±3半音の編集8軸をまとめたものです。固定120録音・40話者の予定行をすべて保持し、失敗・未対応・対象外を欠測として示します。特徴空間ABX・独立trainからの読み出し・費用は別の計測群として継続中です。現ベースはPMLのまま、候補の採用は未決定です。

## 現時点の読み取り

- 無編集の共通117録音・40話者では、予測MOSは候補3.55063、PML3.26989、WORLD3.04897。候補−PMLは+0.28074、話者bootstrapの記述的95%区間は[+0.17731,+0.39108]。ERB、SCOREQ、ECAPAの保存値でも候補が上位です。
- +3半音の共通115録音・40話者では、予測MOSは候補3.03447、PML3.15646。差は−0.12199、同区間は[−0.22120,−0.01542]。編集後の話者類似度も候補が低く、無編集の良さを編集品質へ一般化できません。
- −3半音の予測MOS差は−0.01320、同区間は[−0.09998,+0.07577]。編集後ECAPA差は−0.03030で、音質と声の類似度を別々に見る必要があります。
- ASR比較は全文条件と生成支持の揃った54録音・32話者です。候補の増分WERはPMLより順位が下ですが、対応差の区間は0を含みます。
- 候補の生成成功は無編集117/120、−3半音117/120、+3半音115/120。未成立の例を都合よく分母から消していません。

これらは指標ごとの結果で、総合順位・平均順位・多数決による採用を行いません。予測MOSは人間の新しい聴取評定ではなく、記述的区間は多重比較未補正です。固定120は開発履歴のある集合で、独立した未使用最終評価とは扱いません。
