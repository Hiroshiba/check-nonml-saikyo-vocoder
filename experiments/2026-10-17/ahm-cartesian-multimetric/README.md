## 今回の問いと現在のベース

native aHM解析と固定Cartesian音高編集を一つの凍結候補として、再合成の品質、音高変更への追従と副作用、特徴空間、解析・合成費用を調べます。無編集の主出力もCartesianの変更量0を通し、−3／+3半音と同じ編集経路で比較します。直接native復号は変更量0の整合性を確認する参照で、別方式・独立条件に数えません。

現在の唯一の開発ベースは [BASELINE.json](../../../BASELINE.json) の **PML `pml-lowband-fwcep60-v1`** です。今回の評価PRでベースを切り替えません。[PML正式評価](../../../research/pml-package-evaluation-2026-10-16/index.html)の測定時の旧HNM基準を、今回の現ベースと混同しません。

主比較は同じ新評価環境の候補・現PMLを中心にし、WORLDの無編集を比較対象にします。他の既存方式は入力・出力・測定器・前処理・実装・実行環境の互換性を根拠付きで確認できる軸のみ引用し、不明な歴史値は別表に分けます。標準LLSM2 Layer 0と以前のLayer 1条件も別方式として識別します。

固定LibriSpeech test-cleanの120録音・40話者・各3録音、16 kHz mono、先頭最大6秒を使います。[固定入力manifest](../../../research/pml-package-evaluation-2026-10-16/input-manifest.json)とID・話者・入力SHA・長さ・共通窓を照合し、結果による差替えはしません。録音数を話者数と読み替えません。

以前の12録音・12話者pilotは今回の120の内数です。開発17、pilot12、残91を分け、過去の開発話者との重複も示します。全120は既存開発集合であり、未使用の独立最終評価ではありません。決定的な同一出力を8seedへ複製して独立標本としません。

[測定契約](protocol.md)で品質・制御・特徴を分け、単一のMOS、平均順位、指標の多数決、主観的な重み付き総合点で採否を決めません。人間による新たな聴取評価を完了条件にはしません。予測MOSを人間の評定や自然さの保証とは扱いません。

## 予定する評価

- 無編集：既存品質71軸。複数窓スペクトル、帯域、明瞭性、音量・低エネルギー区間、音高整合、時間包絡、変調、ERB、UTMOSv2、SCOREQ、ECAPA、増分CER/WER
- 編集：±3半音の追従誤差と有声支持、未検出・範囲外、編集MOS／ECAPA。意図した変更を原音との類似度だけで罰しない
- 特徴：保存payloadからの3種類の固定観測による音素ABXと独立train120による固定線形読み出し。3観測を3方式・3票にしない
- 費用：初期F0準備を含む解析、編集、復号、保存I/O、実payload量を分離。別runの速度順位は作らない

候補の音量操作、時間伸縮、傾斜操作、特徴補間、精度摂動後復号、native 48 kHzは未対応です。ASV既存評定や48 kHz補助資料は別集合・別資源条件で扱い、主120の完了数へ加算しません。
