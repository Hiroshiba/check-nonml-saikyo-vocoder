# 方式非依存の追加指標と人工入力による計算確認

## 問いと結論

添付Markdownの後半の18項目から、既存PR #27が担当する5項目と、その他の内容・制御・特徴表現を分ける。今回は新規13入口を独立CLIとして追加した。ERBは#27の単純距離と一部重なるが、局所系列・固定区間・有効セル数を持つ診断として分離した。

HNM向けの内部フィールドは共通契約へ戻していない。現ベースや候補のencode/decodeを変更せず、保存済み波形・特徴・外部証跡を読む。13入口の全部が自然音声で校正されたわけではない。ASRは集計のみ、局所時間は孤立イベント、音色はスペクトル傾斜、品質や制御の足りない曲線はpartialである。

## 比較したもの・していないもの

正式ベースと実候補の性能比較は未実施。これは補助的な指標計算の確認である。ERBに原音自己比較を置き、その他には既知の操作を与えた解析的波形を使った。方式採用・品質合否・使用可能な操作幅の判定はしない。

48 kHz・主に1.2秒の人工入力15条件を各6回、計90回計算した。11条件ok、4条件partial。さらに異常・対象外7条件を各2回観測した。動的ピッチのMAEは約0.044 cent、動的ゲインは約1.36e-8 dB、孤立イベントは約0.021 msだった。これらは人工入力上の数値で、自然音声の推定精度を示さない。

原音自己比較ERB=0、人工ABXの完全な同点=0.5、話者・発話を分けた読み出しを記録した。雑音の生成器はRNG seed 42に固定し、manifestのseed 0はこの人工条件一式の識別ラベル。複数乱数seedの評価はしていない。実コーパスで利用するときは各方式が実際に使うseedを記録する。

## 再生成と記録

[仕様書](../../../docs/MODEL_INDEPENDENT_METRICS.md)の `assessment.probes` と `assessment` のコマンドで入力・完全JSON・HTML・ログを生成する。出力は毎回新しいディレクトリを指定する。部分測定を含むため例示計測の終了コードは1である。

[補助レポート](results/probe-calibration/index.html)と[要約JSON](results/probe-calibration/results.json)は、各条件の代表結果・90回の壁時計／CPU時間・実装ハッシュを保存する。完全なフレーム系列・入力WAV・詳細ログは提出したZIPに保存しており、Git内JSONはその全量の代わりではない。完全ファイルのSHA256も要約に記録した。再生成の所要時間は環境に依存する。

Python 3.13.5・NumPy 2.3.5・SciPy 1.17.0で実行した。リポジトリのlocked Python 3.12環境とは異なる。ローカルでRuff、WORLD、既存の全比較、Pages全体は実行していない。PRのCIと別に判断する。compileall、CLI help、指標一覧、全13入口の人工計測は実行した。

元の指示文、正式ベース、依存固定、既存比較結果を変更しない。公開一覧では方式比較の主runに見せず、supplementとして登録する。研究用の計測・入力生成であり、テストスイートや音質の自動合否判定ではない。

## 次の検証が必要な点

実方式の同一コーパス・同一編集条件、自然音声100件以上、言語・話者・発声様式別の誤差と失敗、話者単位の信頼区間・複数seed・メモリ、#27の実モデル／評定資産との照合が必要。フォルマントや自然音声の局所境界を未校正のまま数値だけ追加しない。


## 2026-10-14追記：現在の生成経路との区別

上記の測定値・90計算・異常条件・実行環境は旧commit `122e712ca5f5bc80c177cc756640f3c696783c79` 時点の履歴であり、書き換えていない。「再生成」の旧手順は現在の運用手順ではない。現行の `assessment.probes` から動作確認専用の原音自己比較、異常入力、架空ASR・玩具特徴の生成を除去し、既知変換に対する測定器の適用範囲・制御追従の研究6条件に限定した。

現行生成器を使っても旧15条件の入力一式は生成されない。今後の研究は[現行仕様](../../../docs/MODEL_INDEPENDENT_METRICS.md)で目的・条件を固定し、新しい出力先に記録する。今回の調整では入力生成・指標計算・モデル推論を実行しておらず、この過去結果を変更後ソースの実測値として扱わない。
