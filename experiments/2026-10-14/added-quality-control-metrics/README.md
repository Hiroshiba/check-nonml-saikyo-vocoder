# 固定自然音声の追加品質・制御指標

現ベースの **HNM v3** と既存比較対象の **WORLD（Harvest）** を、固定LibriSpeech英語120録音・40話者で比較する。非MLの解析・合成方式を変更せず、追加評価器を実音声へ適用する記録である。総合順位や新方式の採用は決めない。

**正式実測と本番レポート保存を完了した。** 合成1200出力、MOS1320行（同条件の引用360／新規960）、ECAPA1200行、20 ms ERB240行、SCOREQ240行が有効。制御・局所診断1440と品質曲線480を合わせたassessment1920 job、ASR165推論・110 jobも完了した。全予定jobの保存完了は、18項目全体の完成や科学的な適用範囲の拡大を意味しない。

主記録は、[音声付き比較HTML](results/run-001/index.html) と [結果JSON](results/run-001/results.json) に保存した。本番記録時刻は2026年10月13日17:13:27.986543 UTC（日本時間10月14日02:13:27）である。ASRや制御診断を別の独立レポートとして数えず、この主記録に含める。

## 現ベースとWORLDの追加指標

話者等重み平均。全項目で各方式120/120録音・40/40話者が有効。MOSは上記の同条件引用値で、今回の新規推論とは分ける。

|---|---:|---:|
| 予測MOS ↑ | 2.5768 | 3.0454 |
| ECAPA類似度 ↑ | 0.9069 | 0.9306 |
| ERB 20 ms誤差 dB ↓ | 2.1025 | 2.1727 |
| 局所ERB 40 ms誤差 dB ↓ | 2.2357 | 2.0568 |
| 局所ERB 40 ms・発話内P95 dB ↓ | 6.7378 | 6.3954 |
| 実NPZ bytes/秒 | 1,386,716 | 1,288,786 |
| SCOREQ natural/ref距離 ↓ | 0.5852 | 0.3791 |

原音の予測MOSは3.8492。SCOREQ・ECAPA・40 ms局所ERBではWORLD側の値が良く、20 ms ERBではHNM側が小さい。窓と床・集約が異なるERB診断を独立した票に数えず、指標間の違いを残す。人間の自然さや知覚的優越の保証ではなく、総合順位は作らない。

## 新規測定とMOSの引用

UTMOSv2はfold 0・抽出seed 20261012・抽出1回に固定した。原音120と無編集240の計360行は、入力float32のSHA256・標本化周波数・長さに加え、実装・重み・全科学設定・依存関係の一致を台帳で確認した過去値を再利用した。編集960行は今回の新規推論である。過去値に付属する推論秒数は今回の所要時間へ加算しない。MOS専用driverの再利用条件は今回の独立台帳と全科学設定の一致に基づく。他の設定へ転用する場合は、その条件でも同一性を別途証明する必要がある。

合成記録には、初期scriptがraw PCMのhashと旧NPYファイル全体のhashを比べてしまった欄も残る。生JSONを成功値へ書き換えず、別台帳で同じNPYファイル同士の240件の一致と誤比較の理由を記録する。MOS再利用に用いたfloat32入力の同一性比較とは別の欄である。

[過去8方式の正式比較](../../2026-10-13/formal-hnm-v3-references/README.md)を今回の測定として再計上しない。歴史的な表の発話等重みと、今回の主表の話者等重みも区別する。

## 集計・測定器・反復

- 品質と制御の主集計は、発話の初回値を話者内で平均し、話者を等重みにして平均する。WORLD−HNMは同じ発話の差を先に計算する。有効発話／120、話者／40、対応可能な対、欠測理由を保持する。
- 20 ms ERBと40 msの`auditory_local`は、窓・床・局所集約が異なる関連診断である。独立した2票として結論を強めない。局所P95は発話内のフレームRMSEのP95を話者単位で平均した値である。
- 音高誤差は両側でF0が推定できたフレームに条件付きである。YINの未検出・有声／無声の不一致・範囲外を残し、未検出を真の発声消失や0誤差と解釈しない。
- ゲインの追従と干渉は、±6 dBの定常操作と理想一様振幅スケールの期待応答を調べる。知覚音量、動的操作全般、ピッチ操作の非対角期待応答は校正していない。
- ASRは公式全文転記を正解に使い、原音のASR出力を正解にはしない。`facebook/wav2vec2-base-960h`、greedy CTC、固定の文字正規化・単語分割、原音CER上限20%。今回の55録音は全て上限内だった。残65録音は切出し正解未整備で対象に含めない。
- ASRの発話等重み・話者等重み・全文字／全語重みを併記する。小差の順序が重みで変わり、全語重みの出力WERは両方式28/630＝4.444%で同じだった。単純な優越にまとめない。
- 追加品質とassessmentは初回＋1反復。UTMOSv2とASRの推論は各波形1回である。時間反復や同一録音の処理を独立標本数として数えない。

## 再生時の注意

+6 dBの全長出力で、振幅の絶対値が1を超えた録音はHNM53/120、WORLD87/120。全録音での最大ピークは約2.5846／2.7428だった。保存波形はクリッピングしていないため、ゲイン追従誤差が小さくても、再生機器や整数化で歪む可能性がある。安全な編集幅を示す結果ではない。

公開する先頭2秒の範囲は全長測定と異なる。22例のうち、`librispeech_1089-134686-0008`のWORLD +6 dBではピーク約1.0623と振幅1超を記録した。該当カードにも警告を表示する。再生音量を低くしてから比較する。UTMOSv2は保存した浮動小数点波形への予測であり、再生系でクリッピングされた音のMOSではない。

合成開始は2026年10月13日16:12:55.407846 UTC、合成1200出力の保存完了は16:23:35.259724 UTC。日本時間では10月14日01:12〜01:23で、この開始日にまとめた。品質推論とASR、制御診断は別工程として同時実行した区間がある。最後のSCOREQ分割実行は17:09:27.761249 UTCに終了した。本番結果の記録日時は`results.json`の`generated_at`（2026-10-13T17:13:27.986543+00:00）をそのまま一覧へ登録した。測定終了時刻とレポート記録時刻を区別する。

## 証跡と公開形式

本番レポートは[scripts/added_metrics_report.py](../../../scripts/added_metrics_report.py)で完了済みJSONから保存する。部分的な分割結果を完了へ丸めず、必要な予定数が揃うまで保存を止める。音声の再合成・再decode・評価推論はこの報告処理では実行しない。

- `results/run-001/`の直下には完成HTMLとJSONだけを置く。モデルhash・実装・環境・準備・初期化・失敗・再開履歴・40話者集計・18項目の範囲へHTMLから直接リンクする。
- 全計測JSON、テキストログ、凍結した実行sourceは、実行環境の絶対パスや認証値を秘匿して保存する。公開側には主結果、話者別集計、モデル・実行条件、ログ索引を置き、内容が重複する分割ごとの生結果・summary・scalar rowsは全値保持の圧縮証跡へ集約する。`provenance-index.json`に原本と変換後のhash・変換理由・保存先を記録し、数値・欠測状態は変更しない。
- 公開JSONは9 MiBを超える場合に空白を削減する。それでも大きい場合は、全JSON文字列を順序付きの小JSONに分け、各部分と連結復元後のSHA256・復元方法を保存する。
- 全分割の生値を含む圧縮証跡はグループの`archives/`にGit保存し、Pagesには載せない。必要な数値を削除して容量を減らすのではなく、重複する公開コピーを減らす構成にした。大きな圧縮ファイルは順序付きpartに分け、各partと復元ZIPのhashを保持する。
- 元録音全体、全長合成音、NPY／NPZ、モデル重み、cacheは公開しない。JSON内の相対音声・表現パスはデータ参照であり、ダウンロードリンクではない。
- 音声例はデータ一覧で事前固定した2録音について、原音と各方式の無編集・4操作を合わせた22例。先頭最大2秒のみを既存の音声抜粋処理でfloat32 WAVにし、HTMLへ埋め込む。音量正規化・クリッピング・再標本化はしない。

音声出典は[LibriSpeech test-clean / OpenSLR 12](https://www.openslr.org/12/)、[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。変更は先頭区間の抜粋と、各方式の合成・操作である。

## この記録で判断できないこと

固定16 kHz英語開発集合の記述的結果である。48 kHz原収録音声の高域保持、日本語や他の発声様式、独立最終評価、人間の自然さ・話者類似度の校正は完了していない。ViSQOL Audioは本集合では対象外。ABX、属性読み出し、局所時間、知覚音色、表現補間、表現摂動による頑健性、複数設定の品質–表現量曲線も実施済みとは扱わない。

テスト・スモーク・自己検査・Pages生成予行は行わない。コードの静的解析と保存済み実測の解釈を分ける。PRで結果を提出しただけではPagesに公開されず、mainへのマージ後に本番公開処理が成功して反映される。今回の測定でBASELINE.jsonやHNM本体を変更しない。
