# 位相の分布を混ぜることと波形を平均することの違い

2026-10-20。既知の人工波形を用いた紙上の補足です。音声生成・数値実験・音質評価・合成方式の採用は行っていません。

予測する確率分布の混合と、一つの出力波形を平均で作る操作は別です。同じ周期の波形でも、半周期ずれた二候補を等しく平均すると、奇数次の調波が消え、最小周期が半分になる例を示します。これは仮想的な位相分布による反例で、実際の推定結果や知覚上の音高を測った結果ではありません。

平均波形の二乗誤差最適性と、予測密度の対数得点最適性は、対象・条件が異なります。全区間で一つの位相を共有する生成と、区間ごとに位相を引き直す生成も区別します。観測の予測分布から標本を作るには、位相だけでなく条件付き雑音も必要です。独立レビューの明確化を反映し、再確認を終えています。
