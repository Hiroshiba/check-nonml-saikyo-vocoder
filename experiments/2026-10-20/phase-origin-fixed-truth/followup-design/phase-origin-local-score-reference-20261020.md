## 1. 結論と適用域

理想生成lawと正しいGaussian scoreに対し、真位相近傍の同じ局所枝で、位相をcycle単位とすると、

    δ_lin = (dᵀε_train)/(dᵀd)
    V_lin = Var(δ_lin) = (dᵀΣd)/(dᵀd)²
    I = dᵀΣ⁻¹d + (1/2) tr[(Σ⁻¹Σ′)²]
    E_test[Δ | train] = −(1/2) I δ² + o(δ²)

が成立する。最後の式でδはtrainだけから決まる位相の真値からの局所差であり、δ_linへの置換は別の推定器linearizationである。反復期待

    E_train,test[Δ] ≈ −(1/2) I V_lin

にはさらに、一次誤差の平均zero、正しい局所枝への集中、非局所誤差および展開剰余の期待寄与が十分小さいことが必要。一般にはVarだけでなくE[δ²]=Var(δ)+(Eδ)²を用いる。

Wの「−1/2 nats/record」はこの理想局所近似の帰結で、実際の有限標本の定数値・合格域ではない。位相非依存ΣではCauchy–SchwarzによりI V_lin≥1。V/S/JではΣ′の寄与を原則落とせない。S/Jの境界で一次微分が存在することは、今回のqの端点消失次数を確認して初めて言える。

この参照は固定100/truthの合格閾値、数値gate、理想global根保証、成功subsetや丸め生成lawの符号保証、音質改善の根拠にしない。非同値根への移動・失敗選択には適用しない。

## 2. 仮定と記号

- 固定真値φ0=0で、Y_train=m0+ε_train、Y_test=m0+ε_test。両残差は独立で、同一の理想N(0,Σ)に従う。train/testは同じ観測gridと有限窓を持つ。θは既知真値に固定し、phaseとともにrefit・rotateしない。
- m0=m(φ0)、d=∂m/∂φ|φ0、Σ=Σ(φ0)、Σ′=∂Σ/∂φ|φ0。dᵀd>0、Σは正定値。Σ′は有限観測座標での全共分散の微分であり、低rank因子の列数が同じことは要求しない。
- 円周差はφ0の近傍で一つの実数chartへ持ち上げる。φ≈1は負の小さいδとして読む。整数差のみの同値性と、非同値な別の停留根は区別する。
- 局所OLSが真値近傍の安定した最小枝にあり、そのlinearizationが妥当とする。noncertified gate通過がこの仮定を証明するわけではない。
- 以下は理想実数関数の式。binary64生成、近似根、φ_eval丸め、数値密度の誤差が無視できるとの証明は含まない。

位相の単位を変えるとd、Σ′、I、Varδは変わるが、I Varδは不変。cycleとradを混ぜて式へ入れない。

## 3. OLS誤差の一次導出

F(φ)=||Y_train−m(φ)||²の停留条件は

    m′(φ)ᵀ[Y_train−m(φ)] = 0。

m(φ0+δ)=m0+dδ+O(δ²)を用い、noise×δおよびδ²を高次として落とすと、

    0 ≈ dᵀε_train − (dᵀd)δ

からδ_linを得る。線形surrogateの中ではEδ_lin=0、分散は上記V_linで厳密。Gaussian性はこの分散式自体には不要で、平均zeroと共分散Σがあればよい。

一方、実際の非線形停留方程式ではm″(φ0)ᵀε_trainを含むランダム曲率があり、δ²項もある。δが小さいという言葉だけで、それらを捨てることは正当化できない。例えばnoiseを小さくし、曲率が安定し、局所枝へ集中する理想漸近がこのlinearizationを支える。finite recordで別の非同値最小へ飛ぶ可能性は本式の外にある。

同じOLSでも、一般の相関noiseまたはphase依存noiseに対するGaussian MLとは限らない。推定に共分散の情報を使わないことと、評価scoreが共分散の変化を感知することを区別する。

## 4. S/Jの動くsample境界を先に点検

今回の解析qは固定正の尺度を持つ

    q(u) = c sin⁴(πu)[1+(3/10)cos(2πu)]

であり、端点をまたぐ局所座標xでは

    q(x)=C x⁴+O(x⁶),  C≠0,
    q′(x)=4C x³+O(x⁵),  q″(x)=12C x²+O(x⁴)。

したがってSのf=qは4次、Jのf=h=−q′/c_dは3次で消える。いずれもf(0)=f′(0)=0で、周期側の端点でも同様。

共分散の周期効果部分の(n,m)成分は

    t f_n(φ) f_m(φ) 1[c_n(φ)=c_m(φ)]

である。φ0=0をまたぐと、nが周期の始点にあるsampleだけが隣の周期へ移る。移るsampleのf_n(φ)はO(|δ|^p)、p=4（S）または3（J）。他の通常sampleとのcross-covarianceのmembership変更分はO(|δ|^p)、移るsample同士では高々O(|δ|^(2p))である。

oracleのK個の固定blockを使った滑らかな補助共分散を近傍で考えると、実際のfloor-based共分散との差は有限次元行列としてO(|δ|^p)。従って両側で

    Σ(φ0+δ)=Σ+δΣ′+o(|δ|)

となり、Σ′は同じ固定block補助系の微分から得られる。これは「membershipが不変」という主張ではない。φ<0側で追加される端の部分周期は独立係数を持ち、端同士を共有しない。その差が一次では消える、という局所事実に限る。

一般のtemplateに自動拡張しない。端点f≠0ならcross-covarianceがjumpし得る。fが1次で消えるだけならcross-covarianceの片側一次微分が異なり得る。通常sampleのfが非zeroの場合に、p>1はここでの一次微分一致の十分条件。偶然のzeroやt=0による退化を除き、端点f=0だけでは不足する。

今回p≥3なので、この境界補正は二次のscore期待展開の主項を変えない。floorに関する数値判定や境界rootの成功認証を与えたものではなく、数学的微分の存在と運用上の失敗規則は別問題である。

## 5. Gaussian Fisherと条件付き期待score差

ε=Y_test−m0、B=Σ⁻¹とする。正しいGaussian familyのφ-scoreは真値で

    Sφ(Y_test)
      = dᵀBε + (1/2){εᵀBΣ′Bε − tr(BΣ′)}。

平均zero Gaussianの一次項と中心化二次項は三次momentがzeroなので無相関。一次項の分散はdᵀBd、中心化二次形式の分散公式より二次項の分散は(1/2)tr[(BΣ′)²]。よってI=E[Sφ²]が上記の形となる。

trace項は非対称行列BΣ′の要素二乗和という意味ではない。対称行列Σ^(−1/2)Σ′Σ^(−1/2)を用いた二乗traceと等しく、非負である。

trainを固定すればδは定数。理想test lawと正しい正規化密度のもとで、既存契約の条件付き期待恒等式が成立する。その真値近傍の二次項が

    E_test[Δ | train] = −(1/2) I δ² + o(δ²)

である。平均と共分散が微分可能でΣが正定値なら、Gaussian期待log densityの一次変動が真値で消え、二次主項が上記になる。必ずしもfloor因子そのものの滑らかな固定列表示は必要でない。今回S/Jは§4で全共分散の必要な局所展開を確認した。

この導出は新たなKL値を計算する提案ではない。既存の二本のscoreの解釈だけに使う。実現Δにはtest noiseによる変動があり、正のΔも許される。

## 6. train反復期待に必要な追加条件

条件付き局所式を形式的に平均すれば−I Eδ²/2となるが、点ごとのo(δ²)だけでは期待の剰余を捨てられない。小誤差へ集中する系列、局所剰余の支配、非局所tailの寄与が小さいことなどが必要。noise縮小などでΣ自身が変わる場合は、Iも変わり得るため、対応する尺度で剰余を比較する。

δ=δ_lin+小さい剰余で、二乗momentも一次近似に従えばEδ²≈V_lin、従って−I V_lin/2。単に非線形OLSの平均誤差が小さいと観察しただけでは、tailやbiasの寄与を排除できない。

本稿は成功subsetにこのV_linを代入しない。trainだけによる成功選択でもδの分布は変わる。理想testの各train条件付き期待に関する既存の恒等式が残る場合と、無選択の反復分散式が残るかは別である。test依存の有限score選択を含むsubsetには、同じ符号論も移せない。丸め生成lawについても理想lawの符号を保証しない。

## 7. Wと位相非依存Σの参照

WでΣ=sI、s>0なら、Σ′=0、

    I=(dᵀd)/s,  V_lin=s/(dᵀd),  I V_lin=1。

よって局所線形・独立反復の期待score差は約−1/2 nats/record。単一testの値、固定100反復の平均、非線形OLS全域の厳密期待ではない。

Aを含む位相非依存正定値Σでは、

    (dᵀd)²
      = [(Σ^(−1/2)d)ᵀ(Σ^(1/2)d)]²
      ≤ (dᵀΣ⁻¹d)(dᵀΣd)

なのでI V_lin≥1。等号はΣd=λd、すなわちdがΣの固有方向にあるとき。Aが有限窓の相関共分散を持つというだけで等号を置けない。周期的なdを無条件に有限AR共分散の固有vectorとみなさない。

これは線形化OLSの効率損失を表す代数関係であり、全ての有限実現Δが−1/2以下という意味ではない。phase依存Σでもmean部分だけには同じ不等式があり、covariance Fisherはさらに非負に加わるが、近似を数値判定へ変換しない。

## 8. Vで落とせない分散包絡の微分

Vは対角Σ=diag(v_n(φ))なので、

    I_mean = Σ_n d_n²/v_n,
    I_cov = (1/2) Σ_n [v′_n/v_n]²。

v_n=s w_n/Zφであるから、

    v′_n/v_n = w′_n/w_n − Z′φ/Zφ。

Zφは離散L点の正規化であり、一般には位相不変でも連続積分でもない。特定の真位相で対称性により一部がzeroになる可能性と、Σ′全体を落としてよいことは異なる。bc/bsは固定真θであり、位相変化を係数の回転で相殺しない。本稿は値を代入・評価しない。

## 9. S/Jのrank-one block式

固定blockにおいてΣ_b=sI+tffᵀ、s>0、t≥0、f_dot=∂f/∂φ、fᵀf_dot=0とする。F=fᵀf、G=f_dotᵀf_dotと書くと、

    Σ′_b=t(f_dot fᵀ+f f_dotᵀ)。

F,G>0ならe=f/√F、v=f_dot/√Gを直交単位vectorに選べる。この二次元部分空間でΣ_bはdiag(s+tF,s)、Σ′_bは非対角成分t√(FG)だけを持つ。したがって

    I_cov,b = (1/2)tr[(Σ_b⁻¹Σ′_b)²]
            = t² F G / [s(s+tF)]。

F=0、G=0またはt=0なら両辺zeroとして読む。この式は正しい。ただしfᵀf_dot=0がなければ追加の平行成分があり、同式を一般のrank-one blockへ用いない。

今回の理想解析qと完全L点gridでは、fの二乗normが位相に依らないためfᵀf_dot=0。Sならf=q、f_dot=q′、Jならf=−q′/c_d、f_dot=−q″/c_d。φ0=0での境界移動は§4の消失次数により一次微分に影響しないので、ここではoracleのK個の完全blockを用いてよい。

### 全K blockとmeanの組合せ

S/Jの今回のtruthは白色baseと独立な周期係数であり、oracleでK blockが独立・同一となる。共通位相は一つだけで、K個の位相を推定するわけではない。blockのmean微分をd_b、D=d_bᵀd_b、C=d_bᵀΣ_b d_b、M=d_bᵀΣ_b⁻¹d_bとおけば、

    I_total = K (M + I_cov,b),
    V_lin,total = C/(K D²),
    I_total V_lin,total = (M + I_cov,b) C/D²。

FisherがK倍になる一方、共通OLSの一次分散は1/Kとなる。従って「K blockだから期待損失をK倍」とするのは誤り。AR cross-block相関を追加した混合truth、異なるblock、端の部分周期では、この同一独立block式をそのまま使わない。

Sではd_b=f_dotでfᵀd_b=0。従ってC=sD、M=D/sでmean部分の積は1。Jではd_b=q′=−c_d fなので、C=(s+tF)D、M=D/(s+tF)で、やはりmean部分の積は1。しかし両者とも一般にΣ′_b≠0であり、totalには上記I_cov,bの寄与が残る。このmean部分の等号を理由にS/J全体をWと同じにしない。

これらはφ0における局所導関数の式だけである。finiteなφ_evalでは、先頭・末尾の独立部分周期、実際のmembership、実際のblock normを用いる元の密度契約が必要。局所のK完全block式やfᵀf_dot=0を、finite shiftの部分周期scoreへ流用しない。

## 10. 五仮想役・二round

一人による仮想論点整理であり、五人の独立査読を装わない。役は推定論、Gaussian score、境界幾何、運用解釈、critic。

### Round 1：式の成立条件

1. 推定論「OLSならVarδがそのまま得られる」→critic「非線形のランダム曲率を落とした条件は何か」→一次surrogateでの厳密式と実際のOLS近似を分け、安定した局所枝を要求。
2. Gaussian score「FisherはdᵀΣ⁻¹dだけ」→境界幾何「V/S/JのΣも位相で動く」→中心化二次scoreを導出してcovariance項を保持。
3. 境界幾何「floorがあるから微分不能」→critic「因子の端点消失次数を見たか」→Sの4次、Jの3次消失から全Σの両側一次微分を確認。ただし一般templateへは外挿しない。
4. 運用解釈「Wは−1/2を合格ラインにできる」→推定論「理想局所の反復期待で、test実現は揺れる」→閾値・gate・固定標本合否への利用を禁止。
5. critic「trainを平均すれば自動的にVarになる」→Gaussian score「bias²、tail、期待剰余が必要」→Eδ²を基本形にして、V_linへの置換条件を独立に記載。

### Round 2：境界・選択・全窓への誤用

1. 推定論「Aも一つのphaseなので積は1」→critic「OLSは一般のGLSではない」→Cauchy–Schwarzと固有方向の等号条件を示し、Aでの等号を断定しない。
2. Gaussian score「S/Jのmean積は1なのでWと同じ」→境界幾何「rank-one方向そのものが回転する」→I_cov,bを加え、mean部分だけの等号と区別。
3. 境界幾何「φ0で固定blockが使えるならfinite shiftにも使える」→critic「部分周期とcross-covarianceの差は一次で消えるだけ」→有限φには元のfloor-based密度を要求し、局所式の流用を禁止。
4. 運用解釈「成功した100未満に−I V_lin/2を当てる」→推定論「選択で誤差分布が変わる」→成功subset、test依存選択、丸め生成への保証を切り離す。
5. critic「期待参照を実測列に追加すべきか」→全役「いいえ。新しい計算・KL列・run変更は要求しない」→文書だけで停止し、noncertified根の保証・自然音声の品質主張にも接続しない。
