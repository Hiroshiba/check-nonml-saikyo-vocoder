# 初回 clock/event 分散 encoder：保存済み科学結果の独立解析

2026-10-19 UTC。新しい合成・fit・科学条件・閾値調整・テスト・実装変更・Git操作なし。旧結果は保持。

## 結論

モデル内C3では4/4 seedが正しい周期AMと96 ms・8 ms・c=4の単一eventを選択した。一方、最大の失敗はC5の非定常meanである。真のq=0・eventなしに対し全4例がq index 10（半径0.6、角度π/4）を選び、背景分散を7.13–7.18倍へ増大させた。eventの偽検出ではなく、mean変化を広域の周期noiseへ誤帰属した。次の単一変更はmeanの時間変化への対応を優先する。C4相互作用は局所的に明瞭な残課題だが、C4だけを理由に予定順を機械的に進めない。

## 局所誤差と帰属

- C0：q=0、eventなしが4/4。C1：真q=10、eventなしが4/4。周期分散をevent枝へ退避する現象はこの小標本では見られない。C2もq=0が4/4で、局在増分の周期化は選択結果に見られない。
- C2：3/4は正しいonset、seed20261019だけ1 ms遅れ。全区間KL約0.003568に対しinside KL約0.085226。次点ΔL約0.2001と近く、単一実現の位置不確実性がある。局在積分powerは全4例−1.70%〜+1.98%でも、位置誤差は残る。遅れ例の支持外power比は約1.09e−5で、真onset前powerは0。これは小さい後尾漏れであり完全支持一致ではない。
- C3：q/位置/幅/強度/個数が4/4一致。局在積分power誤差−1.21%〜+1.71%。全区間KL約0.00113、inside約0.00064–0.00067。最小次点ΔLは0.7803（seed104729）なので、正しい選択を高確信posteriorと読み替えない。
- C4：全4例q=10、onset96 ms・幅8 ms・1 event。ただしseed0はc=1、他3例はc=4。局所在KL平均0.0312は区間全体0.001924より16倍程度大きい。外側KL約0.00097でqベクトル誤差は丸め精度。平均全体KLだけなら局所相互作用不足を見落とす。
- C4の局在power相対誤差平均はnative+0.46%に見えるが、実際の範囲は−68.59%〜+24.39%。正負の相殺である。targetでは平均+6.95%、範囲−66.56%〜+32.43%。推定局在分散形は絶対時間に固定、真値はtarget位相で変形する。重心はnative−0.484 ms、target−0.501 ms。周期qが正しくても局所分布は正しくない。
- C5：qのL2誤差0.6が4/4、phase誤差は真q=0なので採点不能。event数は正しい0でも帰属成功ではない。native KLのmean項0.4109、variance項0.5194、mean MSE0.002483（他条件約0.0000005–0.000001）。nativeと編集の両方で大きい誤差が再現し、単なるtarget時計移動の失敗ではない。native C3に対して全KLは約826倍。
- 全caseに過剰event・欠落eventはない。推定onsetより前および真onsetより前の局在増分は0。背景noiseをevent先行漏れに数えない。2 eventは今回一度も選ばれず、この結果は2 event容量の妥当性を実証しない。

## 次の一変更：stationary mean仮定のみを緩める

推奨は、4調波meanに共通する、絶対時間上の小さなgain envelopeを混合から推定する次版。周期noise、非負局在分散、辞書、q格子、罰則を同時変更しない。C5の真gain/128 ms/遷移幅をencoderへ与えず、同じ推定を全条件へ適用する。保存波形や全残差を増やす救済はしない。

具体設計候補は「単一の滑らかなgain遷移」で、mean係数との尺度不定性を固定し、contrast・中心・幅を有限範囲で推定するもの。これならfloat32を3個追加する設計でcore +12 bytes（最大56/clock込み64 bytes）が一つの予算案となる。ただしこれは今回未採用の次版設計案であり、探索域・自由度・記述長罰則・追加演算を事前に決める必要がある。現在の結果から追加RTFや成功率は推定できない。既知C5形状への過適合の危険を明記する。

次版を実行する場合の問いは、C5でmean MSE・全KL・σ膨張・偽qが同時に改善し、C0–C3の帰属を壊さないか。旧版を保持し同じ固定24入力と両targetで比較する。今回ここでは実装もrunも行わない。C4の局所相互作用誤差は別の未解決項として残し、mean変更と同時に直さない。

自然/b/、未知H/位相、48 kHz、window接続、正式120録音/40話者の採用判断はこの実験の範囲外。4 input seedの有限人工条件の結果を母集団成功率や生理的同定へ一般化しない。
