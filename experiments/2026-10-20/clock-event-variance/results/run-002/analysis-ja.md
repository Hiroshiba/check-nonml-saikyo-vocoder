# 共通gain v2：保存結果の独立解析

2026-10-19 UTC。結論：C5のmean変化を周期noiseへ逃がす失敗は、この固定24入力では大幅に改善した。C0–C4の選択・保存分布・出力に新たな崩れは見られない。これは既知失敗へ対応した有限開発条件の改善であり、未知自然音声の品質や汎化を証明しない。

## 対象と照合

正本は `clock-event-mean-transition-next-design-20261019.md`。v1/v2 receivedディレクトリの results.json、保存NPZ、payloadを読むだけで独立算術再集計した。推定器・truthのimport、合成、fit、科学run、新test、実装変更、Git操作はしていない。親側の全308 member/source SHA・24入力float64 SHA一致確認とは独立の、結果内容の解析である。

6条件×4入力seed＝24 encode、2 target＝48解析分布。96 decode波形の2 noise seedを解析的KLの独立反復に数えない。各target内の2 decode seedで全解析配列は48/48一致。保存NPZから計算したKLと保存JSONの最大絶対差は3.46e−16以下（v1/v2計96分布）。

KL_mean = mean[0.5 (m_true−m_hat)²/v_hat]、KL_variance = mean[0.5 {log(v_hat/v_true)+v_true/v_hat−1}]。分母を共有した代数分解であって因果分離ではない。分散膨張による見かけのmean項低下を避けるため、mean MSEも併記する。

## 次の一変更の判断

限定された表現実験をもう一段進めるなら、**次はC4の局在×周期分散相互作用だけ**を優先する。C5の大きな誤帰属は解消し、既存証拠で残る具体的なモデル不適合がC4の局所形状だからである。gain辞書の細分化・event数増加・F0/VUV・未知Hを同時に広げない。C5の微小残差を0に近づけるための追加最適化は優先しない。

一方、自然音声で役立つかという問いでは、未知位相・未知filter、非定常F0/VUV、窓接続の方が大きな未検証仮定である。C4改善を済ませれば自然品質を主張できる、という順序保証はない。これは「次の限定モデル変更」の推奨であり、自然音声採用や追加実験の実施承認ではない。本解析で新しい条件や必須テストは追加していない。
