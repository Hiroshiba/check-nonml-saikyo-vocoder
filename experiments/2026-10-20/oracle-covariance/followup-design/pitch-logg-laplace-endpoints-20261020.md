# 既存 hyper-g の log-g Laplace：両端で残る近似差

2026-10-20。紙上の独立導出。既存値 δ=3、N=400、d=2K、K=1,…,10 を用いる。数値評価、コード実行・import、tests、新しい run、prior 採用、Git変更は行わない。既存500組BMAの条件も変更しない。

## 0. 結論

r=0 の提案式は正しい。r→1 でも exact BF と Laplace BF の発散の冪は一致するが、有限で K に依存する乗法差が残る。両端の Laplace/exact 比は1未満であり、この K 範囲では K とともに増加することまで解析的に示せる。ただし中間の全 r で同じ大小関係が成立するとは本書では証明していない。

この差は全候補・H0で共通の定数ではなく、状態正規化によって一般には消えない。現在観測されている F0 誤差の原因がこの近似だという因果的主張、誤差率の定量化、exact への置換による改善保証はしない。

## 1. 対象の exact 積分と近似

前提文書 pitch-hyperg-laplace-correspondence-20261020.md を全文読取りした。同文書が一次資料・固定ソースで確認した δ=3 と log-g Jacobian の対応を前提にし、その後の端点解析を独立に行う。記号は

 a=N/2=200,
 c=(d+δ)/2=K+3/2,
 q=c−1=K+1/2,
 p=a−c+1=a−q=399/2−K,
 k=(δ−2)/2=1/2,
 ε=1−r.

p,q>0、p+q=a、指定 K 範囲では p>q。a−c=p−1>0 でもある。

 B_exact(r)=k∫₀∞ (1+g)^(a−c)(1+εg)⁻ᵃ dg.

z=log g、dg=g dz を含めた log integrand は

 h(z)=log k+z+(a−c)log(1+eᶻ)−a log(1+εeᶻ).

 h′=1+(a−c)g/(1+g)−aεg/(1+εg),
 −h″=aεg/(1+εg)²−(a−c)g/(1+g)².

唯一の正の停留点を ĝ=e^ẑ とし、

 B_L(r)=exp[h(ẑ)]√(2π/[−h″(ẑ)])

を今回の Laplace 値と定義する。g 密度の mode を使う近似ではない。0≤r<1 では h′ の分母を払った二次式は定数項1、二次係数−εq<0で、正根は一つ。h は両端で−∞となるため、その根が大域的な最大点である。

## 2. r=0：提案された式の確認

ε=1 なので a が消えて

 h(z)=log k+z−c log(1+eᶻ),
 B_exact(0)=k/(c−1)=1/(2K+1).

停留点と曲率は

 ĝ=1/(c−1)=1/q,
 −h″(ẑ)=(c−1)/c=q/(q+1).

したがって

 B_L(0)=k/q × [q/(q+1)]^(q+1) √[2π(q+1)/q],

 ρ₀(K)=B_L(0)/B_exact(0)
       =[(c−1)/c]^c √[2πc/(c−1)]
       =√(2π)[q/(q+1)]^(q+1/2).

提案式と一致する。log BF の差は log ρ₀(K) である。

### 大小関係と K 依存：数値評価なし

v=1/(2q+1)∈(0,1) とすると

 (q+1/2)log(1+1/q)=atanh(v)/v
                  =1+v²/3+v⁴/5+⋯>1.

従って ρ₀(K)<√(2π)/e<1。最後の定数不等式も解析的なもので、小数評価はしていない。例えば π<22/7 と e>1+1+1/2+1/6 で十分。

q が増加すると v が減少し、この正項級数は厳密に減少するので ρ₀(K) は厳密に増加する。したがって全 K に共通の誤差定数ではない。また r=0 の比は N に依存せず、「N=400 が大きいからここで Laplace が exact になる」とは言えない。

r=0 は J=0 の意味であって、必ずしも y=0 ではない。全零窓に対する現行の energy-floor/skip の判断とは別の代数上の点検である。

## 3. r→1：exact 側の主要項

前の独立導出で確認した不完全 beta 表示を用いると、0<r<1 で

 B_exact(r)=k r⁻ᑫ ε⁻ᵖ Bᵣ(q,p).

p,q>0 なので r↑1 に対して Bᵣ(q,p)→B(q,p)。よって

 B_exact(r)∼k B(p,q) ε⁻ᵖ,
 log B_exact(r)=−p log ε+log k+log B(p,q)+o(1).

ここで B(p,q)=Γ(p)Γ(q)/Γ(p+q) は完全 beta。指定範囲では p>0 なので r=1 そのものの積分は発散する。

固定 λ>0、有限 y では r=J/(T+λ)<1 である。したがって r→1 は形式的な境界解析であり、有限振幅の完全 fit が r=1 になるという主張ではない。例えば fit を保ちつつ振幅を増す極限では接近できるが、今回その入力生成・計測は行わない。

## 4. r→1：Laplace 側の主要項

x=εg、s=log x=z+log ε とする。h は

 h=log k−p log ε
   +log x+(p−1)log(ε+x)−a log(1+x).

ε↓0 の局所極限は

 h+ p log ε−log k → p log x−a log(1+x).

停留点の二次式を x で書くと

 −q x²+[(a−1)r+1−q]x+ε=0.

正根の極限は x̂→p/q。この根は正で有限な極限を持つため、上の局所関数とその曲率の極限をそのまま評価できる。

 ĝ∼p/(qε),
 −h″(ẑ)→pq/a.

従って

 B_L(r)∼k ε⁻ᵖ (p/a)ᵖ(q/a)ᑫ √[2πa/(pq)].

両者の比と log 差は

 ρ₁(K)=lim(r↑1) B_L(r)/B_exact(r)
       =[(p/a)ᵖ(q/a)ᑫ √(2πa/(pq))]/B(p,q),

 log B_L(r)−log B_exact(r)→log ρ₁(K).

発散の冪 p は一致するが、そのことだけで相対誤差が0になるわけではない。log-g の mode は右へ移動する一方、曲率は有限な pq/a に留まり、単に r→1 にしただけで無限に鋭い Gaussian peak ができるわけでもない。

### 比が1未満で K 依存であること

正の x に対する Binet の厳密な Gamma 表示を

 log Γ(x)=(x−1/2)log x−x+(1/2)log(2π)+R(x),
 R(x)=2∫₀∞ arctan(t/x)/(exp(2πt)−1)dt

と書く。[NIST DLMF §5.9, 式5.9.10](https://dlmf.nist.gov/5.9.E10)でこの恒等式を確認した。ここでは数値評価にも漸近級数の打切りにも使わず、正値性だけを利用する。

代入により正確に

 log ρ₁=R(a)−R(p)−R(q).

R(x)>0 で厳密に減少するため、a>p,q から log ρ₁<0、すなわち ρ₁<1。

さらに積分を微分すると R′(x)<0、R″(x)>0。p=a−q なので

 d(log ρ₁)/dq=R′(p)−R′(q)>0   （p>q）.

従って指定 K 範囲で ρ₁(K) も厳密に増加する。これは端点での符号と次数依存の証明であり、誤差の小数値や中間 r の一様 bound は求めていない。

## 5. 状態正規化で何が消え、何が残るか

同じ予測状態質量 w₀,wⱼ を固定し、H0のBFを1、候補 j=(f,K) の exact BF を Bⱼ とすれば

 Pⱼ/P₀=wⱼBⱼ/w₀.

Laplace BFが ρⱼBⱼ なら

 (Pⱼ/P₀)_L =ρⱼ(Pⱼ/P₀)_exact,
 (Pᵢ/Pⱼ)_L =(ρᵢ/ρⱼ)(Pᵢ/Pⱼ)_exact.

正規化分母は odds から消えるが、ρ は消えない。仮に全 H1 セルが同じ ρ でも、H1内の条件付き分布では相殺できる一方、H0との odds には残る。今回の端点では ρ 自体が K に依存するので、K間でも相殺しない。

同じ K、同じ r の候補同士なら同一の近似因子なので相殺する。しかし通常は f ごとに r が異なる。両端の結果だけで全 f/K の順位変化を予言することはできない。

時間遷移を通す場合、近似差が過去の posterior と後続の予測質量にも入る可能性がある。この節の単一frame・共通 w の関係を、そのまま filtered F0列の差の公式と呼ばない。

## 6. 五つの仮想視点による点検

一人の導出を五視点で点検したもので、独立五名の検証ではない。

1. **測度担当**：「r=0 の mode は prior の mode と違うのでは？」→ 正しい。対象は Jacobian g を含む log-g integrand。g密度の mode に置き換えると別近似になる。
2. **端点担当**：「r=1 を代入すれば十分か？」→ 不可。exact積分は発散し、modeも∞へ動く。εg に再スケールして両者の主要項と比を導いた。
3. **近似担当**：「両方同じ冪で発散するなら誤差は消えるか？」→ 消えない。ρ₁は有限で1未満。r=0でもρ₀≠1であり、Nの大きさだけでは保証できない。
4. **状態担当**：「全状態で正規化すれば近似差は無害か？」→ H0とのoddsにそのまま残り、K依存なので次数間でも一般に相殺しない。ただし実際の出力変化の大きさは未評価。
5. **批評家**：「現在の F0 誤りを説明し、exact実装に替える根拠になったか？」→ 否。確認したのは理論上の両端の近似差だけ。観測された誤りとの因果関係、全rの誤差、数値実装の安定性、品質改善は未確認。変更・採用の許可にもならない。
