# 保存済み固定2周波数による exact BF 反事実比較：最小紙上計画

2026-10-20。対象：Hiroshiba/check-nonml-saikyo-vocoder。

## 0. 結論と停止範囲

保存済みの f* / 2f* × K=1..10 の同じ cod を使えば、次の三段階は数学的に計算可能である。

1. 各固定セルの exact hyper-g と log-g Laplace の logBF 差。
2. 同じ K での2周波数間 odds 補正。
3. 旧 prior を凍結し、Kを周辺化した2周波数間の conditional odds、および各周波数内の条件付き K 分布の変化。

他周波数とH0の正規化項は条件付き比から消えるので、全gridのexact BFがなくても第3段階まで定義できる。一方、全grid MAP、全gridでのF0質量、VUV/H0、exact方式の再追跡は導けない。旧filtered priorは旧近似で作られた履歴依存の量であり、凍結比較を「exact filtered結果」と呼ばない。

目的は近似誤差がどの候補・次数・重み付けに現れるかを切り分けることだけ。音質改善、F0精度改善、新方式採用、原因の唯一性を判定しない。

本作業は紙上設計と保存のみ。新測定、コード実行、import、tests、Git変更、外部送信は行わない。別途進行している N=400/K=1..10/δ=3 のスカラー検証の結果を先取りせず、309frameへ新BFを適用していない。

## 2. 主対象は固定セル、旧MAPは補助

frameをt、固定周波数をa∈{1,2}、次数をk∈{1,…,10}とし、保存codをr_takと書く。rとρなど別診断量を混同しない。

主対象は全eligible frameの事前固定2×10セル。309×20=6180は最大のセル数であり、有効性・欠測を未確認のまま「6180有効観測」とはしない。また独立反復数ではない。frameは重なり窓・履歴を持つ。

local/filtered joint MAPの保存点は旧方式で選択された点である。対応f_index、K、codが確定した点だけ補助として扱い、「旧MAP地点の近似誤差」と表現する。新方式のglobal MAP探索を代用しない。固定セルとの重複は重複計上しない。MAP点における一つのKの値から、その周波数の全K周辺化はできない。

### 同じrを守るための成立条件

- exactとLaplaceの双方へ同一の保存float64 codを入力する。J/(energy+.002)は整合性監査用であり、丸めが違う再計算値へ無断で差し替えない。
- fitの意味は保存契約で確認する。名称だけからfit=J/energyなどと仮定してrの代用にしない。
- N=400、d=2k、δ=3、white/DCなし、元regularizationと定数を保つ。
- 非有限値、範囲外、欠測、元のskipは別扱い。clipして救済しない。clip/mask履歴がないことを根拠に任意の値を有効扱いしない。
- 現行のenergy/N<1e−10欠測契約を勝手にH0観測へ変換しない。保存BFがあっても元のupdate対象かを区別する。
- 元の入力・候補・実装freezeとの対応が確定しない点は帰属保留。全gridのlogBFからrを逆算しない。観測波形から再投影もしない。

有効なprojectionで0≤J≤energyかつregularizationが正なら0≤r<1となるが、これは保存値の実測監査を省略する理由ではない。

## 3. セル単位の比較：誤差の所在を二つに分ける

δ=3に対応するexact参照は既存導出より

    B_E(r;k) = [1/(2k+1)] ₂F₁(200,1;k+3/2;r),
    ℓ_E = log B_E.

ℓ_L(r;k)はJacobianを含むlog-g Laplace、ℓ_Sは保存済み旧logBFとする。exactスカラー参照の検証が完了するまでは、ℓ_Eを数値的に信頼できると認定しない。

差を

    η_tak = ℓ_L(r_tak;k) − ℓ_S,tak,
    δ_tak = ℓ_E(r_tak;k) − ℓ_L(r_tak;k),
    Δ_tak = ℓ_E(r_tak;k) − ℓ_S,tak = δ_tak+η_tak

に分解する。

ηは保存値と現行kernel再現の整合性、δは同じr・同じkernelでの積分近似差、Δは保存値から置換した総差である。ηが説明できない場合、Δ全体をLaplace近似誤差と呼ばない。元の計算順・丸めなどの差と数学的近似差は別である。

保持する最小字段は系列/frame、f_index、K、保存cod、energy、元ell、再現Laplace、exact参照、η/δ/Δ、参照精度・有効性・保留理由。J/fitは入力整合性の出典に残す。ここでは数値表を生成しない。

r=0ならexact B=1/(2k+1)という解析端点はあるが、新しい端点入力を309frameへ混ぜない。スカラー検証のテスト内容も本計画で増やさない。

## 4. 最小反事実A：同一Kでの2周波数差

同じt,kでの観測logBF差を

    d^S_tk = ℓ_S,t1k−ℓ_S,t2k,
    d^E_tk = ℓ_E,t1k−ℓ_E,t2k

とすれば

    d^E_tk−d^S_tk = Δ_t1k−Δ_t2k.

両方に同じ補正があれば差は変わらない。大きな絶対BF差がそのままoctave間の判別変化になるとは限らない。

旧prior質量π_takを固定し、両セルが正のsupportを持つなら

    log O^b_tk = log π_t1k−log π_t2k + d^b_tk,
    b∈{S,E}.

したがって同じprior下のlog odds補正もΔ_t1k−Δ_t2k。これは「候補がこの2セルのどちらか、次数k」という条件付き比較であり、全候補のposterior massではない。片側priorがゼロならそのセルはBFの有限な変更だけでは復活しない。両方ゼロなら条件付き比は未定義。

## 5. 最小反事実B：全K周辺化、旧prior凍結

### 5.1 固定周波数ごとの重み付きscore

保存priorの一つの指定系列πを固定し、

    A^b_ta = log Σ_(k=1)^10 π_tak exp(ℓ_b,tak)
           = LSE_k(log π_tak+ℓ_b,tak)

とする。候補集合を S={f*,2f*}×{1,…,10} とすると

    log O^b_t = A^b_t1−A^b_t2,
    P^b_t(f* | (f,K)∈S, π_old)
       = exp[A^b_t1−LSE(A^b_t1,A^b_t2)].

H0と他周波数は条件付けで除外される。どちらかの周波数を選ぶ確率は計算できても、「その集合に入る確率」P((f,K)∈S)はexact全gridなしでは分からない。H1を指定するだけでは他の459周波数が残るため、P(f*|H1)とも違う。

上のπは旧方式の実現priorである。A^Eはそのpriorの下で20セルの観測BFだけをexactに置換した反事実scoreであり、exact方式が過去から生成したpriorではない。

### 5.2 次数の重みが補正をどう変えるか

各周波数内の旧K条件付き分布は

    w^S_tak = π_tak exp(ℓ_S,tak−A^S_ta).

従って

    c_ta = A^E_ta−A^S_ta
         = log Σ_k w^S_tak exp(Δ_tak),
    log O^E_t−log O^S_t = c_t1−c_t2,
    w^E_tak = w^S_tak exp(Δ_tak−c_ta).

この式は保存BFとの差Δを用いる恒等式。ηが無視できると確認された場合にのみ、その変化を積分近似差δの寄与と解釈する。

重要なのはcがΔの単純平均でも、最大KのΔでもないこと。K依存の補正により、周波数内の次数質量が再配分され、その結果として周波数間oddsも変わる。

    min_(k:w^S>0) Δ_tak ≤ c_ta ≤ max_(k:w^S>0) Δ_tak.

これは数値実行なしの範囲チェックになる。ΔがKによらず一定ならw^E=w^Sで、周波数scoreだけがその定数分動く。さらに両周波数で同じ定数ならpair oddsも変わらない。

### 5.3 「次数を周辺化したBF」の命名

m_ta=Σ_kπ_tak>0、ρ_tak=π_tak/m_ta とおけば

    Bbar^b_ta = Σ_kρ_tak exp(ℓ_b,tak),
    A^b_ta = log m_ta + log Bbar^b_ta.

Bbarは指定した条件付きK priorによる混合BF。Aは周波数prior massも含むscoreであり、BFそのものと呼ばない。旧filtered priorのρは履歴に依存する。無断でK一様に置換して「同じpriorの比較」とはしない。

localの既存一様セルpriorを使う場合は、既存契約が確認できたときだけρ=1/10とできる。prior-freeなΣ_k BFをposteriorと呼ばず、一様混合なら1/10の定数を保持する。共通定数がpair oddsで相殺することと、絶対BFの定義で落としてよいことは別である。

## 6. priorと履歴を混ぜない最小読出し

主読出しは、保存された旧filtered prediction priorを各frameで凍結した第5節のpair oddsとK分布。名称は「旧filtered prior固定・20セル観測BF置換」とする。

既存local priorの定義と保存対応が確定している場合だけ、同じ20セルを既存local priorでも読む補助対照を設け得る。新しいpriorは作らない。単純な同K BF差はpriorなしで第4節に残すため、local条件が曖昧でも主たる近似差の分析は可能である。

系列間で同じ観測・同じ保存rの固定セルが確認された場合、exactセル補正δも同じになるべきである。一方、priorの異なる履歴間ではw^Sが違うため、次数周辺化補正cが違ってよい。これを「exact BF自体が履歴に依存した」と誤解しない。

同じtransition規則と同じ実現prior列は別物である。exact BFで過去posteriorを更新すれば、その後のprior、H0、memory更新の判定が変わり得る。旧prior列を固定した結果から、その再帰的変化を外挿しない。

## 7. できること／できないこと

### この保存範囲で定義できるもの

- 固定20セルの同一rに対するexact/Laplace差と、保存ell再現差の分離。
- 同Kの2周波数BF比、指定旧prior下の条件付きodds。
- 全10次数の重み付き周辺化、その2周波数conditional odds、周波数内のK条件付き分布。
- 旧MAP点における点wise補正。ただし選択済み補助点。
- 同一rを持つ既存系列間の補正の一致性と、prior重みを介する相違の代数的切分け。

### この保存範囲では主張できないもの

- exact方式の461×10全セルBF・posterior、新しいglobal joint MAP、全周波数のK周辺分布。
- 全状態正規化したexact H0/VUV、P(f*|H1)、f*や2f*の無条件質量。
- exact方式の自己整合的なfiltered軌跡、switch時刻、memory更新、過去履歴の解消。
- 自然音声のF0精度、octave error率、voicing精度、音質、改善・採用判断。
- 旧MAPの補正が大きいという理由だけによる「Laplaceが誤りの原因」の断定。

他gridを旧Laplaceのままにし20セルだけexactへ置換した「hybrid全grid分布」は、旧全gridBF・prior・必要なH0質量が揃えば数学的には定義可能である。しかしそれはexact全gridではなく、任意の部分置換設計である。今回の最小比較には採用せず、そのhybrid H0やMAPをexact結果として報告しない。

条件付きpair oddsではH0質量がなくてもよいが、H0を含む正規化には必要である。全gridのrがなくても旧posteriorを再計算できることは、新exact posteriorを再計算できることを意味しない。

## 8. 数値精度と集計の事前境界

別途のスカラー検証が、対象r領域とKにおいてexact参照を十分に検証したことが前提。今回のrがその検証範囲外なら自動的に外挿せず保留する。値をクリップしたり、参照法の失敗を−∞やH0へ置き換えない。

将来の判定には検証側が与える数値誤差根拠を用い、ここで恣意的な「小さいlogBF差」の閾値は作らない。各ℓ_Eの絶対誤差がε以内なら、LSEで作るA_taの誤差もε以内、pair log oddsの誤差は高々2εである。異なる上界なら両側の最大誤差を加える。旧ell・再現Laplace側の誤差も比較目的に応じて含める。

符号反転・条件付き勝者変更は数値誤差範囲から分離できるときだけ明確とし、境界は未確定と表示する。小差を0に丸めて順位を確定しない。

最小出力案：

1. セル表：全eligible固定セルのη/δ/Δと参照精度状態。
2. frame表：同K差の補正、K周辺化前後のpair log odds、c_t1/c_t2、各周波数内K分布の変化。
3. 保留表：欠測、入力不一致、参照未検証、ゼロsupport、旧MAP補助点の選択性。

系列・Kごとの記述的範囲や最大差は報告できるが、309frameや6180セルを独立サンプルとして標準誤差・p値を出さない。同じ窓の一致確認を独立再現数に数えない。事後に差の大きいframeだけを主対象へ変更せず、例示は全対象の中での位置を示す。

## 9. 五仮想視点による二往復の反復検討

一人の設計者による仮想レビューであり、独立五名の査読や実測ではない。

### 第一往復：計算対象を絞る

1. 保存データ担当：「全logBFがあるのでexact全gridに直せる」。近似担当：「元r/Jは20セル等しかない」。応答：逆算・再投影をせず、固定20セルを主対象に限定した。
2. 近似担当：「exact−保存ellがそのままLaplace誤差」。批評家：「元kernelの再現差も含む」。応答：η、δ、Δの三つを分け、一致が未確認なら帰属保留とした。
3. 周辺化担当：「各Kの差を平均すればF0 oddsの差になる」。状態担当：「旧K重みが不均一でexpも非線形」。応答：c=logΣw_old expΔを導出し、次数再配分も出力対象とした。
4. 状態担当：「旧filtered priorを使えばexact trackerになる」。批評家：「そのpriorは旧BF履歴で作られた」。応答：旧prior固定の反事実と命名し、再帰の再計算と分離した。
5. 批評家：「global正規化が不明ならpair比較もできない」。周辺化担当：「同じ制限集合に条件付けた比では正規化が相殺する」。応答：pair conditional oddsは可能、集合自体のmassやH0は不可と切り分けた。

### 第二往復：反例と停止条件

1. 保存データ担当：「Jとenergyからrを再計算すれば十分」。近似担当：「元float64 codとの丸め差を混ぜる」。再応答：保存codを共通入力、比の再計算は監査のみ。停止条件：入力同一性が不明なセル。
2. 近似担当：「各セルの補正が大きければoctave判定も変わる」。周辺化担当：「共通補正は相殺し、K依存では重みが効く」。再応答：絶対補正・同K差・周辺化後差を別出力。棄却条件：絶対差だけから順位変更を予告すること。
3. 周辺化担当：「2周波数conditional probabilityが上がったのでF0確率が改善」。批評家：「他候補やH0へ質量が移る可能性が未評価」。再応答：P(f*|S)をP(f*)やP(f*|H1)と呼ばない。棄却条件：条件付けを省略した確率表示。
4. 状態担当：「旧MAP点もexactで再評価できるから新MAPを判定できる」。保存担当：「未評価候補が全gridに残る」。再応答：旧選択点の補助診断に留める。棄却条件：旧MAP補正からglobal argmaxを認定すること。
5. 批評家：「20セル置換のhybrid H0を出せば採用判断に使える」。他役：「混合方式であり科学的問いが変わる」。再応答：hybridは数学的可能性だけ記載し最小案から除外。停止条件：全grid・VUV・時系列・音質への主張拡大。

## 10. 次段階への引渡しと今回の完了点

最小案は、同じ保存rに対するセル差の整合性を先に確定し、その差を旧prior固定の2周波数conditional oddsとK分布へ伝播させること。新しいpriorや時間モデルを作る必要はない。

実施前に必要なのは、別途スカラー参照の検証完了、既存artifact字段と候補順の対応、eligible/skip/supportの契約、数値誤差上界の確認である。ここでは309frameの数値適用を開始せず、追加の測定・実装・実験・外部送信も行わない。

本計画の成果は、保存範囲から定義できる反事実と、欠けた全grid情報が必要な主張の境界を明文化したことに限る。
