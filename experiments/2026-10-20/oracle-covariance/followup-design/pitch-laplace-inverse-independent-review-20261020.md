# log-g Laplace 逆写像の独立レビュー

2026-10-20。対象：`pitch-laplace-inverse-identifiability-20261020.md`。
手計算・記号推論と対象文書の読取のみ。コード実行/import、数値評価・スイープ、tests、保存ログへの適用は行っていない。

## 結論

**既存 a=200、c=K+3/2、K=1..10 の条件では、理想解析式 F(r)=log B_L(r) の全域厳密単調増加、一意逆写像、両端の逆感度は成立する。修正が必要な代数誤り・不足条件は見つからなかった。**

ただし、これは実装済み helper 自身の浮動小数点単調性の証明でも、保存 logBF から元 binary64 r を常に復元できるという証明でもない。本文はこの区別を適切に述べている。離散逆像が一点の場合の条件付き復元可能性を認めているため、「いかなる場合も bit 同一復元が不可能」と強く言い換えてはいけない。

## 1. mode とパラメータ化

q=c−1、w=a−c、p=a−q=w+1、ε=1−r とする。
今回 q≥3/2、w>0、p>2、ε∈(0,1]。

h_z=0 に正の分母 (1+g)(1+εg) を掛けると

    1+[p−(a−1)ε]g−qεg²=0。

定数項が正、二次項係数が負なので正根は唯一。g→0 で h_z→1、g→∞ で h_z→−q<0 であり、この根は唯一の最大点である。r=0 では ĝ=1/q、u=1/c。ε↓0 では εĝ→p/q>0、従って u↑1。

u=ĝ/(1+ĝ)、v=εĝ/(1+εĝ) とすれば mode 方程式は av=1+wu。A=u(1−u)、D=v(1−v) に対し

    κ=aD−wA=1+wu²−av²。

また logit(v)=log ε+logit(u) を r で微分すると

    (w−aD/A)u′+aD/ε=0、
    u′=aAD/(εκ)>0。

mode 上で v=(1+wu)/a を代入して κ を u の式にすると

    κ_u=2w(cu−1)/a。

従って本文の u パラメータ化と微分は整合する。

## 2. 全域 F′>0 の代数照合

包絡定理で mode の移動に由来する h_z ẑ′ は消え、

    F′=av/ε−κ_u u′/(2κ)
       =(av/ε){1−w(cu−1)u(1−u)(1−v)/(aκ²)}。

x=cu−1∈[0,q) と置くと、

    u=(x+1)/c、1−u=(q−x)/c、
    1−v=(aq−wx)/(ac)、κ=(aq+wx²)/(ac)。

従って角括弧の分母を払った差は

    P=c(aq+wx²)²−wx(x+1)(q−x)(aq−wx)。

独立に積を展開して次を確認した。

    P=ca²q²−waq²x
      +wq[a(q+3)+w]x²
      +w[aq+w(q−1)]x³
      +qw²x⁴。

今回 q≥3/2、w>0 なので二次以上の係数は正。一次の負項は x<q を用いて

    ca²q²−waq²x ≥ aq²(ca−wq)
                       =aq²(a+cq)>0

と評価できる。ここで c−q=1、w=a−c を用いた。
したがって P>0。分母 c(aq+wx²)² と av/ε も正なので F′>0。

端点も含め F は [0,1) で連続、r=0 で有限、r↑1 で発散するため、値域は正確に [F(0),∞)。範囲内の有限値に一意の逆像を持つ。F(0) より小さい保存出力の逆像はなく、r=0 への clip は正当化されない。

この証明は F 自体の単調性であり、F−H の単調性・符号を与えない。

## 3. 逆感度の両端

### r=0

u=v=1/c、κ_u=0、ε=1 より F′(0)=a/c。
mode は r=0 の近傍で滑らかで κ>0 のため、一方向の逆関数展開

    r=(c/a)(ℓ−F(0))+O((ℓ−F(0))²)

が成立する。r=0 で相対条件数を通常の有限値として扱わない本文の注意は妥当。

### r↑1

s=εĝ と置くと mode 方程式は

    qs²−[p−(a−1)ε]s−ε=0。

ε=0 の正根 s=p/q は単純根なので、s は ε=0 まで滑らかに延長できる。曲率も κ→pq/a>0。

    F=−p log ε+log k
      +log s+(p−1)log(ε+s)−a log(1+s)
      +(1/2)log(2π/κ)

に代入すると、残りは滑らかであり、

    C_L=log k+p log(p/a)+q log(q/a)
        +(1/2)log[2πa/(pq)]

を得る。従って F=−p log ε+C_L+O(ε) と F′=p/ε+O(1) がともに正当化される。単に O(ε) の式を形式的に微分しただけではなく、滑らかな再スケール根が微分の根拠となる。

よって dr/dℓ∼ε/p、d log ε/dℓ∼−1/p は正しい。

## 4. exact 側と換算感度

r<1 の各固定点では g/(1+εg)≤1/ε なので、積分の微分を局所的に支配できる。従って

    H′=a E_r[g/(1+εg)]>0。

r=0 で基準密度は (1+g)^−c に比例する。u=g/(1+g) の平均は 1/c なので H′(0)=a/c=F′(0)。

near-1 の exact 積分を g=x/ε と変換すると

    B=k ε^−p A(ε)、
    A(ε)=∫₀∞(ε+x)^(p−1)(1+x)^−a dx。

今回 p>2 なので A と A′ は ε↓0 で有限に延長でき、A(0)>0。例えば 0≤ε≤1 における微分被積分関数は定数倍の (1+x)^−q−2 で支配できる。したがって

    H′=p/ε−A′(ε)/A(ε)=p/ε+O(1)。

ゆえに G′=H′/F′ は両端で 1 に収束する。r の絶対逆感度が near-1 で小さいことを、換算 exact logBF の絶対不確かさも消えることと混同しないという本文の解釈は正しい。

## 5. 丸め cell と同定可能性

条件付きの論理は妥当である。

1. 正確な実数 F(r) の最終一回の binary64 丸めだけが誤差源なら、保存値の丸め cell と [F(0),∞) を交差させ、その単調逆像を取れる。
2. tie の包含を無視した閉区間は外側区間として安全。zero/subnormal/overflow の特例を通常の中点式で一律処理しない注意も適切。
3. 有限精度 root finder の一点を保証区間に昇格できない。区間端の実評価には評価誤差も含む検証が必要。
4. 元 r が実数なら通常は区間までしか定まらない。元 r が binary64 なら離散集合との交差が一点の場合に限る条件付き一意性があり得る。
5. 既知の加法誤差 e∈[e₋,e₊] に対する [b₋−e₊,b₊−e₋] は正しい包含変換。不明な helper 内部誤差・clip・offset・文字列丸めを半 ulp で代用できない。
6. H も増加するので、保証 r 区間が得られた場合の H の区間換算は正しい。元 J,T や波形の一意性は導かれない。

## 6. 最終判定

代数、正値条件、端点、丸め誤差の条件付けはいずれも確認できた。本文の結論をそのまま支持する。

結果の短い表現は「理想解析式の逆写像は全域で一意。しかし実ログから元 r の bit 同一性や非自明な保証区間を得られるかは、別途の計算・保存経路の誤差契約に依存する」とするのが適切。

既存 artifact 監査の「全候補 r の保存未確認」という結論は変更しない。今回の単調性証明は、その保存不足を埋める数値的逆算の実施やモデル採用を許可しない。
