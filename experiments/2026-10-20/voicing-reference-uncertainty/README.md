## 報告値

[保存済みヘッダー報告の追補](mocha-fsew0-header-count-addendum-20261020.md)は、Cloud担当の短い報告の記録です。460組すべてで「.larの標本数 − .wavの標本数」は+15〜+20標本。先頭fsew0_001は35,495／35,513標本で+18標本です。保存されたヘッダー情報には、時刻を明示するフィールドはなかったとの報告です。

既報の16 kHzでの0.9375〜1.25 msは長さ差の換算であり、同期ずれを測った値ではありません。
