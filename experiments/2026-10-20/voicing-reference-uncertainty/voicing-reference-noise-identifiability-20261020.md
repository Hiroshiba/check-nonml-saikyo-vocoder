# 不完全なEGG由来VUV参照から何を識別できるか

2026-10-20 UTC。紙上整理のみ。PML、既存研究、データ集合は変更しない。

## 結論

- EGG由来の二値参照にBrier/log scoreを直接付けて確かめられる対象は、原則として**その参照が陽性となる確率**であり、生理的VUV確率ではない。
- 潜在VUVへ戻すには、VUVの定義に加えて参照誤りの識別可能なモデルが必要。誤分類率が既知なら条件付きで逆算でき、範囲だけなら識別集合に止まる。未知率を自然音声だけから必ず分離できるとはいえない。
- 460対はCloudのheader監査報告のみで、原表は親未照合、波形評価なし。誤分類率、VUV校正、残留同期誤差は**未確認**。本稿はそれらを推定しない。

既存の[確率的F0/VUVと絶対Hz編集の契約](https://github.com/Hiroshiba/check-nonml-saikyo-vocoder/blob/main/experiments/2026-10-20/clock-event-variance/probabilistic-pitch.md)は、候補score・モデルposterior・自然音の校正を分けている。本稿の追加点は、最後の「校正」が不完全参照を使う場合の識別限界だけである。方式比較、payload、target編集の議論は繰り返さない。

## 1. 最初に別の変数として定義する

- **Z∈{0,1}**：あらかじめ定義した時間支持における対象VUV。唯一の自明な生理的真値が存在すると仮定した記号ではない。
- **G∈{0,1}**：指定したEGG処理・判定規約から得る観測proxy。EGG信号そのものでも、完全閉鎖の直接観測でもない。
- **X**：同じ時間支持に対応する音声特徴。p(x)=P(Z=1|X=x)、q(x)=P(G=1|X=x)。

何をZとするかは先に固定する。音響的な規則的反復、声帯振動の存在、接触イベントの存在、完全閉鎖、単一F0の定義可能性は別の事象である。無音・摩擦・不規則発声を一律にZ=0とする規約も、振動を重視する規約と同じではない。とくにイベントの有無と周期継続の判定は窓長にも依存する。ここではどれかを採用せず、参照との意味対応を未確定のまま残す。

Herbstらは、同期した摘出イヌ1喉頭の画像とEGGから、接触・離開が有限の時間にわたり、dEGGピークが画像上の声門閉鎖・初期開放と常に一致するわけではないと報告した。これは**接触proxyを閉鎖イベントそのものと同一視しない**根拠であり、ヒト自然発話のVUV誤分類率や共通補正量ではない。[一次研究の著者所属大学掲載抄録](https://ucrisportal.univie.ac.at/de/publications/glottal-opening-and-closing-events-investigated-by-electroglottog/)

## 2. class-conditional errorを仮定した場合の導出

固定した母集団・時間対応の下で、次を**仮定**する。

    G ⟂ X | Z
    α=P(G=1|Z=0), β=P(G=0|Z=1), d=1−α−β.

全確率公式から

    q(x)=α[1−p(x)]+(1−β)p(x)=α+d p(x).                 (1)

従って既知のα,βでd≠0なら

    p(x)=[q(x)−α]/d.                                 (2)

- d>0ならqとpの大小順は一致するが、確率値と閾値は一致しない。p≥tはq≥α+dtに対応する。
- d<0でも**率が既知なら可逆**で、順序と不等号は逆転する。
- d=0ならq(x)=αであり、この観測チャネルはZについて情報を持たない。変動するqが確認されれば、この定数誤りモデルとは両立しない。

既知率でも、qはαと1−βを端点とする区間内でなければならない。範囲外の観測を黙ってclampして整合と呼ばない。qの有限標本推定誤差とモデル不適合は別に検討する必要がある。|d|が小さいと逆算は不安定になり、点識別は精密推定を意味しない。

固定した予測r=r(X)についても、同じ仮定なら

    E[G|r]=α+d E[Z|r].                               (3)

潜在校正E[Z|r]=rに対応するproxy側の条件はE[G|r]=α+drであって、E[G|r]=rではない。しかも信頼度別の平均一致は、すべてのXでr(X)=p(X)という主張より弱い。

## 3. 未知率と、範囲だけが分かる率

**未知率：一般には非同定。** たとえば順向きd>0まで仮定しても、qが非定数で、α≤ess inf q、β≤1−ess sup qを満たす複数の(α,β)が整合すれば、(2)で異なるpを作れて同じ(X,G)分布を説明する。率ゼロを選ぶp=qも一候補にすぎない。従って有声率・潜在確率値・潜在校正・潜在scoreは一般には一意に決まらない。例外的に観測支持や追加仮定でpが一つになる場合まで否定しない。

Scott–Blanchard–Handyは、二群の混入モデルで、異なる観測二群分布、π0+π1<1、相互既約性の条件下に一意な最大除染解を得ることを示している。**未知率なら絶対に不可能**ではない一方、その解が自然発声のZと一致するには仮定の根拠が別途必要。本稿は相互既約性や純粋／極限領域の存在をEGGに仮定せず、推定方式も採用しない。なお同論文のπは観測クラス側の混入割合であり、本稿の前向き誤分類率α,βと数値を混同しない。[原著 §4 Proposition 3](https://proceedings.mlr.press/v30/Scott13.pdf)

**率の範囲Θだけが正当化される場合：** d≠0のモデルに限り、

    Θq={ (a,b)∈Θ : 0≤a,b≤1, 1−a−b≠0,
                    0≤[q(x)−a]/(1−a−b)≤1  a.s. }
    ℙq={ p_(a,b)(·)=[q(·)−a]/(1−a−b) : (a,b)∈Θq }
    I(x)={ p(x) : p∈ℙq }.                           (4)

ℙqが関数全体の識別集合で、I(x)はその点別射影。inf I(x)、sup I(x)で点別の上下界を述べられるが、複数xや集計については**共通の(a,b)が作る同じp∈ℙq全体**で主張を判定する。∏x I(x)から各点を自由に組み合わせてよいわけではない。集合全体で成立する閾値判定や主張だけが頑健に残る。Θqが空なら仮定群が両立しない。Θが整合するd=0も許す場合、その枝ではpに制約が得られない。

これは**仮定に条件付けた識別集合**で、信頼区間ではない。q自体が有限標本からしか分からない場合の不確かさは別に加える。現資料からΘの数値を作らず、範囲付きの潜在校正達成も主張しない。

## 4. proper scoreが保証するもの

二値予測rをGへ直接評価する損失をBrier=(r−G)²、log loss=−G log r−(1−G)log(1−r)とする。条件付き期待値は

    E[Brier|X=x]=q(1−q)+(r−q)²,
    E[log loss|X=x]=h(q)+KL(Ber(q)||Ber(r)).          (5)

よって母集団での一意の最適点はq。**propernessは、誤った観測対象を自動で生理的真値へ変えない。** 有限標本での校正達成も保証しない。これはGneiting–Rafteryのpropernessを本稿の観測変数Gに適用した導出であり、同論文がEGGを論じたわけではない。[原著 §2.1, §3.1 Examples 1,3](https://sites.stat.washington.edu/raftery/Research/PDF/Gneiting2007jasa.pdf)

既知の正しい誤りモデルでd≠0なら、潜在予測rをq_r=α+drに写してGへscoreすることで、r=pを一意の最適点にできる。Brierの最適点からの超過riskはd²(r−p)²になる。**同一母集団・同一定数dでこの写像を使う場合**、候補間の母集団期待Brier riskの順位も潜在Brierの期待risk順位と一致する。有限標本の実測平均順位が一致する保証ではない。一方、proxy log-score差は一般に潜在log-score差の一定倍率ではなく、最適点の一致だけから候補間の集計順位一致を主張しない。どちらも実測された潜在score値と呼ばず、未知／誤った率での写像に保証を引き継がない。

## 5. EGGで特に未解決の仮定

声質・振動様式・信号品質・境界位置などによって誤りがXに依存するなら、恒等式は

    q(x)=α(x)+[1−α(x)−β(x)]p(x)                     (6)

となる。未知の関数α(x),β(x)とp(x)を一つのq(x)から分ける根拠はない。声質U内ではclass-conditionalでも、P(U|Z,X)が変われば全体で定数率にはならない。単一の逆補正は不正当となり、各点でd(x)>0でもX間の順位保存まで失われ得る。これらは今回観測した誤りではなく、無視できると確認していない依存要因である。

参照がuncertain／取得不能で除外されるなら、その選択をMで分ける。残ったデータが制約するのはP(G=1|X,M=1)であり、全対象への校正に戻すには選択に関する根拠が要る。uncertainを0、1、0.5のどれかに自動変換しない。

また、Gの有無だけでP(F0|Z=1,X)の形やoctave質量は決まらない。VUV校正、F0の定義可能性、定義可能な場合のF0分布は別課題。P(voiced)を周期振幅・noise powerに写さない既存契約は維持する。

## 6. 5仮想役・2往復の反証整理

独立研究者の査読や新たな測定ではなく、本稿内の仮想討議。第1往復で案と異議を突き合わせ、第2往復で改訂案へ再反論した。

| 役 | 第1往復：案→異議→応答 | 第2往復：改訂→再反論→判断 |
|---|---|---|
| 統計 | 定数率なら逆算→率も未知→既知と未知を分離 | 範囲で上下界→点ごとに別率を選ぶと緩すぎる→全X共通のΘqを採用 |
| 発声物理 | EGGをVUV参照に→接触・完全閉鎖・周期性が違う→Zを先に定義 | 振動の有無へ限定→不規則発声のF0は別→VUVからF0同定を主張しない |
| 計測 | 同時収録なら同時刻→配布版の時刻対応は未確認→同期の前提を明記 | 同期確認で誤り解消→対象差や検出依存は残る→時間誤差とラベル誤差を分離 |
| 確率評価 | proper scoreなら校正→Gへの校正にすぎない→(5)を導出 | 既知率で写像→潜在score値と同じではない→最適点とscore値を区別 |
| 批評 | 率も音声から推定→識別仮定が追加される→未知率を勝手に確定しない | class-conditionalを標準に→声質依存を消してしまう→説明用の条件付きモデルに止める |

**採用（紙上の条件付き命題）：** (1)–(5)の識別限界、既知率の可逆性、範囲の識別集合、proxyを目標にするproper score。

**棄却：** 「EGG二値旗への校正＝生理的VUV校正」「proper scoreだけで参照誤りを解消」「header一致／同期記述でVUV真値を保証」「未知率を無根拠にゼロや固定値へ置く」。
