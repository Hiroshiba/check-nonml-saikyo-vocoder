# 自作HNMを初代ベースにする

今回の問いは、音声を再現する詳細と、人が変更したい量を分けた非MLエンコーダー・デコーダーを、自作方式として動かせるかである。調波と雑音を分けるHNMを出発点にする。新方式としての独創性や、WORLDを上回る品質を最初から主張するものではない。

ユーザーの今回の指定により、既存の比較対象は **WORLD（Harvest）** のみとする。WORLDがボコーダーであり、括弧内のHarvestはF0解析法を示す。自作方式を初代ベースとして採用する。原音は再合成の正解として別に表示し、ボコーダーの候補には数えない。

## 表現と操作

独自の正規化自己相関でF0を求め、調波の振幅、積分F0に対する相対位相、時間変化する有限帯域雑音PSDを保持する。元波形や残差波形をデコーダーへ渡す経路は設けない。音高編集には固定Hz包絡を使い、ゲイン・時間長の規則も明示する。相対位相を省略した合成や、エンコーダーを経ない手作り表現も対象にする。

ここで意図する共鳴形状の保持や位相の連続性は、測定前の品質保証ではない。低信頼F0や欠測も状態として残す。[5人の提案・応答・再批評と出典](reviews/discussion.md) に、先行例と今回の推論を分けて記録した。

## 表現の単位と容量

F0はHz、時刻は秒、固定周波数格子は513点、調波包絡は正弦波の振幅、雑音PSDは振幅二乗/Hz、相対位相はラジアンで保存する。更新間隔は5 ms、調波の上限は96本。低信頼なF0を0にしたフレーム数も保存する。1秒当たりの配列値はおよそ22.5万個で、低ビットレート符号化を達成した表現ではない。細部省略は相対位相を省略することを指す。

## 比較計画

計画は32入力×2方式の64再合成、5入力×5操作×2方式の50操作、4手作り表現合成である。加えて、110 Hz・220 Hzの既知刺激を使い、細部あり・なしで音高変更が追従するかを調べる。実施件数と失敗数は、結果で確定する。

解析と評価の誤りを共有しにくくするため、自作解析の自己相関とは別に既存YIN系で出力を測り、人工刺激では既知F0と比較する。F0誤差だけでなく、有効数・分母・欠測・誤有声を残す。音高変更によって調波が帯域境界をまたぐことがあるため、帯域エネルギーの完全保持は一律に要求しない。

初代の判断では、数値正常性、ゲイン、長さ、既知F0の編集方向、手作り表現からの合成を確認する。WORLDへの品質優越や20 centなどの品質目安は初代の必須条件とせず、達成しない項目を明示する。

## 実測と採否

64再合成・50操作・4手作り合成・12診断を実行し、処理失敗は0だった。ゲイン・全長・既知F0編集と保存読込が機能する範囲を確認し、初代を採用した。[結果と実音声](results/run-001/index.html)、[採否・改善記録・残る限界](reviews/decision.md)を参照。自然音声2区間のスペクトル誤差中央値では、自作5.638 dB、WORLD 5.537 dBであり、WORLDへの優越は主張しない。

## 残る範囲と次の改善

自然音声は2区間のため、日本語や多話者全体の品質を保証しない。過渡、不規則振動、雑音の周期内変調、位相細部による音高制御漏れ、包絡保持は弱点候補である。表現の知覚的な近さ、知覚語の制御、自然性は未検証として扱う。

実測で弱い箇所を特定し、原因の仮説、5人の往復議論、候補実装、直前ベースとWORLD（Harvest）への比較を繰り返す。初代の採用は研究の終わりではなく、次の改善を同じ条件で測るための出発点とする。
