# WORLD Harvestをベースにした比較

ユーザーの今回の指定により、初代ベースを `world_harvest` に設定した。これは今回の作業判断であり、恒久的なユーザー指示への追加ではない。音質の最良を実験から認定したという意味でもない。

WORLD Harvestで音高を推定し、CheapTrickとD4Cで特徴量を求め、WORLDで合成する。使用するWORLDの版は `c794856b537758a3d300757db2e5e31685a822c2`。他の設定は既存比較と共通で、WORLD DIOとLLSMは既存の比較対象として保持する。以前の正式ベースは未選定なので、削除すべき旧ベース実装はない。

[比較結果と音声例](results/run-001/index.html) を参照。正式ベース自身の行も含め、自己比較の差分は0になる。原音コピーは再合成の参照であり、ボコーダーの候補ではない。

音声例は自然音声2区間と110 Hz調波音の固定先頭最大2秒。方式ごとに区間を選び直さず、音量正規化・クリッピング・サンプルレート変更をしない浮動小数点WAVを保存する。自然音声の操作後の正解波形はないので、原音を操作の正解として採点しない。音声の帰属は [出典と利用条件](../../../data/ATTRIBUTION.md) を参照。

[前回の比較基盤](../comparison-workbench/README.md) は、当時のベース未選定という情報を含めて保持する。今回も自然音声の範囲は2話者各6秒であり、広い分布での品質保証ではない。
