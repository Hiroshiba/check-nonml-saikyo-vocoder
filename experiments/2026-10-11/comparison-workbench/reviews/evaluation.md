# 独立評価担当の調査・設計レビュー

2026-10-11。`USER_INSTRUCTIONS.md` を最上位のユーザー指示として読んだ上で作成した AI の調査記録。ユーザー指示の追加ではない。今回の優先作業は、複数比較対象と比較方法を動く状態にすることであり、最良手法の断定ではない。

## 先行資料が示す問題

- Google の ViSQOL README は、入力長をおよそ 8〜10 秒、音声モードを 16 kHz とし、単発スコアより同一処理の複数標本への集約を勧める。短い母音のスコアで一般的な音声品質を認定しない根拠になる。https://github.com/google/visqol
- Manocha・Jin・Finkelstein (2022) は音の類似性を品質の代替にする問題を扱う。音高変更を原音への一致度だけで採点すると、変更しない出力を好む可能性がある。https://www.isca-archive.org/interspeech_2022/manocha22_interspeech.html
- de Oliveira ら (2024) は PESQ の最適化が知覚品質の劣化を見落とす例を示し、波形自体の直接最適化も検討する。今回も、探索指標の改善をそのまま知覚品質の改善と呼ばない。https://www.isca-archive.org/interspeech_2024/deoliveira24_interspeech.pdf
- PySTOI は名称どおり明瞭性の測定器であり、自然性全体の尺度ではない。初回は導入していない。https://github.com/mpariente/pystoi

この小さな追加調査は論点の確認であり、意見分布を再集計したものではない。添付の調査索引を再精読したとも主張しない。

## 比較方法

### 初期測定器

`work/eval_adapter/metrics.py` に実装した。入力長の不一致・NaN / Inf・空入力は失敗状態として返し、切り詰めたスコアを勝敗に使わない。全メトリクスは JSON の数値または null であり、未定義をゼロに変換しない。遅延補正・DTW・ゲイン正規化は実施しない。

1. 5 / 20 / 80 ms の Hann STFT: 対数振幅 MAE (dB)、spectral convergence。対数の floor を結果へ記録し、窓別値を保存する。無音参照の spectral convergence は null。
2. 固定帯域の全信号エネルギー: 各帯域の参照 / 出力パワー・dB 差。集計対象は参照だけで固定する。無音参照の active-band MAE は null だが、各帯域の追加エネルギーと出力 RMS は残る。これは声道形状の保証ではない。
3. RMS の dB 差、出力の RMS dBFS / peak、finite、サンプル数。
4. 既知 F0 刺激だけに独立 YIN 型差分推定器を適用: 絶対誤差の中央値 / P95、600 cent 超の大誤り、既知有声での未検出、既知無声の誤有声化、各分母を記録。境界をまたぐ窓は境界件数として明示し、cent と UV の集計には使わない。

自然音声には既知 F0 がないので、今回の独立 F0 真値試験の対象にしない。自作推定器は正解ではなく測定器である。WORLD の DIO / Harvest を分析にも採点にも用いて自己整合性だけを測る構成を避けた。

### 独立刺激

`fixtures.make_synthetic_cases(sr, seed)` は各 16 / 24 / 48 kHz で 10 ケースを生成する。どの候補デコーダーも呼ばない。

- 120 Hz 正弦、110 / 220 Hz 調波、150 Hz 基本波欠落、90→240 Hz の滑らかな調波 sweep。
- 4 倍サンプルレートのパルス列 → 固定 IIR 共鳴器 → anti-alias downsampling による 90 Hz 母音様音。調波加算と別の生成系列。
- 6 Hz 振幅変調を持つ帯域雑音、有声 / 無声切替、無音、impulse。

全ケースを一括平均して「音声品質」にしない。純音・impulse・無音は診断であり、方式が音声を想定していることを明記する。一方、NaN・長さの欠落・無音からの大きい発音は音声でない入力でも運用上の失敗として残す。

### 再合成と操作を分離

- 無加工再合成は入力音声を参照として上の再現誤差を測る。
- 音高変更は既知の指定 F0 に対して出力を測る。元音への近さは追従の目標にしない。
- ゲインは指定 dB、時間倍率は明示した丸め規則によるサンプル長を測る。
- 操作の非対象漏れは、無加工再合成を基準としたレベル・長さ・帯域の診断を分ける。
- WORLD の手作り表現からの合成は「encoder を経由しない decoder 検査」に分類し、独立生成器による外部評価とは区別する。

## 測定器の校正と制約

校正用の 30 ケース（10 種 × 3 レート）では、既知有声の未検出 0、既知無声の誤有声化 0、cent 絶対誤差 P95 の最大は約 3.313 cent。混合ケースは各 14 境界フレームを別計上する。この結果は 65〜700 Hz 全域や自然音声での精度保証ではない。

`test_metrics.py` の 7 試験は、copy、0.5 倍ゲイン、lowpass、10 ms delay、1 sample crop、NaN、無音、無音への雑音追加、倍音高への誤変更、無声化、誤有声化、DC、seed 再現性を確認する。DC-only に誤った F0 を返す不具合を批評家の独立監査が発見し、平均除去後にも RMS 判定を入れて修正した。批評家の再監査で DC の誤有声化は 93 / 93 から 0 / 93 に変わり、通常音の校正は維持された。

初回に未測定の項目: 明瞭性、知覚品質、声の類似度、局所過渡の timing、長時間 state、一般の自然音声 F0 誤差、声質語への対応。測っていない項目を合格と表示しない。8〜10 秒の推奨条件に合わない 6 秒切り出しを使って ViSQOL の品質認定をしない。

## 五者議論での具体的応答

- 音響担当へ循環 F0 評価と自生成器への過適合を指摘。回答は独立なパルス / IIR、chirp、AM 雑音の併用に賛成。実装へ反映した。
- 制御担当へ原音 STFT で音高変更を採点する問題を指摘。回答は追従・非対象漏れ・未定義率の分離に賛成。手作り WORLD 表現は decoder 検査と明示することで一致。
- 実装担当へ音声とコードのライセンスの混同、および未定義のゼロ補完を批判。回答は valid / failure counts の保持に賛成。また stock WORLD offline 合成は固定 RNG なので「8 independent seeds」と報告しないことで一致。
- 批評家へ小数自然音声からの最良・高品質認定を退ける方針を提示。批評家から話者数、欠測、測定器の既知破損検査を補強する回答を得た。DC 不具合を修正し再監査済み。

## 採用・撤回判断

初期状態で正式 base が存在しなければ未選定と表示する。WORLD DIO と Harvest は同一合成器の分析器違いとして比較する。比較対象数と合成方式数を混同しない。

比較対象が未実装、測定が欠測、入力選択が少数、指標間にトレードオフが残る間は総合勝者を決めない。有限性・長さ・操作追従の失敗、話者別の悪化、解析不能率の増大を平均スコアで打ち消して採用しない。今後 base を置く場合も、その品質の主張は実際に検証した入力と操作に限定する。
