# 批評家レビュー：比較基盤を先に作る

日付：2026-10-11。担当：critic（必須の批評家、独立した AI エージェント）。
位置づけ：AI によるレビューであり、ユーザー指示ではない。`USER_INSTRUCTIONS.md` が優先する。

## 結論

WORLD を早期に正式 base にする提案は保留する。まず複数の比較対象を同じ実行・測定条件で扱う基盤を作る。正式 base が存在しない間は `base = null` とし、HTML に「正式 base 未選定／比較基盤の初回測定」と表示する。既存法の知名度、著者の品質主張、wrapper の実装完了だけでは、今回の目的で最良だとは認定できない。

ユーザーの追加指示「比較対象は何個あっても OK」「比較方法をまず作る」は親エージェントから原文で共有された。指示専用 PR による反映を先行し、以下はその後の比較基盤に対する受入条件案とする。

## 実際の先例と、読み取れる範囲

1. [WORLD の著者 README](https://github.com/mmorise/World) は F0・非周期性・スペクトル包絡による解析合成を説明し、DIO と Harvest を別の F0 推定器として挙げる。したがって DIO+StoneMask と Harvest の比較は有用だが、同じ合成器に対する解析差であり、独立した二つの合成方式の比較ではない。確認範囲は README。ライブラリ全体の検証完了を意味しない。
2. [LLSM2 の著者 README](https://github.com/Sleepwalking/libllsm2) は調波の振幅・位相、雑音のスペクトル密度・時間形状、および別階層の音源・フィルタ表現を説明する。F0 を外部ライブラリから受け取る点にも注意が必要。今回同じ F0 を供給して比較するなら、条件をそろえた解析合成部分の比較として報告し、自然な end-to-end 方式比較と混同しない。確認範囲は README。
3. [de Oliveira ら（2024）The PESQetarian](https://www.isca-archive.org/interspeech_2024/deoliveira24_interspeech.html) は PESQ の高得点と聴取結果の乖離を報告する。この事例から、今回も単一指標の改善だけを知覚品質の改善と呼ばない。確認範囲は著者要旨であり、波形直接最適化の詳細など本文未確認の主張はこのレビューに含めない。
4. [ViSQOL の公式 README](https://github.com/google/visqol) はモード別サンプルレート、入力条件、集約の必要性を示し、想定外用途では振る舞いが悪い場合があると明記する。したがって名称が「品質指標」であるだけでは今回の適用妥当性は得られない。学習済み写像を含むため、純粋な非 ML 指標とも扱わない。確認範囲は README。

これらは今回の候補・評価上の注意を支える資料であり、分野全体の支持率を示す資料数ではない。添付調査の件数を、自分が全文再確認した件数として再掲しない。

追加で送った条件：ゲインは非クリップ刺激で振幅比を直接測る、duration の丸め規則を固定する、自然音声の F0 欠測を誤差ゼロとしない、WORLD 系を複数の独立合成方式と数えない、同じ話者の多数フレームを独立話者数に置き換えない。

実装担当からの追加応答：`analyzer_variant` と `decoder_family` を分けて記録する方針に合意。WORLD の offline synthesis は関数内の RNG 状態を固定値で初期化する実装を静的に確認したとの報告があった。ただしこのレビュー担当自身がそのソースを再確認したわけではなく、実行ハッシュによる確認も別工程である。同じ seed を外から指定できることや、環境をまたぐ bitwise 一致まで断言しない。

## 比較基盤 PR の受入条件案

### 結果の意味を保つ

- 無加工再合成と pitch/gain/time 操作を別試験にする。元音声との差だけで操作を採点しない。
- 操作の評価では、未操作の同方式出力からの変化と、保持対象の変化を記録する。入力音声を基準とした再合成誤差も別に残す。
- 自然音声で F0 の絶対正解がない場合は「独立測定器による推定」と表示する。測定器を自分のエンコーダーだけにしない。
- 比較対象・設定・入力ファイルのハッシュ・出力長・サンプルレート・前処理・依存 version を結果に結び付ける。
- サンプル数、発話数、話者数を分ける。少数英語発話から日本語、歌唱、ささやき、広帯域の品質へ一般化しない。
- 非有限値、例外、欠測、測定対象外、未実装を区別する。欠測をゼロ誤差や合格へ変換しない。比較表の分母をそろえ、coverage を残す。
- 失敗したデータを平均から黙って除外しない。比較器が未対応なら適用範囲として残す。

### 測定器を先に検査する

- identity/copy の音響差が数値誤差範囲にあることを確認する。
- 既知ゲインでレベル差の方向・単位を確認する。DC オフセット、クリップの有無を別に扱う。
- 正弦波・複数調波・既知 F0 変化で F0 測定を校正し、無音・雑音では F0 を無理に作らない。真の無声、推定不能、誤った有声判定を区別する。
- 時間シフト・低域通過・雑音追加など、検出対象が明確な変換に指標が反応することを確認する。ただしすべての指標に同じ単調性を要求しない。
- 固定遅延補正やゲイン正規化の有無を明示する。都合のよい動的整列で境界や時間の誤差を隠さない。
- 値は得られても適用条件外なら外部品質指標の合否根拠にしない。ViSQOL 等の導入未完了を計測済みと記載しない。

### 比較対象とデータを独立させる

- WORLD DIO と Harvest は解析差を比較する対象として保持してよい。方式の多様性を主張するには別合成器も必要。
- 自作 decoder が生成した刺激だけでは品質を選ばない。独立な人工刺激は機械的性質の検査、自然音声は再合成の診断と役割を分ける。
- 自然音声の取得ができなければ、その障害・代替案を記録して他の測定を進める。自然音声未評価のまま正式な品質優位を宣言しない。
- データを再配布するなら出典、利用条件、必要な帰属を確認する。取得用スクリプトの場合も URL と digest を残す。
- 複数の公開比較対象を維持することと、失敗した新提案の実装を保存しないことを区別する。旧 base の削除回避のために比較対象へ名前だけ変えない。

## 正式 base 選定・置換を止める反証条件

次のいずれかが残る間は比較基盤や測定の改善を続け、正式 base の優位判定はしない。

1. 評価の主要部分が自生成信号だけで、自然音声や独立な刺激への挙動を確認できていない。
2. 改善が F0 測定器の欠測増加、対象区間の除外、異なる前処理から生じている。
3. 平均再合成誤差が改善しても、意図した操作が効かない、無音に発音する、イベントを消すなどの契約違反が増える。
4. 同一条件を再現できず、候補差が乱数や依存差より大きいか判断できない。
5. 新しい候補の結果に、比較時点の正式 base・version が記録されていない。
6. 指標に合わせて候補を選んだ後、同じデータだけで知覚品質が確定したと主張している。

このレビューは閾値や方式をユーザー要件に追加しない。現段階の受入は「比較器と測定器が再実行可能で、結果の意味と欠測が明示されている」ことであり、「高品質ボコーダーの完成」ではない。
