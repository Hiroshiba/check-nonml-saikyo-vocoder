# 独立した測定器監査の結果

2026-10-11、critic 担当。比較担当とは別に作った刺激で `vocoderbench/metrics.py` を監査した。
初回の隔離実験を移植した [audit_metrics.py](../../../../scripts/audit_metrics.py) が入力を内部生成するため、外部音声・NPZ・native ボコーダーは不要。リポジトリのルートで次を実行する。

```sh
python scripts/audit_metrics.py --output runs/metric-audit
```

各検査の成功・失敗を表示し、2 本の JSON を保存した後、失敗があれば終了コード 1 を返す。今回、20 検査が成功した。これは既知刺激に対する測定器の工学検査であり、方式の品質認定ではない。最終実行の [基本監査 JSON](../results/run-001/metric_audit_results.json) と [広帯域監査 JSON](../results/run-001/wideband_pitch_results.json) に測定器・監査スクリプトの SHA-256 と判定を記録した。

監査コード自体の失敗検出も確認した。別 Python プロセス内で F0 の前処理だけを意図的に無効化すると、20 検査のうち 4 件を失敗として記録し、失敗数を返した。リポジトリの測定器ソースは変更していない。この意図的な不合格結果は上記の正常な最終結果には混ぜていない。

| 入力への変更 | 測定結果 | 判断 |
|---|---|---|
| copy | STFT 差 0、レベル差 0 dB | 一致を検出 |
| 0.5 倍 gain | -6.0205999133 dB | 正しい符号・単位 |
| 10 ms shift | STFT 対数差 1.0958 dB | 自動整列で消していない。時刻の直接推定ではない |
| 1 kHz lowpass | STFT 対数差 4.7901 dB、帯域誤差増加 | 帯域の欠落を検出 |
| 100 ms crop | `length_mismatch`、-2400 samples | 共通部分だけで完全一致としない |
| NaN / Inf | `nonfinite_input_or_output` | 無効を明示 |
| 既知有声から無音化 | 93/93 有声フレーム欠測、F0 誤差 null | 欠測を 0 誤差扱いしない |
| 無音の正解 | F0 誤差 null、誤有声 0 | 未定義を明示 |
| 10 倍 gain | +20 dB、peak 3.5053 | 正規化で振幅範囲逸脱を隠さない |
| 180 Hz 複数調波 | 修正版で有効 93/93、絶対 F0 誤差 P95 0.0676 cent 未満 | この刺激の推定校正。自然音声の精度保証ではない |

## 発見・修正・再確認

当初、定数 DC=0.1 を既知無声として与えると 93/93 フレームを有声と誤判定した。原因は平均除去前だけで RMS による無音判定を行い、平均除去後のゼロ信号を周期性の高い信号として扱うことだった。

評価担当へ反例を送り、平均除去後にも RMS を検査する修正と回帰試験追加の返答を得た。同じ独立刺激を再実行し、誤有声は 0/93、通常 180 Hz の値と他の破損検出に回帰がないことを確認した。

## 追加の広帯域周期信号による監査

WORLD に手作りの 180 Hz・平坦包絡特徴を入力した波形で、F0 測定器が 90 Hz・180 Hz・未検出に分かれる現象を見つけた。方式側の誤りと区別するため、候補 decoder を使わず解析式の等振幅調波和を作った。

サンプルレート 24 kHz、1 秒、基本周波数の整数倍を Nyquist 未満まで加えた厳密に既知の周期信号で、修正前の YIN は 160 Hz と 220 Hz を 93/93 フレーム検出した一方、180 Hz を 0/93 フレームしか検出できなかった。非整数サンプル周期と高域エネルギーに依存する測定器の盲点を示す反例である。同じ解析刺激の生成を上記 `audit_metrics.py` に含めた。修正前の現象は `tests/test_metrics.py` の広帯域校正テストが前処理なしの呼出しで再現する。

固定低域通過を外部で施すと 180 Hz は 92/93 フレームで検出され、誤差 P95 は 0.065 cent 未満となった。ただしフィルタ過渡と有声無声への影響を検証せず、この一例だけを根拠に測定器を変更してはいけない。評価担当へ、方式や真値に依存しない前処理と、複数レート・音高・無声信号での再校正を依頼した。修正版と比較全体の再実行が確認できるまで、この問題の解消を承認しない。

その後、評価担当は F0 診断だけに固定 2 kHz・6 次 Butterworth の forward/backward フィルタと最大 80 ms の even 端反射を導入した。端フレームを除外せず、波形再現指標へはフィルタを適用しない。同担当から 48 広帯域刺激と従来校正の再確認結果を受け取った。

批評家は修正版を独立に再実行した。上記 160/180/220 Hz の解析信号はすべて 93/93 フレーム有効、gross error 0、P95 最大 0.088 cent 未満。手作り WORLD 180 Hz 出力も 43/43 有効、P95 0.206 cent 未満となった。copy/gain/shift/lowpass/crop/NaN/Inf/無音欠測/DC の独立監査にも回帰はなかった。この反例について測定器修正を確認したが、比較全体も新しい測定器で再実行した結果を確認し、128 行の再合成計測と 50 行の操作計測が新しい測定器を使用していることを確認した。

## 残る注意

- `compare_waveforms` の `status = ok` は測定成功を意味する。品質合格ではなく、無音出力でも測定できる場合は `ok` となる。
- STFT の差だけでは shift の時刻を正確に測ったことにはならない。
- F0 評価は明示した 80 ms 窓・65–700 Hz 範囲と固定 2 kHz 前処理に依存する。周期性が 2 kHz より上だけに存在する場合は未検証。自然音声では別途推定の不確かさを扱う必要がある。
- この監査は知覚評価器の妥当性、方式の品質順位、正式 base の選定を承認していない。
- 最終比較レポートの正式 base 未選定表示、固定した比較基準との区別、処理成功と品質合格の区別、真値・相対音高の欠測分母を確認した。LLSM の操作未実装と自然音声 2 話者の限界を明示している。
