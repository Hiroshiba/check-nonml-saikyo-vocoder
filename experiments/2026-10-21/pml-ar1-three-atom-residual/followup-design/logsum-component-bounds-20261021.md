# 混合得点の差から、成分の変化をどこまで言えるか

混合得点の差と成分ごとの行列式項の極値から、二次形式・尺度項の変化に片側の制約を置けます。ただし、ここで定義するlowerとupperは異なる極値を制約します。同じ量の区間や、成分の復元としては読めません。低q選択の原因・真F0・品質の因果関係・採用は未解決で、PMLを維持します。

これは[固定モデルの幾何を読む追補](model-geometry-20261021/README.md)に続く紙上補題です。以前の原文・親追補を改稿せず、五つの仮想専門役による二巡の議論を整理しました。実在五人の査読ではありません。別担当が今回確認したのは、以下の式・反例・解釈条件の紙上整合性です。実測や公開原稿全文の検証、以前の実装静的レビューを新たな査読として数えるものではありません。

## 同じ窓・入力・前処理と、共通の30成分を条件にする

同じ物理窓、入力z、前処理を固定します。成分は三原子aとK=1..10の30通り `i=(a,K)` で、qとrに共通の正の事前重み `w_i>0` を使います。qに依存しないGaussian–IGの共通定数を省き、次のように定義します。Δはq−rの対応差です。

```text
ℓ_i(q) = d_i(q) + f_i(q) + log w_i
B(q) = log Σ_i exp ℓ_i(q)
p_i(r) = exp[ℓ_i(r) − B(r)]
Δd_i = d_i(q) − d_i(r),  Δf_i = f_i(q) − f_i(r)
ΔB = B(q) − B(r)
```

`p_i(r)` は基準候補rでデータzに条件付けた作業モデル内の成分重みで、合計は1です。元の事前重みwとは区別します。

## 混合差から得られるのは、別々の極値への片側制約

基準側の成分重みを用いると、混合差は次の形になります。

```text
ΔB = log Σ_i p_i(r) exp(Δd_i + Δf_i)
min_i(Δd_i + Δf_i) ≤ ΔB ≤ max_i(Δd_i + Δf_i)
Dmin = min_i Δd_i,  Dmax = max_i Δd_i
lower = ΔB − Dmax ≤ max_i Δf_i
min_i Δf_i ≤ upper = ΔB − Dmin
```

正の重みの合計が1なので、指数関数の重み付き和は各項の最小値と最大値の間にあります。対数を取れば最初の上下界です。さらに `ΔB≤Dmax+max_i Δf_i` と `ΔB≥Dmin+min_i Δf_i` から、lowerとupperの片側制約を得ます。

lowerは `max_i Δf_i` の下限、upperは `min_i Δf_i` の上限です。全成分で `Δf_i=0` なら `Dmin≤ΔB≤Dmax` ですが、この区間に入ることから全成分の変化ゼロは導けません。

## 非零の成分変化が打ち消し合う一般logsumの反例

30成分を二つの空でない群に分け、基準側 `p_i(r)` の群質量をpと1−pとします。これは元priorの群質量ではありません。`0<p<1` とし、全成分で `Δd_i=0`、各群のΔfをそれぞれtとuに置きます。

```text
0 < t < −log p
u = log[(1 − p exp t) / (1 − p)]
p exp t + (1 − p) exp u = 1
ΔB = 0
```

この条件でtは正、uは負であり、非零の変化があっても混合差は0です。これは一般のlogsum命題の反例です。現調波モデルの同じz・共分散制約の下で実現した数値例とは主張しません。

## 現モデルの二次形式と、相殺できる対応差を限定する

現モデルでは、係数事前I/Kと完全なcos/sin対の行列Xを使い、`S_qK=X_qK X_qKᵀ/K` とします。係数積分に用いる行列を `A_i(q)=K I_(2K)+X_qKᵀ C(a)⁻¹ X_qK` と書くと、各項は次の形です。

```text
V_i(q) = C(a) + S_qK
R_i(q) = zᵀ V_i(q)⁻¹ z
f_i(q) = −203 log[2 + R_i(q)/2]
d_i(q) = K log K − (1/2) log|A_i(q)| − (1/2) log|C(a)|
Δd_i = −(1/2)[log|A_i(q)| − log|A_i(r)|]  （同じa,Kの対応差）
```

Rは、係数を積分した後の全観測共分散による二次形式です。独立に最適化した残差平方和とは呼びません。`det C(a)` の相殺は同じa,Kの対応差に限られ、原子混合の前からその項を削除してよい意味ではありません。

保存されたH1条件付きの `b(q)=B(q)−c(window)` では、同じ窓の共通normalizerが差で相殺し、`Δb=ΔB` です。q依存prior、成分欠落、DP後の得点はこの式に混ぜません。周辺化済みbから欠けた成分を復元したとも、支配成分を同定したとも言えません。

## 実数の含意とfloat64の参照診断を分ける

理想実数では `lower>0` なら少なくとも一成分で `Δf_i>0`、`upper<0` なら少なくとも一成分で `Δf_i<0` です。保存float64から求める参照余裕には厳密な誤差上界がないため、実数の符号証明にはなりません。

参照診断の対象は、新L/Fのgate1、選択q=52..66、r=2qまたは3qという部分集合に限ります。同じbのargmaxでqを選ぶ場合だけ、選択規則から `Δb≥0` が生じ得ます。系列選択Fには局所argmaxの保証を仮定しません。gate1は生理的な有声真値ではなく、重複・重なり窓も独立標本とは数えません。
