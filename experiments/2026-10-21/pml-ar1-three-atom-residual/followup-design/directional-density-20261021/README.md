# RMS後の得点を、同じ連続モデルの方向密度として考える

原点中心の連続モデルを方向へ写した密度を、未採用の別仮説として整理します。旧RMS後working tを誤りとは断定しません。[限定感度分析計画](sensitivity-plan.md)も未実行です。低qの原因、生理的VUV、真F0、品質改善や採用を示す結果はなく、PMLを維持します。

## 正の共通尺度を消し、球面上の密度を定める

N=400、s>0として、既存の原点中心モデルを固定します。aは−0.8、0、0.8の等重み、q=52..512、K=1..10、係数事前I/K、仮説事前H0/H1=0.3/0.7です。

```text
x | s,j ~ N(0, s V_j),  s ~ IG(shape 3, scale 2)
V_H0 = C(a),  V_H1 = C(a) + X Xᵀ/K
u = x/||x||,  z = √N u,  R_j = zᵀ V_j⁻¹ z
```

通常の単位球面の面積測度に関する各成分の方向密度は、次の形です。

```text
p_j(u) = Γ(N/2)/(2π^(N/2)) |V_j|^(-1/2) (uᵀV_j⁻¹u)^(-N/2)
```

極座標の面積因子ρ^(N−1)を含めて正の半径ρを積分すると、この式になります。正の共通尺度sは方向化で消え、IGのα、βも残りません。半径√Nの球面では面積がN^((N−1)/2)倍になるため、zの密度は次のとおりです。

```text
p_j(z) = √N Γ(N/2)/(2π^(N/2)) |V_j|^(-1/2) R_j^(-N/2)
非定数score = −(1/2) log|V_j| − 200 log R_j
```

球面の次元は399、二次形式の指数は−N/2=−200です。正規化した一様確率測度を使う場合は球面の面積に応じて密度の定数が変わるため、ここでは通常の面積測度を明示しています。一般の符号依存半径へ尺度消去を広げません。

## 方向への写像と、raw半径への条件付けを分ける

成分に依存する標本選別がなければ、方向へのpushforward（写像で誘導される分布）は混合と可換で、成分prior π_jを保持します。一方、raw半径ρに正則条件付けする操作では、半径密度h_j(ρ)を用いて成分重みが `π_j h_j(ρ)/Σ_k π_k h_k(ρ)` に更新されます。成分内の半径条件付き分布も、半径を積分した方向分布とは区別します。

旧t密度に元priorを掛けるposteriorは、仮想raw観測x=zに対するposteriorとして整合しています。「prior変更が必要だった誤実装」とは呼びません。方向密度は別の観測写像の仮説です。

旧tと方向密度の非定数scoreの差は、成分ごとに次の形になります。

```text
g(R) = 203 log(2+R/2) − 200 log R
g′(R) = (3R−800)/[R(R+4)]
```

これは成分単位の関係です。周辺化した得点差へ単一のRを代入できません。400次元Lebesgue密度と399次元球面の面積密度を直接比べて「適合が改善した」とも言えません。

## 五つの仮想役による二巡と、その後の紙上確認

親から共有された議論を記録します。実在五人の査読ではありません。

| 仮想役 | 第1巡の論点 | 第2巡で限定した範囲 |
| --- | --- | --- |
| 確率役 | 正の尺度を方向化で消す | 一般の符号依存半径へ広げない |
| 測度役 | 球面面積・一様確率・半径条件付きの違い | 球面次元399と指数−200を分離する |
| 混合役 | 写像後にもpriorを保持する | 量子化や全零除外が成分依存の選別なら別に扱う |
| 観測役 | 非零location・centering・有限精度を点検する | 新しい平均除去・再RMS・floorを加えない |
| 批評役 | 旧scoreの誤りや改善を結論しない | 相対λ=1とSNRの前提は残る |

この後、別担当が極座標積分から式・測度・混合・感度目的を紙上で独立確認したとの報告を受けています。実装・実データ・この新原稿全文を検証したとの主張はしません。

## 全体尺度の不変性を、相対尺度や有限精度へ広げない

消えるのはV→cVという全体尺度です。`C+λS` の相対λ=1とI/Kの前提は残ります。非零locationでは一般に尺度が消えず、centeringを入れるなら399次元部分空間上の別モデルです。今回は追加しません。

連続モデルの全零確率0と、量子化音声の全零は別です。非零標本への選別が成分依存なら、prior保持を自動適用できません。float64が厳密な球面支持・尺度不変性・符号を保証するとも扱いません。旧文書・実測結果・75品質値・21短音声は保持します。

## 一般結果と、現モデルへの導出の確認範囲

- [Frahm博士論文2004、pp.59–60 Theorem 35](https://www.hsu-hh.de/stochastik/wp-content/uploads/sites/772/2018/02/Dissertation.pdf#page=73)：該当本文の方向密度を確認しました。一般結果を上のN=400・Gaussian–IGモデルへ適用し、半径√Nへの定数を明示した部分は親の統合と別担当の導出です。
- [Frahm–Jaekel 2015、Theorem 3](https://www.hsu-hh.de/stochastik/wp-content/uploads/sites/772/2017/10/AP-2015-01.pdf#page=12)：該当本文を確認しました。detΣ=1の記法と、球面の測度・定数を区別して読みます。
- [Tyler 1987](https://academic.oup.com/biomet/article-abstract/74/3/579/238632)：親の確認範囲は出版社abstractのみです。本作業も本文未確認で、今回の導出を本文で照合した根拠には数えません。

周辺の三方向は短い補足に留めます。[Nielsen 2012（DOI）](https://doi.org/10.1109/ICASSP.2012.6288947)の次数別F0支持と幅の正規化、[Godsill–Davy 2005（DOI）](https://doi.org/10.1109/ASPAA.2005.1540225)の調波番号に応じた係数分散の減衰は、親から共有された論点です。この2件の本文は本作業では確認できていません。

[Emiyaら2010](https://perso.telecom-paristech.fr/rbadeau/assets/emiya10.pdf)は該当節とFig.6周辺を確認しました。滑らかな調波振幅のAR包絡と残差MAを分け、subharmonicに対する補完作用を例示しています。楽器、長い窓、近似scoreなど現モデルとの違いがあり、即移植しません。三方向を同時実装せず、今回の計画では固定K/I/Kを保持します。
