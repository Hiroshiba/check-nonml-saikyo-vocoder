# F0候補の系列選択を既存PMLへつなぐ

初回3録音では既存PMLが3/3成功し、局所選択Lと二段系列選択Fは各0/3で、候補6枝が合成前に失敗しました。候補音声は未生成で、聴き比べ音声・MOS・品質順位はありません。全120評価と標準比較器による比較は未実施です。[初回native失敗の研究記録](first-native-failure/README.md)に、F0統計・6件の例外・実終了2・保存と親受領の到達点を保存しました。

比較の設計は、調波次数Kにまたがる重みをまとめたLと二段系列Fが出す推定直後のF0（raw F0）だけを既存PMLへ入力し、SPEC・PDD・NMを一貫して再解析して、同じ復号器を使うものです。H0を生理的な有声・無声（VUV）やNMの確率へ写さず、密度混合の直接音声化とも呼びません。新しい残差codecは増やしません。

PMLを唯一のbaseとして維持します。品質評価の段階Bと残り117録音への展開は停止中で、追加clip・修復・再実行は行っていません。
