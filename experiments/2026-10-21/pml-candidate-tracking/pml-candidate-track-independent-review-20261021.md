# 候補系列契約の独立・静的レビュー

2026-10-21 JST。対象は `pml-candidate-track-freeze-proposal-20261021.md` と `pml-external-f0-static-contract-20261021.md` の文章・数式のみ。実装、import、計算例、計測、tests/smoke、Cloud、外部書込み、対象文書の変更は行っていない。PML は唯一の base のまま、候補未採用。

## 判定

設計の大筋は整合する。旧 densitymix の結果を引き継がない K 周辺化→H0/H1 gate→有 clock 区間内 q という新しい二段規則であり、厳密生成 HMM／joint MAP と呼ばない点は正しい。ただし、以下の数値評価順と時間契約の最終確認を凍結せずに実装へ進むと、「同じ数式」の別実装が別経路を出し得る。

## 実装準備前に凍結する事項

1. **浮動小数点の canonical DP。** L1 max-plus の O(Q) 厳密性は実数算術の主張である。直接 `d(p)-λ|u(q)-u(p)|`、prefix/suffix 変形、隣接差分の再帰は、IEEE の加減算順・丸めにより一致しない。近似同値幅を設けないことだけでは再現性契約にならない。下記の一つの演算グラフ、float64、再中心化の位置、候補順と各 argmax の tie を固定し、別の直接 L1 実装との bitwise 同一性は要求しない。

2. **log potential の計算規約。** 非零窓の未正規化 log weight を ℓ0, ℓqK とすれば、cq=logsumexp_K ℓqK、h=logsumexp_q cq、z=logaddexp(ℓ0,h)、a0=ℓ0−z、a1=h−z、bq=cq−h とできる。線形 weight へ指数化してから v/m を合計すると、underflow による偽の全 H0 や `−inf−(−inf)` が起こり得る。K 昇順→q 昇順の集約、使用関数・軸・dtype、元 log weight の固定式／source、定数・u の生成式を固定する。非零窓の非有限値や演算失敗を零窓へ読み替えない。

3. **保存 grid と base の整合。** J=1+floor((N−1)/80)=ceil(N/80) は最終 anchor を最終標本以内に置き、未到達の末尾は 0…79 標本となる。s=min(max(80j−200,0),N−400) も N≥3200 の現入力条件と両立する。ただし、この式だけで analyze の返す時刻／行数や resample 非発生は保証されない。別担当の静的 API 確認と統合し、L/F は同一 J の raw・返却時刻それぞれに float64 bitwise grid 検査を必須とし、L 対 F の post clock を直接比較する。REAPER base は変更せず、自身の既存保存 grid 契約を検査して実 payload を開示する。base と L/F の行数が異なる場合に適用外とするのは直接 F0 配列の bitwise 比較であり、無断の補間・末尾追加・切断・再格子化で合わせない。同一元入力・同一 n_samples の復号・同一評価区間／評価器が成立すれば、フレーム数不一致だけで音声品質比較まで無効にはしない。

## 最小の canonical DP 固定案

以下は仕様案であり、未実装。Q=461、q は 52…512 の昇順。u(q)=12 log2(fq/f52) を float64 で一度生成する案なら、実数上の距離は元の 12 log2(fq) と同じで不要な絶対定数が消える。ただし IEEE では元式と同じ値を保証しないので、この変更自体も先に固定する。

**gate:** 開始は r0(g)=a0(g) とし、架空の初期状態からの切替 cost は課さない。各 j≥1 で t_j(g)=max_h[d_(j−1)(h)−κ·1(h≠g)] を計算し、前状態を記録してから r_j(g)=a_j(g)+t_j(g)。毎 frame d_j(g)=r_j(g)−max_g r_j(g) とする。各 max の score 完全一致は h=0、終端も g=0 を優先する。

**q:** 選ばれた gate=1 区間の開始は r(q)=b(q) として再中心化。次 frame は、中心化済み d(p) から

- A(q)=max_(p≤q)[d(p)+λu(p)] を昇順 prefix scan、
- B(q)=max_(p≥q)[d(p)−λu(p)] を降順 suffix scan、
- t(q)=max[A(q)−λu(q), B(q)+λu(q)]、
- 左右の前状態選択後に r(q)=b(q)+t(q)、最後に d(q)=r(q)−max_q r(q)。

λu は同じ生成値を再利用し、括弧の順に評価する。prefix/suffix 各比較と左右 merge の各 argmax では、そこで実際に比較する float64 score が完全一致したときだけ前状態 index 最小を選ぶ。終端 score の完全一致は q 最小。これは全経路の辞書順最小でも、変形前の全候補の直接評価で生じる丸め後 tie の最小 index 保証でもない。初期 frame を含め各 frame で最大値を一度求めて再中心化し、非有限値は fail-closed とする。

実数上では左側が p≤q、右側が p≥q の L1 遷移を正確に分割するため O(Q)／frame。score は O(Q)、backpointer は O(JQ)。gate DP は O(J)。K の局所周辺化費用は別。再中心化も IEEE の結果を変え得るので、任意の最適化ではなく canonical な評価順の一部とする。

## 整合を確認した点

- **位相原点。** 同一の物理窓について完全な cos/sin 対を使い、係数の結合事前がその対ごとの回転に不変なら、位相原点の変更は直交基底変換で、周辺重みは実数上不変。十分条件は零平均、各対で同一分散、独立な対からなる等方ブロック事前と、位相に依存しない variance prior／RMS 代入値。単に対の周辺分散が同じだけで、位相依存の対間相関や平均が残る場合は十分でない。この条件を既存式に結び付けて固定する。全窓 local n=0…399 は妥当で、同一の端点窓には同じ計算を再利用できる。ただし、別の実データ窓への shift に対する観測同一性ではない。位相係数を下流へ渡さない範囲に限定する。
- **周辺化・prior。** H1 総 prior 0.7 を 461×10 に配分し、K→q の和を取れば multiplicity の扱いは明示的。a1 は H1 総質量、b は H1 条件付き q。各窓 prior を一度使い、追加初期 prior なしという定義に矛盾はない。重複窓なので独立尤度積／校正 posterior ではない。gate を先に決めて q の最適値を gate へ戻さないため joint MAP とは異なる。
- **零窓。** exact 全零だけ a0=a1=bq=0 とするのは正規化 posterior でなく欠測 potential の上書きだが、その意味は明記されている。L の H0 tie、F の隣接／遷移による補完と整合する。旧診断の 9 calibration_zero 窓の成功扱いや過去結果の変更にはつながらない。
- **下流。** gate=0 で q の DP 区間を reset しても、raw 0 は PML が正の観測間を補間する。従って最終 PML clock の断絶・無声音・位相 reset を意味しない。全 H0 は 65 Hz fallback。H0 を NM に写さない点も一貫する。
- **失敗・seed・評価。** analyze／decode の seed=0 明示、filter 後の有限かつ 50<F0<700 の保存条件、追加 clip／solver／格子変更による救済なしは整合する。記述的な開発比較に限り、正差だけで採用・独立未使用評価の免除をしない。κ/λ 等を同じ 120 の結果で変更しない点は漏洩を防ぐ境界として必要。

## 計測前の残件と文面上の軽微事項

- 失敗時に対応差へ入れる録音集合、話者内 3 録音の分母、欠損話者の扱い、比較不能の表示を事前固定する。実分母の記録だけでは、枝ごとに成功例を別平均して生存者バイアスを作る余地が残る。評価方向の一次参照も本文が認める未凍結事項。
- 静的契約の「seed 別途指定予定」「H0 変換未設計」「dense 未決定」は、提案が選択した seed=0／raw 0／400×80 に対する先行監査の未決定欄である。どの版の決定が優先するかを統合版で明示すればよく、既存 PML の変更理由にはしない。
- 「score 完全同値時は前状態最小」とだけ書かず、上記 canonical の各比較段階に限定する。「正確に最大化」は実数算術での意味と区別する。
