# PML の非リンギング F0 軌跡仮説の設計レビュー

2026-10-21 JST。設計判断のみ。**推奨は新しい比較仮説の明文化であり、実装・実行・再試行・採用の承認ではない。**

## 結論

元の L/F 実験は失敗として閉じ、正式 base `PML / pml-lowband-fwcep60-v1`、source、原結果を変更しない。次に検討するのは「validator に合わせて値を押し戻す処理」ではなく、**連続合成時計を有限支持の非負平均で推定するという別の軌跡モデル**である。選択器を凍結し、線形 Hz 領域の非負平滑を主たる設計対象とする。log-F0 化と系列事前の変更は別要因に分離する。

ただし、凸包保存は音響的な適切さも native 完遂も保証しない。帯域・支持幅の選定根拠と既存分析への注入境界が未解決なので、現時点で最終核を推奨せず、コード準備にも進まない。

## 1 既知の失敗と証拠の境界

保存結果診断 `pml-native-first-failure-diagnosis-20261021-ja.md` と同 JSON を読んだ。初回は exit 2、PML 3 枝成功、L/F 6 枝は解析後の `PMLParameters` 構築で失敗した。post 最小値 L/F は 0008 が 43.7784/45.1769 Hz、0011 が 24.2771/40.4331 Hz、0032 が 44.1993/44.0697 Hz。50 Hz 以下は順に 6/2、8/1、2/1 の計20フレーム、700 Hz 以上は0。raw の正値は全て50 Hz超で、範囲違反は全て gate=1 にある。

既存 source は、非正 raw の補間、既存の65..700 Hz clamp、Butterworth 往復処理を順に行い、後段の再 clip をしない。保存制約は厳密な `50 < F0 < 700`。この構造と保存 post は平滑化による下振れという機構推定に整合するが、未保存の中間配列や filter 応答を再現した証拠ではない。[既存解析](https://github.com/Hiroshiba/check-nonml-saikyo-vocoder/blob/2251f947032296c6cdf03e8022c74eefbeef17e8/vocoderbench/pml/pml_analysis.py)、[保存制約](https://github.com/Hiroshiba/check-nonml-saikyo-vocoder/blob/2251f947032296c6cdf03e8022c74eefbeef17e8/vocoderbench/pml/parameters.py)

本レビューは source と既存診断の読取、文献確認、以下の解析的導出だけを行った。波形読取、配列の新しい算術、filter replay、import、test、smoke、品質計測は行っていない。元3件を修復成功へ変更せず、phase B と残117件は停止のままとする。

## 2 先に訂正すべき時間格子

**200 Hz は L/F の raw・保存格子であり、既存 IIR の内部格子ではない。** 均一5 ms raw に対し、source の `fc=(1/step)/4` は50 Hz、`hshift=(1/fc)/8` は2.5 msなので、内部格子は400 Hzである。内部補間、往復 filter、元時刻への戻し補間を区別する。REAPER raw は保存診断でも非厳密5 msであり、平均間隔と既存 jitter/resample 分岐をそのまま扱う。一律200 Hzや400 Hzに直す案は追加の変更になる。[既存解析](https://github.com/Hiroshiba/check-nonml-saikyo-vocoder/blob/2251f947032296c6cdf03e8022c74eefbeef17e8/vocoderbench/pml/pml_analysis.py)

平滑化族だけの比較に近づけるなら、raw 補間・既存 clamp・内部格子生成・戻し補間・既存 resample 条件を共通にし、内部の平滑演算だけを別名候補で置換する。端点拡張の違いは平滑演算の仕様差として開示し、同一条件とは呼ばない。

## 3 新仮説と厳密な保証範囲

仮説は「同じ局所情報・同じ L/F 選択から得た連続時計に対して、有限支持の非負局所平均は、signed IIR の範囲逸脱を導入せずに、合成に必要な軌跡情報を残せる」である。前半は数学的性質、後半は未検証の音響仮説であり、分けて扱う。validator 通過だけを後半の証拠にしない。

補間・既存 clamp 後の正値列を x、固定の非負係数を h とし、Σh=1、端点は最寄り値延長とする。y[j]=Σ_k h[k] x[endpoint(j+k)] と定義する。

- **実数上の導出**：各 y[j] は参照入力の凸結合なので局所最小値以上・局所最大値以下。線形補間・端点延長との合成も非負・行和1の写像なので、全経路で入力範囲を保存する。
- 固定核と最寄り値延長は定数列を保存し、単調な全区間 step を単調に保つ。「任意信号の全ての局所極値を保存」「全ての正核に阻止帯域 ripple がない」とは主張しない。ここでの非リンギングは範囲外 overshoot と単調 step の反転を作らないという限定語である。
- L/F は既存候補格子が50.78125..500 Hzなので、既存の補間・clamp 後は65..500 Hz内。上記の実数上の写像ならこの範囲を保ち、保存制約から余裕を持つ。これは録音3件の値に合わせた新しい floor ではない。
- REAPER は既存 clamp 上端700 Hzちょうどを取り得る。非負平均は700の定数区間を700のまま残すため、**REAPER 全入力の strict <700 は保証しない**。上限を縮めず、その失敗を記録する。
- float64 の有限演算は実数の証明そのものではない。係数の表現・演算順・端点を事前固定し、実測境界違反・非有限・時刻不一致は停止する。丸めを口実にした clip、ε、再正規化、値の差替えを追加しない。
- 保存 F0 が妥当でも、StoneMask、SPEC、PDD/NM、保存、復号に別の失敗があり得る。凸包保存を native 完遂保証へ拡張しない。

## 4 線形 Hz と log-F0 を混同しない

線形平均は加算的な瞬時周波数の局所推定であり、内部の線形 Hz ramp を保存する。位相 φ の微分が2πfであるという定義に対し、端点を除けば線形平滑と微分が可換なので、連続クロックという PML の用途との関係が明確である。今回は元処理と領域を揃え、平滑化族の変更を調べるため線形を主比較に置く。これが知覚上最良という意味ではない。

log 平均は y=exp(Σh log x) という幾何平均で、log 線形 ramp と周波数比の局所変化を扱いやすい。実数上では同じ凸包内にあり、同じ入力の算術平均以下となる。両方式とも正の定数倍率に対して同変なので、「移調同変性が log にだけある」は誤り。log を試す場合も非正 raw へ ε を足さず、共通の既存補間・clamp の後だけに適用し、別の要因として比較する。

知覚は普遍的に log が正しいとも言えない。Hermes と van Gestel のイントネーション強調度の実験では、異なる音域の変動幅の一致は線形 Hz／log の中間にある聴覚尺度で説明された。これは特定の知覚課題の結果であり、PML 品質や全ての pitch 判断へ一般化しない。本稿では一次論文の公開 abstract を確認した。[Hermes and van Gestel 1991](https://pubmed.ncbi.nlm.nih.gov/1831823/)

## 5 提示3tapの二段階批評

以下は伝達式からの導出であり、数値 probe ではない。対称3tap `[a,1−2a,a]` の内部応答は H(ω)=1−2a+2a cos ω。

1. **200 Hzへ直接作用する場合**：50 Hz は ω=π/2。a=(1−1/√2)/2 は H=1/√2となり、単方向 Butterworth の設計点だけに一致する。既存の往復処理自体は |B|²なので、その内部定常応答は50 Hzで1/2。そこへの一点整合なら a=1/4、核は `[1/4,1/2,1/4]`。ただし既存の内部格子とは異なる。
2. **実際の400 Hz内部格子を保つ場合**：50 Hz は ω=π/4。非負条件0≤a≤1/2では H≥cos(π/4)=1/√2となり、3tapでは1/2に届かない。200 Hzでの係数を「既存同等の50 Hz平滑」として移植できない。

これらの利得は端点を除く filter 自体の定常応答であり、有限長の補間→往復→戻し補間という全経路を一点で同一視しない。Butterworth の cutoff は単方向の1/√2点、filtfilt は前後2回の適用である。[SciPy 1.17 butter](https://docs.scipy.org/doc/scipy-1.17.0/reference/generated/scipy.signal.butter.html)、[SciPy 1.17 filtfilt](https://docs.scipy.org/doc/scipy-1.17.0/reference/generated/scipy.signal.filtfilt.html)

議論用の完全決定的 reference Nref は、**既存内部格子に一度だけ** `[1/4,1/2,1/4]` を作用させ、両端を最寄り値延長とするものと置ける。このとき H=cos²(ω/2)、内部50 Hz利得は(2+√2)/4であり、元 IIR の1/2とは異なる。これは正核の性質を説明する非採用 reference で、最終推奨核ではない。通過帯域、阻止帯域、急変のにじみ、必要な微小変動の減衰は同等でない。「全応答一致」「同じ平滑強度」「符号だけの効果」とは報告できない。

より長い正核や別の支持幅を検討してもよいが、一点整合自体を目的にせず、残すべき時計変調と許容誤差から独立に決める。今回の3件の min、失敗位置、成功率から核幅や cutoff を選ばない。

## 6 最小の比較と反証可能な判定

将来別途承認される比較は、**3選択器 R=既存REAPER、L、F × 2後処理 B=元処理、N=事前凍結した非負線形処理**の6セルを最小とする。R,N は新候補であり正式 PML ではない。L/F×2だけでは、正式 PMLとの差に後処理の変更が混ざる。核の一般優位や log の優位を主張しないので、主比較に核探索・log 条件は足さない。

- 選択器差は同じ後処理下の F−L、既存選択器からの差は L−R と F−R。
- 後処理差は各選択器内の N−B。交互作用は `(F−L)_N−(F−L)_B`。F,N対R,Bだけを選択器の改善と呼ばない。
- 各セルで全予定録音を分母に、native 完遂率、失敗 stage、strict 範囲外数、保存品質の可用性を報告する。native 完遂を MOS の代理指標にしない。
- 音声品質差は同じ指標が両側で取得できた共通集合だけの記述とし、分母・除外理由を併記する。失敗を0点へ変換せず、成功例だけの平均から全体の改善を主張しない。B側の L/F が全失敗なら、N−Bの音声品質差も交互作用も未定義である。
- 新しい N の F−L が見えても、元実験の F−L 品質の結論にはしない。F−L差が消えれば、その処理下では選択情報が消えたという反証的結果を残す。

科学的な問いは「保存可能になったか」だけでなく「残すべき変調を残せるか」である。将来の独立した既知 clock 入力には定数、単調 step、線形 Hz ramp、正弦状変調、短区間・端点を含め、解析式と出力の整合、参照 clock からの Hz/log 誤差、変調利得、端点の時間的にじみを比較する。正核の範囲保存が破れれば実装仮説を棄却し、範囲保存しても独立に定めた音響誤差予算を超えれば実用軌跡仮説を支持しない。時計の正解を別の推定器出力で代用しない。

**未解決ゲート**：必要変調帯域・誤差予算・最終核・独立評価入力は、今回の3件からは決められない。これらが外部の音響要件で事前固定されるまで上記は比較の設計であり、開始可能な事前登録ではない。quality は未実施なので、κ、λ、格子、cutoffの品質調整根拠は存在しない。

元3件の B セルは既存原本の参照だけにし、再計測・再合成しない。このレビューは3件の N セルを新しく埋めることも、残117件を展開することも承認しない。元データを再利用する将来の開発比較は既観測データの探索と明示し、独立検証と呼ばない。

## 7 系列制約だけを変える案との比較

F は既に gate の切替 penalty と log 周波数差 penalty を持つ。これを強める、hard jump 制約を足す、候補を65 Hz以上へ縮める案は選択器そのものを変え、L/F 比較も変える。しかも signed IIR が後段に残る以上、raw の点ごとの有界性だけでは post の凸包保存を証明できない。

既存後処理の出力まで制約する prior を新設するなら、後処理を含む実行可能集合を持つ別の目的関数になる。保存成功に条件付けて候補を選び直す行為を、元 posterior の復元や同じ F の修理とは呼べない。将来の joint gate/clock 生成モデルは独立の研究としてはあり得るが、重複窓の局所 potential を校正済み独立尤度に読み替えず、今回の κ=λ=1 を後付け調整しない。

したがって今回の機構切分けには、**選択器を固定した後処理族の明示的比較の方が解釈しやすい**。これは音質が良いと分かったという判断ではない。

## 8 五つの仮想専門役による二巡レビュー

一人の机上検討を五役に分けたもので、独立した五人の査読とは称さない。

### 第1巡 問題提起

- **確率モデル役**：Fの正則化不足が原因と決めるのは早い。後処理を変えるなら推定量の定義変更を明示し、posterior の校正や joint MAP を主張しない。
- **音響役**：連続クロックの変調と生理的 VUV を区別する。log の知覚優位は未確定で、平滑化による実在変動の喪失もあり得る。
- **数値解析役**：正核なら実数上の凸包保存を示せるが、格子・端点・IEEE丸めを仕様化する必要がある。200 Hzと400 Hzの混同、単方向と往復の利得混同を指摘した。
- **実験計画役**：L/F×postだけでは正式 PMLとの差を切り分けられない。R,N対照と失敗を含む分母が必要。
- **懐疑的批評役**：下限だけ通れば成功という評価は validator への過適合。元3件で核を選び、同じ3件で検証したと称するのを禁止する。

### 第2巡 修正と残余異議

- **確率モデル役**：L/Fのpotential・遷移・同点規則を凍結し、Nを別名の推定量とする修正を支持。系列モデル自体の改善は今回未検証という異議を残す。
- **音響役**：線形を交絡切分けの主比較、logを将来の別要因とする。最終帯域と許容誤差の根拠が未解決なので、最終核の推奨には反対。
- **数値解析役**：内部格子保持、最寄り値端点、追加clipなしを支持。REAPERの700ちょうど、浮動小数点、下流の別失敗には保証を与えない。
- **実験計画役**：3×2、native完遂と品質可用性の分離、共通集合だけの品質差を採用。全B失敗なら品質改善を識別できないという限界を残す。
- **懐疑的批評役**：3tapは説明用referenceに降格。新核でも既存 filter と応答は違うため、正係数だけの因果効果と主張しない。独立入力・音響ゲート・実装境界が未凍結なので実装と launch に同意しない。

## 9 変更しない不変条件と実装前の障害

- 正式 PML、元の候補 source、失敗原本、既存 baseline と USER_INSTRUCTIONS を不変に保つ。追加 floor/clip、candidate drop、再格子化、別 solver、成功したことにする再試行をしない。
- 新比較でも q=52..512、K=1..10、窓400標本・hop80、c=1、prior、κ=λ=1、二段 F、zero/H0の意味、tie規則を固定する。H0をNMへ変換しない。元manifestは新しい未使用集合の宣言ではない。
- L/Fは J=1+floor((N−1)/80)、anchor=80j、時刻float64 arange(J)×float64(0.005)を維持し、保存gridをuint64 viewでbitwise検査する。Rの元raw/gridと既存resampleをL/Fへ合わせて直さない。異なるgridの配列を同じframeの対応差と呼ばない。
- 入力は16 kHz・mono・実数・有限・[-1,1]・3200標本以上・非零という既存契約と、凍結された区間・SHAを保持する。追加の正規化、clip、silence trim、alignmentをしない。
- 共通の元入力、解析/復号seed=0、strict保存制約、60 FWCEP、SPEC/PDD/NMの一貫再解析、既存save/load/decodeと正確なn_samples出力を保持する。F0だけを保存 payload に差し替えない。同じseedでも時刻ごとの同一雑音を保証しない。
- **現APIの障害**：既存 `analyze` は必ず元 postprocess を呼ぶ。N後のF0をそのまま再投入すれば二重処理になり、非負処理の保証も失う。正式sourceを変更せず、重複codec実装や monkey patch も避けて、processed-F0以後をどう共用するかは新たな最小境界の静的設計が必要。現時点では未解決である。[既存解析](https://github.com/Hiroshiba/check-nonml-saikyo-vocoder/blob/2251f947032296c6cdf03e8022c74eefbeef17e8/vocoderbench/pml/pml_analysis.py)
- 将来もしコード準備が別途承認されても、新規moduleは各400行以下、未採用codeはLibraryのみという保存方針を守る。本稿はコードを作らず、Git/Cloud/Libraryへ書き込まない。

**最終勧告**：失敗を残したまま、非負軌跡処理を別モデル比較として設計する価値はある。ただし最終核、音響的誤差予算、独立入力、既存分析との薄い共用境界が決まるまでは、実装・launch・quality・117件展開・base変更を承認しない。
