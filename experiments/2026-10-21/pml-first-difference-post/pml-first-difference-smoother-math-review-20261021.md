# 一階差分 F0 平滑化案の独立数学レビュー

## 判定

新しい独立候補として検討する数学的根拠はある。ただし formalPML の同値置換、品質改善、物理的に正しい F0、初回 native 失敗の修復成功は主張できない。本レビューは指定 source と保存診断の静的読取・代数のみであり、実装、import、実行、再現計算、測定はしていない。

## 有限区間で成立すること

内部 grid の長さを n≥1、y を clamp 後の補間列とする。D は有限 path 上の隣接一階差分、λ>0、A=I+λDᵀD とする。解 z=A⁻¹y は

J(z)=½‖z−y‖²+½λ‖Dz‖²

の一意な最小点である。任意の非零 v に対して vᵀAv=‖v‖²+λ‖Dv‖²>0 なので A は SPD。

n≥2 の端点行は (1+λ)z₁−λz₂=y₁、内部行は −λzᵢ₋₁+(1+2λ)zᵢ−λzᵢ₊₁=yᵢ。最後の端点も対称である。これは有限差分罰則が誘導する自然端点で、周期接続や固定端点ではない。

A1=1。さらに Au=b≥0 に負の最小成分 uᵢ があると、(Au)ᵢ=uᵢ+λΣⱼ∼ᵢ(uᵢ−uⱼ)<0 となり矛盾する。したがって A⁻¹≥0、A⁻¹1=1。各 zᵢ は y 全体の凸結合なので、厳密実数では min(y)≤zᵢ≤max(y)。定数列は保存する。連結 path・λ>0 では逆行列の各成分は正であり、y が非定数なら各成分は大域的な最小値・最大値の厳密内側に入る。

補強として D A⁻¹=(I+λDDᵀ)⁻¹D。この右側の逆行列も非負なので、Dy≥0 なら Dz≥0。すなわち単調入力は単調出力になり、単調 step の振動も生じない。ただし任意の音声系列について全ての局所的挙動や聴感を保証する定理ではない。「大域範囲保存・単調性保存」と限定して記述するのが正確である。

二階以上の差分では DᵀD の非対角符号構造が変わり、この M-matrix／最大原理の論証を引き継げない。一階差分罰則は曲率罰則ではなく、レベル差そのものを縮める設計である。

## 周波数校正と端点の留保

無限等間隔 grid では H(ω)=1/[1+λ(2−2cosω)]。既存 source は fc=(1/step)/4、hshift=(1/fc)/8 なので、解析上は任意の正の mean step に対して ωc=2πfc·hshift=π/4 になる。名目 5 ms raw なら raw 200 Hz に対して内部 400 Hz、fc=50 Hz だが、校正の成立はこの名目値や L/F に限定されず、REAPER の時刻間隔が厳密な 5 ms でなくても既存内部 grid に対する正規化周波数として同じである。H(π/4)=1/2 には λ=1/(2−√2) が必要十分であり、提案値は正しい。既存 Butterworth の cutoff で単方向振幅 1/√2、理想的な前後方向適用で振幅 1/2 という一点を合わせる校正である。

有限 path の固有利得は k=0,…,n−1 に対して 1/[1+λ(2−2cos(kπ/n))]。有限端点を含む演算全体には単一の LTI 応答を割り当てられず、任意の有限列に対する 50 Hz 利得の厳密一致ではない。既存 filtfilt の端点処理、返却時補間も同等にはならない。

一点一致は帯域全体の一致でもない。一階差分案は低周波でも二次の減衰を持ち、Nyquist で利得は正のままなので、8 次 Butterworth 前後適用とは通過域・阻止域の形が大きく異なる。従って比較結果は ringing の有無だけに帰属できない。raw 200 Hz 上の任意の 3-tap は別の正規化周波数・別の演算であり、この校正や内部 grid 維持の代案にはならない。非負・総和 1 の 3-tap 自体が範囲保存となることは否定しない。

## 全 pipeline と strict gate

既存の raw zero 補間、65–700 clamp、内部 grid の生成式・時刻端点、返却補間、source dtype への代入を維持する必要がある。数学的に同値な式への書換えも浮動小数点の完全同一性とは別である。線形補間と一定端点延長も厳密実数では範囲を保存するため、理想的な pipeline の post は同じ包含を保つ。

L/F の内部入力が 65–500 Hz に入るなら厳密実数で post もその範囲にあり、strict 50<F0<700 には余裕がある。一方、REAPER 由来の入力が 700 を許容するため、無条件の strict <700 は証明できない。特に定数 700 は保存される。非定数入力なら理論上は厳密内側でも、全候補に共通する正の余裕や有限精度での strict 性は別問題である。

浮動小数点 solve、補間、dtype 丸めを含む実装に対して、この実数の証明は厳密包含の証明ではない。既存の finite と strict 50<F0<700 の gate を変更せず残し、失敗時に再 clamp／repair してはならない。StoneMask refined F0 の性質で post F0 の gate を代用してもならない。

## 確率的解釈の限界

独立な Gaussian 観測誤差の分散を σ²、Gaussian 一階増分の分散を τ² と置けば λ=σ²/τ² と解釈できる。ただし増分罰則だけのレベル prior は定数方向に正規化できない improper prior である。観測項を加えた posterior は SPD precision を持つ proper Gaussian となり、その平均と MAP が z に一致する。posterior の標本まで範囲制約を満たすという意味ではない。

今回の λ は帯域を合わせる設計値であって、観測から推定された noise 比ではない。Gaussian 機構の真実性、声の物理的正しさ、selector の尤度の妥当性、モデル改善の証拠にはならない。improper prior の任意な正規化定数を放置した周辺尤度や Bayes factor の主張にも使えない。

## 比較設計への勧告

初回 first3 の保存された成功・失敗と provenance はそのまま参照し、再実行しない。formalPML は変更せず、新候補は明確な別名・別 provenance とする。3 selectors × 2 postprocessors の比較では同一 raw・同一 zero 補間／clamp／内部 grid／返却規約を固定し、変更要因を postprocessor に限定する。失敗結果を隠したり、新候補の成功に置き換えて記録してはならない。

新実験を行う場合も、今回の代数検討は実装・測定の許可そのものではない。最も強い反論は、帯域全体と端点挙動の変更が大きく、成功しても「元の formalPML を維持した修復」ではなく別設計の評価である点である。
