# F0の平滑化を一次差分で比べる

線形Hz上の一次差分でF0を平滑化する別モデル（D1）の設計を保存しました。親からは新しい候補ソースの準備と静的レビューが完了したとの報告を受けています。本計測は未開始で、新しい音声・MOS・品質順位はありません。PMLを唯一の正式ベースとして維持します。

元IIRの[初回L/F失敗](../pml-candidate-tracking/first-native-failure/README.md)と、品質評価の段階B・残り117録音への展開停止は不変です。D1は失敗後に立てた別仮説であり、元実験の修復成功ではありません。

## 最新設計は親レビューの補遺にまとめた

[親設計レビューの補遺](pml-first-difference-post-parent-design-review-20261021.md)が最新仕様です。他の3原文は検討過程と独立レビューの履歴で、準備前の「未実装」「未解決」という表現も当時の記録として残します。

既存の補間・65〜700 Hzへの範囲制限後の列yに、時間刻みΔtで割らない隣接一次差分Dを使います。自然端点で `Az=y`、`A=I+ρDᵀD`、`ρ=1/(2−sqrt(2))` を固定します。名目5 ms格子では内部400 Hz・返却200 Hzで、前後の既存処理を維持します。

実数演算での凸包保証は、float64での厳密包含、真のF0精度、音質の保証とは別です。既存REAPER入力は700 Hzを取り得るため、厳密な `50 < F0 < 700 Hz` を全入力で満たす保証もありません。失敗を追加clipで救済しません。

## 初回3録音は別モデルの開発比較とする

元R/L/Fの推定直後のF0（raw F0）と既存PML音声をバイト同一で再利用し、将来の新R_d1・L_d1・F_d1だけを別実行する計画です。RはREAPER由来、Lは局所選択、Fは系列選択です。

品質比較の予定は既存PMLと新3枝の4音声です。4音声×3録音×4指標の48枝別値に、原音のUTMOS 3値を加える計51個の個別値は、すべて未測定です。初回3録音は開発比較であり、方式採用や固定120録音全体への一般化には使いません。

同じ後処理内の選択器差、同じREAPER rawに対する後処理差、選択器と後処理を合わせた総合差を分けます。旧L/F-IIRには音声がないため、完全な6条件の品質比較ではありません。R_d1だけが良い可能性も残します。
