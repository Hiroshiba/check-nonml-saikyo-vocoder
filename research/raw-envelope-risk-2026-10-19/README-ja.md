# 生高域包絡の移送リスク対照：90条件の途中記録

実験ラベル：2026-10-19。固定5録音の数値観測と、同条件の再実行結果を保存する研究チェックポイント。

## 現時点の結論

**基準方式はPMLのままとする。RAW_FULLは未採用であり、元音高に同期した振幅変調（source-AM）を分離していないリスク対照である。**

- 5録音 × 3音高 × 2 seed × 3方式の90条件が完了した。別実行でも同じ90条件を完了し、対応する全90出力のNPYファイルSHA-256が一致した。
- sample3・+3半音では、RAW_FULLの早期高域パワーが対応PMLから11.88〜14.25 dB低下した。−10 dB交差は保存原音と同じ2.1045秒だった。一方、PML相対では+4/+6 ms後方へ移動しており、既存の警告フラグをそのまま保持する。
- RAW_FULL全30条件のうち25条件に、少なくとも一つの既存の損害フラグが立った。これはPML基準の数値警告であり、25録音の知覚的悪化や原音からの悪化を表す数ではない。
- 相対F0 MAE、unvoiced miss、認識、自動MOSはこのチェックポイントでは未計測。保存分類は「必要観測不足」で、観測済みの早期効果と損害フラグも併記する。品質改善、音素onsetの完全一致、AM分離成功は結論しない。正式120例評価も未実施。

この記録は途中状態の保存を目的とする。実装コード、音声、NPY/NPZ配列、モデルを含まず、新しい公開HTMLも作成しない。既存の測定値・失敗結果・判定閾値は変更していない。

## 2. 何を変えた比較か

元高域波形の二乗パワーを平滑化して時間包絡を作り、既存PMLのGaussian noise（GN）のFFT前の振幅へ渡す。q_AM≡1とし、元F0に同期したAMを取り除く処理は行っていない。周期成分の漏れ、過渡・子音の調音包絡、元音高のAMが一緒に含まれ得る。

65タップの1.5 kHz高域通過FIR、97タップGaussian（σ=9.6標本）、8標本間隔のパワー格子を固定する。保存source F0から求めた局所平均Lに対し、セル内の乗数をa=sqrt((A+ε)/(L+ε))、ε=10⁻¹²とする。セルの元乱数ξ、4096点rFFTをF、元の片側bin平均による正規化量をD0、変調後の正規化量をD1とすると、比較は次のとおり。

| 方式 | GNのスペクトル | 役割 |
|---|---|---|
| PML | F(ξ) / D0 | 元の対応基準 |
| RAW_SHAPE | F(aξ) / D1 | 変調後に再正規化した機構比較 |
| RAW_FULL | F(aξ) / D0 | 形状と正規化量の変化を含む主操作 |

SPEC、NM、編集F0、パルス・セル時刻、後段の複素冪・窓・OLAは固定する。同じ録音・音高・seedの3方式は同じ乱数生成器とdraw順序を使う。異なる音高間で同じseedでも、絶対時刻上で同じ雑音になるとは限らない。完成波形の音量正規化・クリッピングは行わない。

これは未分離包絡を移す複合介入である。「AMなし」「独立時間グリッドだけの効果」「周期枝の完全保持」「最終雑音パワーの指定値への制御」とは解釈しない。

## 3. 固定した観測器と参照

- 帯域パワー：80標本＝5 msのperiodic Hann、hop 16標本＝1 ms、NFFT 128。局所帯域は[1500,3000)、[3000,8000) Hz。
- 交差時刻：保存原音の強部パワー95百分位P*を共通参照とし、−30/−20/−10 dBへ初めて到達した観測中心。固定検索区間内のみを調べ、時刻補間はしない。
- sample3：早期[2.080,2.094)、強部[2.103,2.126)、検索[2.080,2.126)秒。他4例は保存済み各帯域t*から固定した早期・強部・検索区間を再利用する。全区間とP*をJSONに保存する。
- PML比較：同じ録音・音高・seedのPMLを基準に、パワー比は10log10、RMS比は20log10で記録する。正の値同士の比にεを加えない。
- 事前の早期効果基準：sample3・+3半音・RAW_FULLの両seed・両帯域で、早期パワーが対応PMLより3 dB以上低下すること。不要雑音の除去や音質改善の定義ではない。
- 原音相対の交差補助値は、保存出力時刻から保存原音時刻を引いた事後の記述。既存のPML相対フラグを変更・免除する判定には使わない。

1 msの観測格子上で交差が一致しても、有限窓内の形状、物理的な発音開始、音素境界、波形支持端の完全一致を意味しない。音高編集後に対する原音は理想出力や絶対F0真値でもない。

## 4. sample3・+3半音：早期低下と交差後退を分ける

### 早期平均パワーのPML相対差

| seed | 1.5–3 kHz | 3–8 kHz |
|---|---:|---:|
| 0 | −13.2469 dB | −12.9322 dB |
| 20261015 | −14.2529 dB | −11.8807 dB |

事前の3 dB低下基準を両seed・両帯域で満たした。短時間エネルギーの操作が出力観測に現れたこととは整合するが、意図した非周期成分だけを修復した証拠にはならない。

### −10 dB初回交差

この例では下表の時刻が両高域帯域で共通だった。

| seed | 保存原音 | 対応PML | RAW_FULL | RAW_FULL−PML | RAW_FULL−原音 | 既存のPML相対後退フラグ |
|---|---:|---:|---:|---:|---:|---|
| 0 | 2.1045秒 | 2.0985秒 | 2.1045秒 | +6 ms | 0 ms | true |
| 20261015 | 2.1045秒 | 2.1005秒 | 2.1045秒 | +4 ms | 0 ms | true |

既存フラグは「対応PMLより2 ms超後方へ移動したか」を問うため、trueが正しい。PMLが原音より早く交差していた量と、RAW_FULLの後方移動がここでは一致している。**PML相対の+4/+6 msを、原音からattackが+4/+6 ms遅れたという意味へ読み替えない。** 同時に、原音交差との一致を理由にフラグをfalseへ変更しない。

同じ条件の強部平均パワー差は、seed 0で+1.1231/+1.1530 dB、seed 20261015で−0.3248/−0.0395 dB（1.5–3/3–8 kHz）。この局所例で強部1 dB超低下はないが、他条件まで良好だったとは補完しない。

## 5. 全30 RAW_FULL条件の不利な観測と欠測

表の分母は常に5録音 × 3音高 × 2 seed＝30条件。すべて対応PML相対である。RAW_SHAPEも全30条件を同じ定義で記録している。

| 保存フラグ | RAW_FULL true | RAW_FULL false | RAW_FULL欠測 | RAW_SHAPE true |
|---|---:|---:|---:|---:|
| 1.5–3 kHz：−10 dB交差が2 ms超後退／新たな未到達 | 19 | 11 | 0 | 17 |
| 3–8 kHz：−10 dB交差が2 ms超後退／新たな未到達 | 19 | 11 | 0 | 14 |
| 1.5–3 kHz：強部平均パワーが1 dB超低下 | 5 | 25 | 0 | 2 |
| 3–8 kHz：強部平均パワーが1 dB超低下 | 3 | 27 | 0 | 3 |
| 全体RMSが1 dB超変化 | 0 | 30 | 0 | 0 |
| 全体0–1 kHzパワーが1 dB超低下 | 0 | 30 | 0 | 0 |
| 相対F0 MAEが10 cent超悪化 | 0 | 0 | 30 | 0（全30欠測） |
| unvoiced missが2ポイント超悪化 | 0 | 0 | 30 | 0（全30欠測） |
| 自動MOSが0.15超低下 | 0 | 0 | 30 | 0（全30欠測） |

いずれかの既存フラグがtrueの条件はRAW_FULLで25/30、RAW_SHAPEで20/30。フラグ同士は重複するので件数を足さない。RAW_FULLの録音別件数は入力順に6/6、6/6、6/6、1/6、6/6である。警告がない残り5条件も、必要観測が揃った合格例ではない。

早期3 dB以上低下の記述集計はRAW_FULLの1.5–3 kHzで23/30、3–8 kHzで26/30。ただし事前の主効果基準は§4のsample3・+3に限られ、この集計を新しい成功率や採否基準にしない。

局所パワー・交差の収録値は全90条件で利用可能だが、品質関連4項目は全90条件で欠測（計360項目）。認識も未計測であり、欠測をゼロ誤差・品質維持に置き換えない。全30 RAW_FULL条件で「必要な損害観測が不足」を保持する。元音高に同期したAMを分離していないリスクも全条件に残る。

PML相対の警告は、原音からのずれや知覚的劣化と同義ではない。一部では原音に近い交差へ移動しても警告が立ち得る。一方、sample3の一致だけから他録音・他音高の強部や品質まで良化したと推定することもできない。

## 6. 別実験v1の停止と位相診断

先行するAM分離エンコーダーv1は、5/5録音で適格性を満たさず、予定90合成行が停止、合成は0件だった。7周期からの係数同定と保留方式が、この5録音で十分な被覆を得られるという固定仮説は成立しなかった。これは包絡移送後の品質評価ではない。今回のq=1実験でv1の失敗・閾値・未知状態を成功へ書き換えない。

保存F0の積分位相とREAPER推定epochの記述比較では、局所位相変動があった。sample3の固定区間には5 epochがあり、円周集中R=0.86075、隣接位相増分は0.88421〜1.14635周期。同じ7周期支持には大きなパワー変動もあり、位相だけを停止の原因に絞れない。

さらに、周期パワーmax/min≤2なのにv1不適格となった33節点のうち、単一runで3 epoch以上を持つ19節点はR=0.99370〜0.99989だった。残り14節点は3 epoch未満のためRを算出していない。この19節点には分散不適格を含む10節点があり、高い位相集中と元の不適格が共存する。支持が重なる節点を独立標本とは扱わない。全1797隣接対で最近整数の位相増分が1以外の例はなかったが、物理的なepoch欠落・過検出がない証明ではない。

推定epochは真値ではなく、この診断からAM再推定の成功や品質改善を結論しない。pyreaperの一致SHAはPython wrapperを指し、compiled extension binaryの同一性は未確認である。

## 7. 再実行の証拠と残る作業

A/Bの全90条件キーが一致し、対応NPYのSHA-256は90/90一致した。これは保存ファイルの決定論的な再現の証拠であり、観測器の正しさ、因果分離、品質改善を証明するものではない。全測定receiptのbytes同一性を主張していない。

主要な識別子：

- 科学ソースfreeze SHA-256：`a0ccd38bc96d361411a85c7658c325157a7f27d3886cc5efdcbe09c3dff5f695`
- 固定仕様SHA-256：`63c904ca9e5e1dfb06f318c1b50cfef3ca445247c584acf202e4bbeaaeceaf01`
- 入力manifest SHA-256：`85d49b80bd00293eac7a44ef9eadd94e1a349872b2e03099b46a7ff21fe49b20`
- Aの測定receipt SHA-256：`b4bf35744446638591e9c8f7bff3f255b08315c47ca6b52687ed1801caeb5956`
- Bの測定receipt SHA-256：`f0fb857bda6041d7a174c67266a643015347a981c14938dcfd29cbb2ad14337b`

各入力・出力・観測記録の対応SHAと実行環境は[reproducibility.json](reproducibility.json)に保存する。SHAは証拠の識別子であり、未同梱のソースや波形を復元するものではない。このGitチェックポイントだけで全処理を再実行できる完全な再現パッケージとはしない。

次は固定済み出力に対する相対F0・unvoiced miss・認識・自動MOSの評価を別途完了し、このDraftへ追記する。現在の未計測を消して先に合格扱いせず、追記時には評価器と出力SHAの対応を明示する。今回の保存作業では再合成・波形再計測・モデル実行・ソフトウェアテストを行っていない。正式120例評価、採用、音高ごとの方式選択、利得や平滑幅の調整はこの記録の結論に含まれない。
