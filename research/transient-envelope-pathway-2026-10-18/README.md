# サンプル3：後続入力から先行雑音への経路を切り分ける

2026-10-18 UTC / 2026-10-19 JST。PR #44の比較を終えた後の原因診断。PMLを唯一のbaseとして維持し、新しい採用候補の実装ではない。

## 観測

既知のLibriSpeech録音 `librispeech_121-121726-0012` の同じ原音・保存PMLを使用。保存FWCEPは導入済みpyworld 0.3.5でfloat32全成分の一致を再現した。2.095秒の解析F0は97.327181Hz、理想解析窓は30.823866ms。これは正のF0が有声の真値であるという意味ではない。

原音のStoneMask F0を固定し、2.100/2.103/2.106秒以降をhold、過去方向の反転、zeroに置き換えた9条件と原音2回、計11解析を実施。全条件でフレーム列・FFT・F0は同じ。ゼロ置換は境界不連続を含むストレス条件。

2.103秒から後のhold/反転で、2.095秒の解析包絡は1.5–3kHzで−18.1028/−17.8272dB、3–8kHzで−14.0750/−13.9527dB変化した。分母は同じ時刻の改変前原音。2.080秒のフレームは全条件で不変、2.090秒フレームは2.106秒からの変更で不変。原音の技術的反復は一致。

## 合成への伝播

2.103秒以降をhold/反転した解析結果から、保存FWCEPの419行（2.095秒）だけを置換。他の包絡、マスク、F0、合成時計、乱数seed0を固定し、native/±3半音を各3条件、計9波形生成。元解析から419行を再符号化した値も保存値と一致。

- nativeと−3半音ではこの行を参照しないため、波形差は0。影響が一般に存在しない証拠ではなく、当該行を使わない対照条件。
- ＋3半音はパルス446がこの行を参照。最初の波形差は2.0874375秒。
- 5ms周期Hann・1ms刻み・FFT128の帯域powerでは、中心時刻2.080–2.094秒の平均が、holdで1.5–3kHz −12.6413dB、3–8kHz −12.5436dB、反転で−12.6201/−12.5043dB変化。
- 窓は中心の前後2.5msを含む。これは聴感上の開始時刻・音質改善量ではない。
- ＋3と−3の未介入波形hashは、先行する720枠の低域参照実験の対応するPML基準波形と一致。

後続の入力が早い特徴へ入り、その特徴がさらに早い合成時刻へ反映される経路を、固定介入で確認した。置換した未来は真の音声ではない。最小位相の変化も伴うため、物理的な破裂音成分だけを除去したとは言わない。低い雑音powerだけでは良い方法と判断できず、全120録音への一般化・新baseへの採用は行わない。
