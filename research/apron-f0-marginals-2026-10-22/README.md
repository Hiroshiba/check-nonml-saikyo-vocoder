# ApronのF0点列とpYINの候補支持量

固定したLibriSpeech test-cleanの120録音・40話者、計123,307フレームについて、保存済みのpYIN状態モデル内で無声状態と有声F0候補が受ける周辺質量を記録した。現在の作業ベースApronが保存したF0点列は、同じ録音の文脈として2例の図に重ねた。Apronの点列はLLSMによる調整後、pYINの支持量は調整前であり、両者の差をF0精度や音質の差とは読めない。

録音を等重みにした平均は、モデル内の無声状態全体が0.614275、有声候補全体が0.385725だった。無声状態は無音の判定ではない。有声の最頻ビンからの距離を10セント刻みで全975位置に並べた図も、真の音高からの誤差ではない。中心位置が最大になるのは最頻ビンを中心に選んだ定義による。解釈と限界は[HTML](index.html)に記した。既存の[Apron品質評価](../apron-fixed120-evaluation-2026-10-22/index.html)は別の測定であり、この診断に品質順位は付けない。

公開した[要約](summary.json)には数値診断と120録音の元配列SHAを、[個票目録](index.json)には各録音JSONの容量・SHAを残した。`recordings/`の120ファイルは保存済み草稿から原bytesのまま選んだ。5枚のPNGも元bytesのままで、[図の来歴](figure-sources.json)には元配列のSHAと表示尺度を記載した。[計測来歴](provenance.json)には固定入力、pYIN引数、実行環境、科学source、抽出・解析ownerのseal識別を記録した。これらは保存結果の公開用抜粋であり、第三者が測定を独立再実行したという意味ではない。

再計算する場合の科学手順と元sourceはcommit `1a1181bac001fae325a5381cd9a11f6b07076b75` の `experiments/2026-10-22/apron-f0-marginals/README.md` と `scripts/apron_f0_marginals/`に固定されている。16 kHz mono float64原入力を`resample_poly(x,3,2)`で24 kHzへ変換し、公開`librosa.pyin`を各録音に1回呼んで実際のO・T・piを保存した後、保存因子を前後向き計算に用いた。保存済み7実行のexit・回収状態は要約と来歴で追える。インストール済みlibrosaの`core/pitch.py`と`sequence.py`は参照commitのblobに一致したが、wheel全体の来歴までは証明していない。

観測因子Oの全配列と有声ビン対数周辺量の全配列はローカル保管で、ここには含めていない。公開個票には各フレームの無声・有声の対数全量と、録音ごとの無条件offset平均を含めた。新しい音声は追加していない。HTMLの試聴は、既公開の2録音の原音とApron無編集の先頭5秒にだけリンクする。音声の出典と改変条件は[既存の帰属表示](../apron-fixed120-evaluation-2026-10-22/audio-credits.html)を参照してほしい。固定120録音は開発にも使っており、未知の最終検証集合ではない。
