# 調査資料と確認範囲

`research_index_ja.html` と `research_sources.json` は、ユーザーが提供した過去のAI調査資料を内容変更せず保存したもの。307論文・339非論文等の件数はその資料の記録であり、今回新たに全件を精読した件数ではない。

今回直接確認した一次資料・公開文書と、そこから導いた判断は `experiments/2026-10-11/comparison-workbench/reviews/` の各文書に分けて記録した。WORLD、Harvest、LLSM2、Rubber Band、Signalsmith、指標の限界、LibriSpeech等の少数の関連資料を再確認した。多数の引用が同じ開発者・プロジェクト由来の場合、独立した多数の支持とは扱わない。

資料の分布を分野全体の支持率へ読み替えない。新しい方式を提案する際は、出典が実際に述べることとAIの解釈を区別し、必要な部分の確認範囲を更新する。既存資料のURLや要旨だけから実装や数値を正しいとみなさない。
