# PML追加評価の棚卸し（2026-10-16）

対象: 低域雑音マスク拡張PML＋60FWCEP。今回のPRは評価中のdraft。現行197派生軸を今回の38派生軸で置き換えて完了としない。

mainの現ベースはHNM v3を維持する。このdraftのBASELINE変更・旧HNM削除は未マージの置換案であり、追加評価後に採用判断する。

## 既存データの範囲

- 既存公開レポート `research/all-method-final-2026-10-15/results.json.gz`: 18群、197派生軸。18群以外の既存音響65軸・速度6軸等も含む。未対応・欠測も残るので197全て成功という意味ではない。
- 凍結研究の最終比較: 120録音40話者、うち設定選択と分けた108録音36話者を主集計。38軸は予測MOS、40ms ERB、スペクトル相対L2、RMS/SNR、YIN、局所区間、レベル、支持数など。eSTOI・SCOREQ・ECAPA・ASR等は入っていない。
- 凍結研究のピッチ操作比較: ピッチ操作は使用済み10録音の原因分析。さらに密な包絡のPMLであり、FWCEP60版の120録音操作評価を代替しない。
- 今回のPMLパッケージは旧研究コードを整理した版。旧研究の波形を引用する場合は「凍結研究版の評価」と明示する。新パッケージの評価と呼ぶにはその版の正式120録音処理が必要。テスト/スモークで置き換えない。

## 再利用の重要な境界

既存共通時間窓は最短方式GOLF等により、例えば6秒入力でも5.99秒。PML研究の全長6秒誤差をそのまま同じランキングへ入れない。旧197軸の話者bootstrap seed=20261014・同順位許容差と、PML研究のseed=20261015・厳密値の競技順位も異なる。新順位は既存契約に固定して保存rawから計算する。38軸は別の原因分析として保持する。

旧比較方式のスカラーは前処理・対象・評価器が同一の範囲で引用する。共通支持にPMLを加えると集合が変わり得るので順位・差・CIは再集計する。旧HTMLを上書きして当時の順位を変えない。

## 実行順と終了条件

1. 固定新run、候補版hash、旧baseline比較ID、全予定ケース/条件を保存。候補を旧HNMとして扱わない。
2. 主120の正式無編集処理を最初に完了し、保存済み旧波形/評価値の引用可否を確認。合成・特徴・失敗情報は録音単位で逐次保存する。
3. P1の音響/SCOREQ/ECAPA/ASRを並行可能な資源単位で計算。速度計測時間だけは他のCPU推論を止めて独立させる。
4. 120×4編集、編集品質、特徴ABX/読み出しを実施。重い節目評価は一度の依頼分として実施し、日常比較の既定へ無条件追加しない。
5. ASV/VCTKと補間/量子化は可用性・対応契約を先に整理し、未対応/適用外の理由を全予定行に記録。入力不足を手近な数例で置き換えず、補助集合として別表示する。
6. 予定行にpending/running/記録欠落がなく、成功には波形/評価器/入力のSHAと有効数があり、失敗・未対応・資源ブロックには具体的な根拠がある状態で集計。『全成功』と『全予定の状態が確定』を分ける。
7. 旧HNMとの差だけでなく既存7方式の各軸順位と有効数、トレードオフを示して採否を再判断。未対応があることを理由に自動採用も自動却下もしない。

## 資源見積り（容量のみ概算、所要時間は未測定）

主120合計615.935秒。16k float32は1条件約39.4MB、float64は約78.8MB。無編集+4編集でfloat32約197MB。PML特徴本体は1集合約62MB、train120を追加すると同程度。診断trace/dense SPEC/PDDを全条件へ複製しない。大量の中間包絡配列を重複保存しない。推論モデルは既存取得済みをhash確認後再利用し、複数コピーしない。モデル推論時間とABXの実所要は未見積りのため数十分等の約束をしない。
