# 比較方法と結果の読み方

本書はAIによる測定仕様。ユーザー指示や聴覚上の保証値ではない。実行実装は `vocoderbench/`、全値は結果JSONに残す。

## 入力と比較範囲

初回は、評価対象のデコーダーとは独立に生成した10種類の人工信号を16/24/48 kHzで実行し、LibriSpeechの2話者の章単位の音声から、固定した先頭6秒を追加する。人工信号は、正弦波、整数倍の周波数成分を重ねた調波音、基本波を除いた調波音（missing fundamental）、基本周波数が連続変化する音（F0 sweep）、パルス列とIIR共鳴器による音、振幅を周期的に変化させたAM雑音、有声・無声の切替、無音、インパルスである。IIR共鳴器は、過去の出力を使うフィルタで声道の共鳴に似た周波数特性を作る。自然音声の切り出し区間は、元コーパスの発話単位とは一致しない。

F0測定器の追加校正信号は `vocoderbench/fixtures.py` に含み、`vocoderbench.calibrate_pitch` で測定する。これらは今回の音高測定の反例を検査するためのもので、コーパスの話者数に含めない。

F0は基本周波数を表し、ここでは音高を測る物理量として使う。WORLD DIO/Harvestは解析器だけが異なる。LLSMには同じWORLD DIOのF0を供給するため、F0の誤りを共有し得る。LLSM固有の表現をWORLDの表現へ変換せず、本来の層0（layer 0）による解析・合成を実行する。`identity`は原音をそのまま返す測定器検査であり、比較対象の品質ランキングから除外する。

## 共通前処理

モノラルPCM波形を、固定の振幅尺度で64-bit浮動小数点（float64）へ変換する。音量の正規化、波形の自動整列、局所的な時間伸縮で対応位置を合わせるDTW、無音除去はしない。自然音声は16 kHzのまま使う。各ケースはすべての比較対象に同じ配列を渡す。入力配列と元ファイルの内容を照合するハッシュ値、および切り出し位置を記録する。

WORLDはC/C++実装の呼出し口であるC APIへ要求サンプル数を指定して合成し、その後の切り詰めやゼロ埋めはしない。LLSMはC実装が生成する余分な末尾を入力長まで切り、切る前の長さ、切ったサンプル数、固定遅延0をメタデータに残す。この規則は最適な整列を探索したものではなく、末尾の品質を保証しない。

## 再合成の測定

| 軸 | 定義 | 限界 |
|---|---|---|
| 多解像度スペクトル | Hann窓5/20/80 ms、窓を進める間隔（hop）は窓長の1/4。振幅のdB絶対差平均と、振幅スペクトルの相対誤差（spectral convergence） | 同じ雑音統計でも実現波形が異なると誤差が出る。知覚スコアではない |
| 帯域エネルギー | 0/200/500/1000/2000/4000/8000/16000/Nyquistのうち、対象サンプルレートの範囲内の境界で分割。Parsevalの関係に従う重みを付けたパワーを比較 | 聴覚の周波数分解能を近似するERB尺度ではない。全時間平均なので局所劣化を隠し得る |
| レベル | 波形RMS比の20 log10、出力RMSのdBFS値とピーク振幅 | 元が無音なら音量の比は未定義。無音への雑音付加は出力RMSとピーク振幅で見る |
| 音高 | 独立したYIN型の差分測定器を用い、既知のサンプル単位F0に対する誤差をcentの中央値/P95、欠測・誤有声・大誤りとして記録 | 広帯域刺激に対する前処理と校正を実装・校正記録に記録。全波形への正確性を保証しない |
| 境界 | インパルス付近の5 msエネルギー最大位置と既知位置の差 | 自然子音の境界精度ではない。平滑窓と雑音で位置が動く |
| 正常性 | 長さ差、値が有限であること、例外、繰返し実行した出力の最大差 | 正常動作と品質は別 |

STFTは、波形を短い窓に分けて周波数成分を調べる短時間フーリエ変換である。MR-STFTは複数の窓長で測った結果を使う。spectral convergenceは、振幅スペクトルの差のノルムを参照側のノルムで割った値である。Nyquistはサンプルレートの半分の周波数を指す。Parsevalの重みは、周波数側のパワーを波形側の平均二乗値と対応させるためのもの。RMSは二乗平均平方根による振幅、dBFSは基準振幅に対するデシベル表示である。centは音高差の単位であり、P95は測定値の95パーセンタイルを表す。

表のSTFT誤差・帯域の絶対誤差・cent誤差は小さいほど参照に近い。符号付きのRMS差は正なら出力が大きく、負なら小さいことを表す。比較基準に対する誤差の差分（Δ）が負なら、その指標の誤差が比較基準より小さい。これらを自然性や総合品質の順位と同一視しない。

対数計算に使うSTFT振幅の下限値（floor）は、参照STFT最大振幅の1e-5と1e-10の大きい方とする。帯域パワーの下限値は1e-12。帯域の集約対象は参照パワーがmax(1e-12,全パワー×1e-6)を超える帯域で、全帯域値と有効帯域数も残す。無音などで未定義の値を0にしない。

F0は、全サンプルが入力内に収まる80 msの分析区間（フレーム）を10 ms間隔で取り、65–700 Hzを測定範囲とする。真値の有声・無声を跨ぐフレームは境界として別計数し、cent誤差や有声・無声（UV）の集計に入れない。`valid_voiced_frames / expected_voiced_frames`は「測定できた有声フレーム数／正解が有声のフレーム数」、`false_voiced_frames`は「正解が無声なのに有声と測定したフレーム数」である。境界数、全フレーム数も併記する。自然音声には絶対正解F0がないため、同じ測定器の出力差は推定された相対変化と表示する。

F0診断だけに、固定2 kHz・6次Butterworthの低域通過フィルタを、前向きと後向きに適用する（forward/backward）。端点では最大80 msの波形を偶対称に反射して延長する（even反射）。これは広帯域で周期がサンプル数の整数にならない反例への対策で、すべての方式・信号に同じ処理を行う。STFT・帯域・レベルの測定波形は加工しない。2 kHz以下に十分な周期成分があることが必要で、高域だけの周期性や自然音声全般での精度は未校正。[校正と前処理比較](F0_CALIBRATION.md) に78ケースの結果と限界を記録する。

## 操作の測定

WORLDの2構成で±3半音、±6 dB、時間1.25倍を測る。これは初回試験値であり対応品質の保証範囲ではない。対象は16 kHzの110 Hz調波音、有声・無声の切替、インパルス、自然音声2区間。

- 音高（pitch）は正のF0だけを倍率変更し、無声は0のままにする。既知F0への誤差と未操作出力からの相対変化を別に記録する。
- 音量（gain）はスペクトルのパワーを10^(dB/10)倍する。指定した変化量と波形RMSから測った変化量との差を追従誤差とする。
- 時間長（duration）は、必要なサンプル数を四捨五入し、ちょうど中間なら大きい整数へ丸める（round-half-up）。F0は有声の連続区間内で対数補間する。有声・無声の状態を音高と分けて扱い、無声区間を有声で橋渡ししない。パワーは対数、非周期性（aperiodicity）の振幅比は線形補間する。
- 時間操作は全長誤差と既知イベントの時刻を測る。動的・複合操作や自然音声の局所タイミング保持は別の未完了課題とする。
- 手作りの平坦なスペクトルと有声・無声のパラメータから合成し、エンコーダーを通さずに実行できることを確認する。自然音声品質の正解刺激とは扱わない。

LLSMの操作は未実装と表示し、0誤差や合格に置き換えない。任意の知覚語の制御、話者類似距離はまだ判定しない。

## 再現性と集約

入力生成用と合成器用の乱数は分ける。seedは、乱数列の初期状態を指定する値である。WORLDのオフライン合成は上流実装が呼出しごとに固定状態で初期化するため、外部からのseed指定はない。LLSMはC標準ライブラリ（libc）の乱数をseed+1で初期化し、同一環境の同じseedで一致することを確認する。LLSMのC実装を複数スレッドから並列に呼び出さない。別環境でのビット単位の一致や、複数seedによる平均品質は今回の証拠に含めない。

比較時に全ケースの行を残す。要約は自然音声と人工信号を分け、有効数・失敗数を併記する。少数ケースの中央値は診断値であり、人の評定を平均したMOS、分野全体の順位、有意差の証拠ではない。フレーム数を独立した話者の数とみなさない。

正式なベース手法がある場合は、そのIDと版（version）を結果に必ず記録する。初回はベース手法が未選定であることを明記し、差分の表示基準を `world_dio` に固定する。初代を選定した後は、最新のベース手法と同じ条件で比較し直して採否を決める。

## 未実装の評価

eSTOI、ViSQOL、固定MOS予測器、既存人間評定への校正、話者の知覚距離、信頼区間を伴う多話者評価、長時間・動的・複合操作は未実装。これらを実施済みと扱わず、音響誤差だけから人にとっての自然性・透明性を主張しない。
