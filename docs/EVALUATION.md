# 比較方法と結果の読み方

本書はAIによる測定仕様。ユーザー指示や聴覚上の保証値ではない。実行実装は `vocoderbench/`、全値は結果JSONに残す。

## 入力と比較範囲

初回は、独立生成の10種類の人工信号を16/24/48 kHzで実行し、LibriSpeechの2話者のchapter音声から固定した先頭6秒を追加する。人工信号は正弦波、調波、missing fundamental、F0 sweep、パルス列とIIR共鳴器、AM雑音、有声無声切替、無音、インパルス。自然音声区間は元コーパスの発話単位とは一致しない。

F0測定器の追加校正信号は `tests/test_metrics.py` に含む。これらは今回の音高測定の反例を検査するためのもので、コーパスの話者数に含めない。

WORLD DIO/Harvestは解析器だけが異なる。LLSMには同じWORLD DIOのF0を供給するため、F0誤りを共有し得る。LLSM固有表現をWORLDの表現へ変換せず、本来のlayer 0解析合成を実行する。identityは測定器検査であり比較対象の品質ランキングから除外する。

## 共通前処理

mono PCMをfloat64へ固定スケールで変換し、正規化・自動整列・DTW・無音除去はしない。自然音声は16 kHzのまま使う。各ケースはすべての比較対象に同じ配列を渡す。入力配列hash、元ファイルhash、切り出し位置を記録する。

WORLDはnative C APIへ要求サンプル数を指定して合成し、後段crop/padはしない。LLSMはnativeが生成する余分な末尾を入力長まで切り、native長・切った数・固定遅延0をメタデータに残す。この規則は最適な整列を探索したものではなく、末尾の品質を保証しない。

## 再合成の測定

| 軸 | 定義 | 限界 |
|---|---|---|
| 多解像度スペクトル | Hann 5/20/80 ms、hopは窓の1/4。振幅のdB絶対差平均とspectral convergence | 同じ雑音統計でも実現波形が異なると誤差が出る。知覚スコアではない |
| 帯域エネルギー | 0/200/500/1000/2000/4000/8000/16000/Nyquistの範囲内境界でParseval重み付きpowerを比較 | ERB尺度ではない。全時間平均なので局所劣化を隠し得る |
| レベル | 波形RMS比の20 log10、出力RMS dBFSとpeak | 元が無音ならゲイン比は未定義。無音への雑音付加は出力RMS/peakで見る |
| 音高 | 独立YIN型差分測定、既知のサンプル単位F0に対するcent中央値/P95、欠測・誤有声・大誤り | 広帯域刺激に対する前処理と校正を実装・テストに記録。全波形への正確性を保証しない |
| 境界 | インパルス付近の5 msエネルギー最大位置と既知位置の差 | 自然子音の境界精度ではない。平滑窓と雑音で位置が動く |
| 正常性 | 長さ差、finite、例外、繰返し最大差 | 正常動作と品質は別 |

STFTの振幅floorは参照STFT最大振幅の1e-5と1e-10の大きい方。帯域power floorは1e-12。帯域の集約対象は参照powerがmax(1e-12,全power×1e-6)を超える帯域で、全帯域値と有効帯域数も残す。無音などで未定義の値を0にしない。

F0は80 ms完全フレーム、10 ms hop、65–700 Hzを測定範囲とする。真値の有声無声を跨ぐフレームは境界として別計数しcent/UV集計に入れない。`valid_voiced_frames / expected_voiced_frames`、`false_voiced_frames`、境界数、全フレーム数を併記する。自然音声には絶対正解F0がないため、同じ測定器の出力差は推定された相対変化と表示する。

F0診断だけに、固定2 kHz・6次Butterworthのforward/backwardフィルタと、最大80 msのeven反射を適用する。広帯域で周期がサンプル数の整数にならない反例への対策で、すべての方式・信号に同じ処理を行う。STFT・帯域・レベルの測定波形は加工しない。2 kHz以下に十分な周期成分があることが必要で、高域だけの周期性や自然音声全般での精度は未校正。[校正と前処理比較](F0_CALIBRATION.md) に78ケースの結果と限界を記録する。

## 操作の測定

WORLDの2構成で±3半音、±6 dB、時間1.25倍を測る。これは初回試験値であり対応品質の保証範囲ではない。対象は16 kHzの110 Hz調波、UV切替、インパルス、自然音声2区間。

- pitchは正のF0だけを倍率変更し、無声は0のまま。既知F0への誤差と未操作出力からの相対変化を別に記録する。
- gainはスペクトルpowerを10^(dB/10)倍する。波形RMSの変化量との差を追従誤差とする。
- durationはサンプル数をround-half-upし、F0は有声の連続区間内で対数補間する。voicingを独立に扱い、無声区間を有声で橋渡ししない。powerは対数、aperiodicity振幅比は線形補間する。
- 時間操作は全長誤差と既知イベントの時刻を測る。動的・複合操作や自然音声の局所タイミング保持は別の未完了課題とする。
- hand-madeの平坦スペクトル・有声/無声パラメータから合成し、encoderなしでの実行を確認する。自然音声品質の正解刺激とは扱わない。

LLSMの操作は未実装と表示し、0誤差や合格に置き換えない。任意の知覚語の制御、話者類似距離はまだ判定しない。

## 再現性と集約

入力生成seedと合成器の乱数を分ける。WORLD offlineは上流が呼出毎に固定状態で初期化するため外部seed指定はない。LLSMはlibcの乱数をseed+1で初期化し、同一環境の同seedで一致することを確認する。LLSMをthread並列でnative呼出ししない。別環境のbitwise一致や多seed平均品質は今回の証拠に含めない。

比較時に全ケースの行を残す。要約は自然音声と人工信号を分け、有効数・失敗数を併記する。少数ケースの中央値は診断値であり、MOS、分野全体の順位、有意差の証拠ではない。フレーム数を独立話者数とみなさない。

正式baseがある場合はそのID/versionを結果に必ず記録する。初回はbase未選定を明記し、差分の表示基準を `world_dio` に固定する。初代を選定した後は、最新baseと同じ条件で比較し直して採否を決める。

## 未実装の評価

eSTOI、ViSQOL、固定MOS予測器、既存人間評定への校正、話者の知覚距離、信頼区間を伴う多話者評価、長時間・動的・複合操作は未実装。これらを実施済みと扱わず、音響誤差だけから人にとっての自然性・透明性を主張しない。
