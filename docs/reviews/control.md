# 制御・表現担当レビュー：複数比較対象に共通の操作測定

日付: 2026-10-11。担当: control_research。ユーザー指示ファイルを確認済み。本稿は AI による調査・提案であり、ユーザー指示を追加・変更しない。実装・実験は未実施。

## 一次資料で確認した根拠

- [WORLD 公式 README](https://github.com/mmorise/World): F0、非周期性、スペクトル包絡から解析・再合成する実装。DIO/Harvest、CheapTrick、D4C の出典がある。比較対象として利用可能であることを確認したが、本プロジェクトの最良手法とはまだ判定していない。
- [Harvest 論文要旨, Morise 2017](https://www.isca-archive.org/interspeech_2017/morise17b_interspeech.html): 時間的な F0 候補の接続と、EGG 付き 2 データベースによる評価を報告。DIO と同じ合成器に接続して解析器の影響を比較する理由になる。あらゆる発声での優越を意味しない。
- [LLSM2 公式 README](https://github.com/Sleepwalking/libllsm2): layer 0 の調波・雑音表現と layer 1 の音源・フィルタ表現を分離する。調波位相と雑音の時間形状を持つ一方、固定次元の符号化では一部を失う。詳細保持と操作を別々に測る実装上の先例。
- [Rubber Band 開発者資料](https://www.breakfastquay.com/rubberband/integration.html): 固定・動的ピッチで設定が異なり、操作タイミングと入出力遅延、終了処理を区別している。静的な一点の操作成功から動的操作の成功は導けない。
- [Signalsmith Stretch 公式 README](https://github.com/Signalsmith-Audio/signalsmith-stretch): 入力側・出力側遅延、automation、seek/flush を別に扱う。時間比率と最終出力長だけでは局所時刻の正しさを保証しない。
- [PyWorld 実装](https://github.com/JeremyCCHsu/Python-Wrapper-for-World-Vocoder/blob/master/pyworld/pyworld.pyx): synthesize の出力長はフレーム数と frame period から計算される。D4C の ap は包絡に対する線形振幅比と説明される。
- [WORLD 合成実装](https://github.com/mmorise/World/blob/master/src/synthesis.cpp): ap を二乗して周期・非周期の配分に用い、sp から振幅を得る。パラメータの単位を混同する実装を防ぐため参照した。

確認範囲は上記 README・開発者文書・論文要旨・関連ソース関数。文献全体を新たに精読したわけではない。この少数の資料から分野全体の支持率は計算しない。

## 提案：最良を先に決めず比較可能性を作る

親エージェントから共有された追加指示に従い、複数の比較対象と比較方法の整備を先行する。WORLD DIO + StoneMask / WORLD Harvest は同じ CheapTrick・D4C・合成器で比較でき、解析差を切り分けやすい。LLSM2 は詳細位相・雑音時間構造の比較対象として価値がある。独自 HNM の品質優位を裏付ける本プロジェクト内の証拠はまだない。

比較対象ごとに native parameter を保存し、比較 API と測定軸を共有する。すべてを WORLD の 3 特徴へ変換すると、LLSM2 が保持できる細部を捨てた比較になりうる。未対応の操作は明示的に unsupported とし、0 誤差で埋めない。

現段階で扱う操作名は F0、gain、duration とする。「息っぽさ」「張り」「真の声道固定」「知覚上の声質距離」は未検証。pitch shift のスペクトル包絡固定は、声道の生理的固定の証拠にはならない。

### 共通の比較ケース

| ケース | 目的と測定 | 注意 |
|---|---|---|
| 無加工再合成 | 原音との多解像度スペクトル差、帯域エネルギー差、F0・有声無声・境界 | 元波形との比較と、操作差の基準となる再合成を分ける |
| F0 の静的操作 | cent 追従誤差、方向・単調性、非対象の duration/level/帯域包絡の変化 | 原音との STFT 類似度だけで順位づけしない |
| gain | 指定 dB と波形 RMS 比の差、その他パラメータの変化 | クリップしない信号を用い、波形 gain と power gain を区別 |
| duration | 要求 sample 数との差、既知イベント時刻、立上がり幅、末尾の保持 | crop/pad により全長だけ合っても成功とはしない |
| 表現の安定性 | 入力 gain・時間シフトに対する期待変換との差 | 全特徴不変を要求しない。単位は cent/dB/ms などに固定 |
| 動的・組合せ操作 | 掃引の連続性、操作時刻、複合漏れ | 未実施なら制御性全体を合格としない |
| 手作成・補間特徴からの合成 | decoder 単体の正常性・操作追従 | encoder が出した特徴だけを受理できる系と区別 |

探索条件案は F0 ±3/±6 半音、gain ±6 dB、duration 0.75/1.25/1.5 倍。これらはユーザー要件でも品質保証域でもなく、比較のための仮条件。20 cent 等の過去 AI 提案値を受入条件として固定しない。まず測定器の誤差と実測分布を出す。

## 実装時に必要な反例と検査

1. F0 = 0 を log 補間して非有限値になる、0 と有声を線形補間して偽の低 F0 を作る反例。voicing と有声音高を区別し、有声領域内でのみ対数音高を補間する案を比較仕様に残す。境界での選択規則も記録する。
2. sp は power として gain dB を変換し、ap は振幅比として扱う。sp の正値、ap の有効範囲、すべての配列の有限値・shape を検査。上流が黙って補正する値でも、adapter が与えた異常値は別計数する。
3. 指定長、native 合成長、crop/pad 数を別々に出す。既知イベント付き刺激で末尾を測り、自然音声では末尾 20–50 ms のエネルギーを診断する。人工的な無音 padding を「保持された音声」と数えない。
4. gain 入力変換の同変性: E(a x) に対し F0 と ap の変動、sp の期待 power 比との差を測る。無音・微小振幅では floor の効果を別集計する。
5. 時間シフト安定性は境界と内部を分ける。開始位置 1 sample・半フレーム・1 フレームを変更し、変換を戻したパラメータ差を出す。境界区間を除外した場合も区間数・理由を記録する。
6. F0 既知刺激は独立生成の正解軌跡を使う。自然音声は encoder と別系統の測定器を診断に用い、測定不能率・有声無声不一致を必ず併記。ACF 自体にも倍音強調・missing fundamental・noise・境界の校正試験が必要。
7. 再現性は同条件での二度の合成を実測し、保存・読込後にも検査する。外部実装が seed を公開しない場合に「8 seeds 実施」と装わない。

## 5 人議論でのやり取りと反映

- 音響担当へ、独自 HNM を WORLD より先に採用する音響証拠があるか質問。現時点ではないとの応答。単純な HNM は比較候補にとどめ、位相・時間雑音の効果は一要因ずつ比較する。F0/gain/time から始め知覚語を認証しない点で一致。
- 評価担当へ、ACF の倍音誤りと有声境界の除外が結果を歪めないか質問。既知 F0 を正解とし、独立測定器も校正し、自然音声の不一致・除外・測定不能を報告することで一致。操作音声の原音類似度で順位をつけないという反論を受け、無加工品質と操作差を分離した。
- 批評家へ、最小ゲートに不足がないか質問。元波形との差と無加工再合成との差の双方、測定 coverage、gain のクリップ回避、既知イベント試験が必要との応答を反映。過去 AI 提案閾値はユーザー要件でないことを確認した。
- 実装担当へ、crop/pad による全長一致が末尾欠損を隠さないか質問。requested/raw/crop-pad samples とイベント診断を分けることで一致。実装担当からの境界補間の問いに、voicing mask と有声内 log F0 を分ける反例検査を返した。

## 到達範囲

最初に完成できるのは、同条件で再実行できる複数比較対象の測定契約であり、高品質・透明性・知覚制御性の証明ではない。初回の WORLD 内の解析器対照は原因切り分けに有用だが、方式多様性を満たす比較の代用にはしない。正式 base は実験の証拠から 1 つだけを選び、その時点までの未検証領域を結果 HTML に残す。
