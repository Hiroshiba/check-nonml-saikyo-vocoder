## 初回のリポジトリ設定

リポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選びます。この設定にはリポジトリの管理権限が必要です。ソースを変更するPRだけでは、この管理設定は変更されません。

`main` へのマージで `実験記録の公開` ワークフローが動きます。初回設定を後で行った場合は、Actionsから同ワークフローの **Run workflow** を実行してください。公開URLはデプロイジョブの環境リンクでも確認できます。

PRでは静的解析だけを行い、サイト生成の予行はしません。サイト生成・内部リンク検査は `main` へのpushと明示的な公開実行で行います。公開対象は保存済みの結果・資料HTMLとJSON、一覧ページです。元録音全体、キャッシュ、共有ライブラリ、Git管理外の実験結果は含めません。比較用の短い原音・合成音声は、出典を明記して結果JSONとHTMLに同梱します。

## ローカルで確認する

```sh
uv run --locked python scripts/build_site.py
uv run --locked python -m http.server --directory _site 8000
```

ブラウザで http://localhost:8000/ を開きます。サイト生成にはPythonの標準ライブラリだけを使い、音声処理のビルドや再測定は不要です。uv環境の初回作成には依存パッケージの取得が必要です。`_site/` は公開用の一時生成物で、Git管理しません。

グループの構成と追加手順は [記録の構成](../experiments/README.md) を参照してください。Markdown文書はGitHubの読みやすい表示へリンクします。結果HTMLと参考資料HTMLはPages内で直接閲覧できます。

登録形式2の `kind: navigation-only` は、タイトル・案内作成日・比較範囲・元レポートへの入口だけを一覧に表示します。種別を省略した既存登録は従来の集計付き表示を維持します。案内では `results.json.gz`、音声、比較スキーマのダミーを作らず、統計や順位も再計算しません。

案内の `source_path` は `experiments/` 内の保存ディレクトリ、公開先 `path` は `research/` 内を指定します。保存側の `artifact-manifest.json` で列挙したHTML・JSON・gzipだけを同じ相対構造へコピーし、従来どおりSHA・byte数・重複・10 MiB未満・公開先衝突を確認します。`artifact_count` はmanifest自身も含み、案内にも `index.html` は必須です。ソース、モデル、長時間の元音声、生特徴量は追加しません。許諾確認済みの短例については末尾の原因診断の扱いを参照してください。

## 一覧の指標を広げる際の表示判断

これはAIの表示設計であり、毎回測る指標の指定やユーザー指示の追加ではありません。確定レポートの登録形式2では、5つの主品質指標を常時表示し、残る39指標を13個の用途別折畳みに配置します。横幅を抑えつつ、音響・認識・制御・表現・容量/速度・別集合まで確認できるようにしています。重複的な197軸すべてや診断値を一覧へ展開する代わりに、各見出しから当該詳細表へリンクします。

参考速度は、全120録音40話者と固定70録音24話者のそれぞれで、保存済みの解析RTF・未編集復号RTFを別々に引用する4列とします。どちらも固定原入力秒が分母です。合計RTFは一覧から外し、詳細の科学的な原記録・値・区間は保持します。全120の保存I/O条件の混在と、固定70の事後補助解析という位置づけを併記し、別計時の再実行や新しい順位計算は行いません。

各列は保存された主群または条件付き群を明示し、比較方式と録音・話者・対/三つ組の数を元データへ照合します。主群という名前だけで全8方式・120録音を仮定しません。別集合や異なる分母を合算せず、元ASV105/VCTK126の未完も残します。表示の集計保存日時と、過去値引用を含む測定時点を区別します。

順位は元の整数をそのまま表示します。同順位と順位の飛びを維持し、表示値の丸めから並べ直しません。上位3位は順位の文字・太字・枠でも強調し、色だけに依存しません。小さい非ゼロ値は有効数字表記とし、未対応・適用外・比較不成立へ順位を付けません。過去の記録に順位が保存されていない場合は新しい順位を計算せず値を保持します。総合順位や優越の確証として解釈しません。

一覧の試聴は同じ元録音の原音・現HNM・WORLD Harvestの先頭2秒を維持します。一覧改善によって詳細の測定値・差分・区間は変更しません。2026-10-15の別の研究用途の掲載判断により、詳細の音声欄にはGOLF-ffとSiFi-GANの4例を加え、計18例としました。既存14例の音声bytesと一覧の原音・HNM・WORLDの3試聴例は保持し、根拠と限界は[掲載判断](reviews/2026-10-15-research-audio-publication.md)と帰属HTMLに記録します。


## 1録音の原因診断（2026-10-18追加）

`transient-envelope-pathway-2026-10-18` は、既知1録音の解析依存と特徴1行の伝播を示す案内です。全方式の品質評価・採用判断ではなく、PML baseと同じ条件の出力を比較します。

この案内経路では、manifestに固定されたSVG図と、5秒以下のWAV短例も公開形式として扱います。WAVはヘッダから長さを確認し、従来のパス・SHA・byte・10MiB・重複・衝突の確認を維持します。従来の集計付き登録の形式は変更しません。

今回の音声はCC BY 4.0のLibriSpeechから同じ4.045秒の1録音を使った5コピーです（原音、PML native、PML +3半音、説明用介入2条件）。コーパス全体や長時間の元音声は公開しません。この短い録音の全区間を含む点を明記し、個別WAVとHTML参照に分けて二重埋め込みを避けます。帰属HTML・音声manifestに出典と変更内容を記録します。元のPML、生特徴NPZ、全精度測定波形は含めません。
