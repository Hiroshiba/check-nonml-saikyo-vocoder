# 独立 F0 測定器の追加校正（v2）

2026-10-11。これは測定器の適用条件と修正記録であり、ボコーダーの品質認定ではない。

## 発見した盲点

批評家による独立監査で、24 kHz / 180 Hz の WORLD 手作り表現からの合成音を旧 YIN 型測定器へ渡すと、43 frame 中 17 frame が約 90 Hz、10 frame が未検出となった。出力の調波格子は 180 Hz である。

候補デコーダーから独立した解析的コサイン列でも再現できた。整数倍の調波を Nyquist 直下まで等振幅で加算した 180 Hz 信号は、旧測定器で 93 frame すべて未検出となる。サンプル周期が整数でないと広帯域パルスの整数 lag 差分が大きくなり、本来の周期を閾値検出できない。従来の滑らかな調波・母音様刺激 30 ケースに通っていても、この性質は保証されなかった。

de Cheveigné・Kawahara (2002) の YIN 論文も低域通過前処理の影響を議論している。ただし本実装は YIN 型の簡略測定器であり、原論文の全手順を再現したものではない。
https://www.ee.columbia.edu/~dpwe/papers/deChevK02-yin.pdf

## 修正と比較

F0 診断にだけ、固定 2 kHz・6 次 Butterworth の forward/backward filter を適用した。端点は最大 80 ms の even reflection を使う。odd reflection だと先頭にパルスがある刺激の延長が不自然になり、最初の frame に欠測が出るためである。端点 frame を採点から外す変更はしていない。再合成の STFT・帯域・RMS 指標には、このフィルタを適用しない。

前処理は候補手法、指定 F0、試験結果で切り替えない。固定された測定仕様として全出力へ適用する。`prefilter_hz=None` は旧方式の校正比較用に残しており、良い方のスコアを候補ごとに選ぶための機能ではない。

追加の校正刺激は、70.3 / 90.7 / 120 / 160 / 180 / 220 / 437.3 / 650 Hz、開始位相 0 / 0.37 cycle、16 / 24 / 48 kHz の計 48 ケース。すべて候補デコーダーを使わない解析的な広帯域パルスである。全 frame を含めた結果は次のとおり。

| 前処理 | 校正 frame 数 | 未検出 | 600 cent 超の大誤り | 各ケース P95 の最大 |
|---|---:|---:|---:|---:|
| 旧方式・無フィルタ | 4,464 | 1,302 | 372 | 1,197.978 cent |
| 1,500 Hz | 4,464 | 0 | 0 | 0.581 cent |
| 採用仕様・2,000 Hz | 4,464 | 0 | 0 | 0.556 cent |
| 3,000 Hz | 4,464 | 0 | 0 | 0.483 cent |

3,000 Hz がこの刺激上ではわずかに低い誤差を持つ。2,000 Hz を普遍的な最適値とは主張しない。今回の具体的な盲点を抑え、既存の母音様音・基本波欠落・sweep・雑音・UV 境界・無音・DC の検査を維持する固定仕様として採用した。品質スコアを最大化するために、今後も前処理を都度変更する運用にはしない。

従来 30 ケースと追加 48 ケースの計 78 ケースでは、既知有声の未検出・既知無声の誤有声化・600 cent 超の大誤りはいずれも 0、ケース別 P95 の最大は 3.117145 cent。既存の UV 混合窓は、従来どおり境界 frame として明示している。

批評家の独立再監査では、解析的 160 / 180 / 220 Hz は各 93 / 93 frame を検出し、WORLD の手作り 180 Hz も 43 / 43 frame、P95 約 0.2053 cent となった。copy・gain・delay・lowpass・crop・NaN / Inf・DC・無音の回帰も見つからなかった。

## 再現と適用範囲

- `python -m unittest discover -s work/eval_adapter -p test_metrics.py -v`: 8 テスト。
- `python work/eval_adapter/calibrate_pitch.py`: `calibration.json` を再生成。ケース別結果、未フィルタ / 3 cutoff の比較、生成器・測定器・校正スクリプトの SHA-256 を保存する。
- API は変更なし。`pitch_metrics` の結果に前処理仕様と適用範囲が加わった。
- 2 kHz 以下に周期の判断に足る成分を持つ、今回の既知刺激に対する機械的校正である。高い倍音だけに周期情報がある音、異常発声、多重周期、自然音声一般への精度保証ではない。
- これまでの測定器 v1 で得たボコーダーの F0 成績と、v2 の成績を同じ列に混ぜない。候補全体を同じ v2 で再実行する必要がある。
- 未検出、UV 境界、欠測を集計から隠して cent 誤差を改善したことにしない。
