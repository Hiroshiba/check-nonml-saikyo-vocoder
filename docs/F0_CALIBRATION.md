# 独立 F0 測定器の追加校正（v2）

2026-10-11。これは基本周波数（F0）を測る測定器の適用条件と修正記録であり、ボコーダーの品質認定ではない。以下の「フレーム」は音高を測る短い分析区間、「P95」は誤差の95パーセンタイルを表す。音高差の単位はcentで記す。

## 発見した盲点

批評家による独立監査で、24 kHz / 180 Hz の WORLD 手作り表現からの合成音を旧 YIN 型測定器へ渡すと、43フレーム中17フレームが約90 Hz、10フレームが未検出となった。出力の調波成分は180 Hz間隔に並んでいる。

候補デコーダーを使わず、数式で作ったコサイン列でも再現できた。整数倍の調波をサンプルレートの半分の周波数（Nyquist）直下まで等振幅で加算した180 Hz信号は、旧測定器で93フレームすべて未検出となる。周期が整数サンプル分の長さにならない場合、広帯域パルスを整数サンプルだけずらした波形同士の差分が大きくなり、本来の周期を閾値で検出できない。このずらす幅をlagと呼ぶ。従来の滑らかな調波音・母音様刺激30ケースに通っていても、この性質は保証されなかった。

de Cheveigné・Kawahara (2002) の YIN 論文も低域通過前処理の影響を議論している。ただし本実装は YIN 型の簡略測定器であり、原論文の全手順を再現したものではない。
https://www.ee.columbia.edu/~dpwe/papers/deChevK02-yin.pdf

## 修正と比較

F0診断にだけ、固定2 kHz・6次Butterworthの低域通過フィルタを前向き・後向きに適用した（forward/backward filter）。端点では最大80 msの波形を偶対称に反射して延長する（even reflection）。端点の値を基準に上下を反転して延長する奇対称反射（odd reflection）だと、先頭にパルスがある刺激の延長が不自然になり、最初のフレームに欠測が出るためである。端点のフレームを採点から外す変更はしていない。再合成の短時間周波数分析（STFT）、帯域エネルギー、二乗平均平方根の振幅（RMS）の指標には、このフィルタを適用しない。

前処理は候補手法、指定 F0、試験結果で切り替えない。固定された測定仕様として全出力へ適用する。`prefilter_hz=None` は旧方式の校正比較用に残しており、良い方のスコアを候補ごとに選ぶための機能ではない。

追加の校正刺激は、70.3 / 90.7 / 120 / 160 / 180 / 220 / 437.3 / 650 Hz、開始位相0 / 0.37周期（cycle）、16 / 24 / 48 kHzの計48ケース。すべて候補デコーダーを使わず数式で生成した広帯域パルスである。全フレームを含めた結果は次のとおり。

| 前処理 | 校正フレーム数 | 未検出 | 600 cent 超の大誤り | 各ケース P95 の最大 |
|---|---:|---:|---:|---:|
| 旧方式・無フィルタ | 4,464 | 1,302 | 372 | 1,197.978 cent |
| 1,500 Hz | 4,464 | 0 | 0 | 0.581 cent |
| 採用仕様・2,000 Hz | 4,464 | 0 | 0 | 0.556 cent |
| 3,000 Hz | 4,464 | 0 | 0 | 0.483 cent |

3,000 Hzがこの刺激上ではわずかに低い誤差を持つ。2,000 Hzを普遍的な最適値とは主張しない。今回の具体的な盲点を抑え、既存の母音様音、基本波欠落、音高が連続変化する音（sweep）、雑音、有声・無声（UV）の境界、無音、直流成分（DC）の検査を維持する固定仕様として採用した。品質スコアを最大化するために、今後も前処理を都度変更する運用にはしない。

従来30ケースと追加48ケースの計78ケースでは、既知有声の未検出・既知無声の誤有声化・600 cent超の大誤りはいずれも0、ケース別P95の最大は3.117145 cent。有声・無声が混在する分析窓は、従来どおり境界フレームとして明示している。

批評家の独立再監査では、数式で生成した160 / 180 / 220 Hzは各93 / 93フレームを検出し、WORLDの手作り180 Hzも43 / 43フレーム、P95は約0.2053 centとなった。原音コピー（copy）、音量変更（gain）、遅延（delay）、低域通過（lowpass）、切り詰め（crop）、非数・無限大（NaN / Inf）、DC、無音の既存検査でも、修正による悪化は見つからなかった。

## 再現と適用範囲

以下のコマンドはリポジトリのルートで実行する。

- `python -m unittest discover -s tests -p test_metrics.py -v`：8テストを実行する。
- `python -m vocoderbench.calibrate_pitch`：カレントディレクトリの`calibration.json`を再生成する。ケース別結果、フィルタなしと3種類の遮断周波数（cutoff）の比較、生成器・測定器・校正スクリプトの内容を照合するSHA-256を保存する。出力先は`--output`で指定できる。
- 初回の保存結果は [calibration.json](../experiments/2026-10-11/comparison-workbench/results/run-001/calibration.json) を参照する。
- API は変更なし。`pitch_metrics` の結果に前処理仕様と適用範囲が加わった。
- 2 kHz 以下に周期の判断に足る成分を持つ、今回の既知刺激に対する機械的校正である。高い倍音だけに周期情報がある音、異常発声、多重周期、自然音声一般への精度保証ではない。
- これまでの測定器 v1 で得たボコーダーの F0 成績と、v2 の成績を同じ列に混ぜない。候補全体を同じ v2 で再実行する必要がある。
- 未検出、有声・無声の境界、欠測を集計から隠してcent誤差を改善したことにしない。
