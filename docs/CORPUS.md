# 固定した英語120録音と日本語の補助集合

正式な比較入力は `data/clean_speech_v1.json` に固定する。英語120録音・40話者を採否の分母とし、日本語は別の `data/jvs_available_v1.json` にある取得済み12録音・4話者を補助評価する。音声は `data/cache/clean_speech_v1/` へ保存し、Gitには入れない。元録音のID、話者、言語、発声、取得位置、SHA-256、入力の測定値、先頭の切り出し範囲を記録する。完成した一覧は上書きせず、入力を変えるときは別の版にする。

## 配布元と実際に固定した構成

| 集合 | 固定した構成 | 配布元の説明と今回の限界 |
|---|---|---|
| 正式：LibriSpeech test-clean | 40話者、配布上の女性20人・男性20人。各話者から独立した3発話、計120録音・120種類の転記文 | [OpenSLR公式ページ](https://www.openslr.org/12/)の16 kHzの英語朗読音声を使う。入力検査での除外は0件。子ども、雑踏、会話、歌唱などを網羅した集合ではない |
| 補助：JVS ver.1 | 通信停止前に取得できた4話者の通常・ささやき・裏声を各1録音、計12録音 | [公式ページ](https://sites.google.com/site/shinnosuketakamichi/research-topics/jvs_corpus)は100人のプロ話者、24 kHzのスタジオ収録、発声別音声などを説明する。今回の取得済み4話者は日本語一般の代表標本ではない。性別タグと転記は保存前に取得処理が終了したため未取得と明示する |

正式集合は2026年10月11日15:38:35 UTC、方式出力・自動MOSの比較前に凍結した。120音声という数には、人工信号、別サンプルレートへの変換、乱数seed、同一録音の複数切片を含めない。元ファイルのSHA-256は120件すべて異なる。日本語12録音は正式120件へ混ぜず、別の件数と結果で報告する。

LibriSpeechの「clean」は無加工・無雑音の保証ではない。[原論文の第3節・第5節](https://www.danielpovey.com/files/2015_icassp_librispeech.pdf)は、認識誤り率による話者分割と、元音声がMP3圧縮やノイズ除去・音量正規化を経ている場合があることを説明する。今回の「清潔な入力」は、配布条件と下記の機械検査に基づく限定的な選択であり、新しい聴取評価を行ったという意味ではない。

## 比較前に変更した計画

当初は日本語60録音と英語60録音を予定し、各言語20話者から選ぶ方針だった。日本語は各話者の通常・ささやき・裏声を1録音ずつ選ぶ予定で、JVSの公式公開ZIPから12件を取得した。しかし同日15:30:23 UTC以降、環境の通信許可が停止し、取得が403で失敗した。失敗はスタックトレース付きログに記録されている。未取得48件を品質による除外や評価済みとは扱わない。

方式出力やMOSを見る前に、取得済みの公式LibriSpeech test-cleanアーカイブから40話者×3発話の120録音を正式集合とする計画へ変更した。通信制約を迂回せず、入力規則と抽出区間は維持した。JVSの取得済み12件はすべて補助集合へ残した。JVSの性別・転記は終了した処理のメモリー上にだけあり、復元を推測で埋めず未取得としている。日本語60件の予定を実施できたとは主張しない。

継続時には、取得済みアーカイブや原音を再利用し、集合変更は出力を見る前に理由を明記して固定する。取得完了と評価完了を区別し、比較を待たせる通信障害が起きた場合も、手元にある適法な入力で成立する比較を先に進める。

## 選び方と入力確認

配布メタデータの性別ごとに、固定文字列を付けたSHA-256順で20人ずつ選ぶ。今回のtest-cleanでは全40話者になる。話者内の発話は、話者IDと音声の配布パスを含むSHA-256順に調べ、最初の適合3録音を採る。全話者で同じ文だけを選ぶ規則にはしない。転記文の種類数は録音数と別に報告する。

以下の規則は出力音声や自動MOSを計測する前に決めた。

- 整数PCMのモノラルであり、値が有限である。
- 元録音が1秒以上ある。
- 元録音も使用する先頭最大6秒も全無音ではない。低音量だけを理由に除外しない。
- 元録音と使用区間のどちらも、フルスケール直近（絶対振幅が `1 − 1/32768` 以上）の標本が0.1%を超えない。これはクリッピングの簡単な疑い検出であり、すべての歪みを見つけるものではない。

除外理由と入力値を `excluded_before_freeze` に保存する。取得に失敗した録音を別の録音へ黙って入れ替えず、ログへスタックトレースを残して取得処理を失敗させる。凍結後に取得できなくなった音声や、手法が失敗する音声も比較対象から除外しない。

各録音の比較区間は先頭から最大6秒とする。無音除去、音量正規化、動的な位置合わせ、方式別の区間選び直しは行わない。完全な発話より短い区間になる場合があるため、元発話の長さと使用標本数を区別する。単純平均をあらゆる言語や発声の品質と呼ばない。

自動MOSが高い入力を選ぶことはしない。凍結後は原音にもMOSを測り、正式集合は全体・配布上の男女別に報告する。補助集合の日本語、ささやき、裏声などは評価器の未検証領域として分ける。既存評定が元録音に付いていても、ボコーダー出力へその評定を転用しない。

## 取得と再現

LibriSpeech test-cleanは公式のtar.gzを取得した。実際のサイズは346,663,984 bytes、SHA-256は `39fde525e59672dc6d1551919b1478f724438a95aa55f874b576be21967e6c23`。これらを固定一覧にも保存する。FLACから整数PCM WAVへの変換だけを行い、サンプルレートやチャンネル数を変更する引数は渡さない。原FLACとWAVのSHA-256、および復号PCMのSHA-256を記録する。

```bash
uv run python -m vocoderbench.corpus fetch
uv run python -m vocoderbench.corpus prepare --offline --manifest data/new_version.json
```

`fetch` は凍結一覧の録音だけを再取得し、保存済み音声も照合する。`prepare` は初回の選定・入力検査・一覧凍結を行い、既存一覧は上書きしない。`--offline` は取得済みアーカイブだけを使う。新しい版を作る必要がない限り `prepare` は使わない。比較器は `corpus.load_cases()` から同一の入力配列を受け取る。補助集合には `corpus.load_cases('data/jvs_available_v1.json')` を使う。

復号後の整数PCMのSHA-256、サンプルレート、標本数、モノラルという条件を入力音声の一致判定に使う。FFmpegの版によってWAVのヘッダーだけが変わる場合は、PCMが一致することを確認してワーニングと実際のWAVハッシュを残す。元FLACや元WAVがキャッシュにある場合は、配布元ファイルのSHA-256も一致を要求する。

JVS公式ZIPは3,536,595,425 bytes。通信停止前にHTTP 206の部分取得を確認し、5,457,496 bytesの索引と42,372エントリーの構成を調べた。全3.5 GBを保存せず、必要な範囲だけを取得した。補助集合には各音声のZIP内位置、圧縮サイズ、CRC、展開後SHA-256を残した。取得済み12件は元ZIP索引のCRCと長さにも一致した。通信停止後の再試行は行っていない。

## 音声公開と利用条件

JVS公式条件は、研究や個人利用を認める一方で原音の再配布を原則認めず、ウェブページなどで約10音声を公開する例外を説明している。継続するレポートで加工例が増えることを考慮し、今回はJVSの原音・加工音とも公開しない。取得済み日本語12録音の数値と入力条件のみ公開する。将来タグを取得する場合はCC BY-SA 4.0、転記を取得する場合はJSUT由来の条件を確認し、音声条件と混同しない。

LibriSpeechはCC BY 4.0であり、出典、版、変更内容を示して音声例を公開する。公開音声例は固定一覧のID順で英語2話者を選び、各話者の最初の1録音を使う。`public_audio_example_ids` は `librispeech_1089-134686-0008` と `librispeech_1188-133604-0003`。結果を見て選び直さない。音声全体やキャッシュはGitへ追加しない。

## レビューで修正した点

批評担当との往復で、話者IDを発話選定順へ含めること、転記文種類数を独立録音数と分けること、低音量のささやきを不潔として除外しないこと、MOSを理由に日本語を外さないことを確認した。通信停止による計画改訂は、出力を見ず120録音・40話者を維持し、補助集合と未取得を分離する条件で再検討し同意を得た。また、WAVのヘッダー差を音声の不一致と誤認しないよう復号PCMの一致確認を追加した。自動MOSの得意な入力へ選定を合わせる方法は採らない。
