# 追加指標の測定仕様

この文書はAIが作成した測定仕様であり、ユーザー指示より優先しない。実装は `vocoderbench/extended_metrics.py` と `vocoderbench/temporal_metrics.py`。100音声以上の固定入力を測る前に、下記の条件を固定する。

## 何を分けて測るか

| 目的 | 指標 | 解釈上の限界 |
|---|---|---|
| 言葉の分かりやすさ | eSTOI | 清潔な参照が必要。自然性、声の魅力、話者の似方、MOSではない |
| 音量と振幅 | RMS、ピーク、波形平均、クレストファクター、参照とのRMS差 | 録音の音量差も含む。知覚ラウドネスの規格測定ではない |
| 振幅上限 | 絶対振幅1以上の割合・最長連続サンプル数、0.999以上の割合 | 振幅尺度に対する超過。録音時にクリッピングした証拠とは限らない |
| 静かな区間の保全 | 参照低エネルギー区間の出力RMS・ピーク・エネルギー割合 | 参照から機械的に選んだ区間であり、人が付けた無音・無声の正解ではない |
| 音高の整合性 | 独立YINによる入出力F0差と有声判定の不一致 | 自然音声の絶対F0真値はない。双方に同じ測定誤りが出る可能性がある |
| 時間変化 | 帯域別10/40 ms RMS包絡の差・相関 | 雑音を生成し直した場合は正しくても差が残る。100 Hz以上の周期内形状は測らない |
| 変動の速さ | RMS包絡の2–8、8–20、20–50 Hz変調パワー | 位相一致は測らない。窓の平滑化や発話長に依存し、知覚尺度として校正していない |
| 既知の過渡 | エネルギー分位時刻、90%幅、既知時刻±5 ms外の比、総エネルギー比 | 単一人工イベントの診断。自然子音の境界時刻推定ではない |

これらは従来のMR-STFT・帯域エネルギー等を補う診断である。相関する指標を多数並べても独立した証拠が増えるとは考えず、多数決や加重総合点で採否を決めない。MOS予測は別の評価器・別の適用範囲として扱う。

## 共通条件とAPI

`measure_extended(reference, output, sample_rate, include_pitch=True, include_temporal=True, is_speech=True)` は、同一時刻・同一長のモノラル波形を受け取り、JSONへ保存できる辞書を返す。無加工の再合成が対象であり、意図して音高・時間・声質を変えた出力に原音との類似度をそのまま適用しない。

自動整列、音量正規化、無音切除は共通前処理で行わない。eSTOIだけは公式方式内の再標本化・無音除去・正規化を使用し、他の指標の波形へ流用しない。非有限値・長さ不一致・空入力は、その理由を結果とログに残す。指標単位の例外はスタックトレースをログへ流し、失敗の行を残す。

## eSTOI

`pystoi==0.4.1` の `stoi(..., extended=True)` を使う。提供元は清潔音声と劣化音声の関係から明瞭性を推定する実装として説明している。[公式リポジトリ](https://github.com/mpariente/pystoi)

公式実装は内部で10 kHzへ再標本化し、参照の最大フレームエネルギーから40 dBより低いフレームを除去する。256サンプル窓のSTFT後、30フレーム未満なら警告と代替値 `1e-5` を返す。本実装ではこの値を採点せず、`insufficient_active_frames` と `value: null`、公式の生値、警告を保存する。警告はログにも記録する。[実装本体](https://github.com/mpariente/pystoi/blob/master/pystoi/stoi.py)

行・列正規化で機械epsilon規模の乱数が使われるため、評価器のseedを0に固定する。合成器のseedとは別である。呼出しの前後でNumPy旧乱数状態を保存・復元し、同じ実装内の呼出しをロックする。並列測定にはプロセス単位の独立実行を推奨する。[正規化実装](https://github.com/mpariente/pystoi/blob/master/pystoi/utils.py)

人工信号は `not_speech`、参照の定数・無音は `reference_no_ac_energy`、出力の定数・無音は `output_no_ac_energy` として `null` を残す。無音化した出力を、単なるダウンロード失敗や無効資料と混同しない。これらを平均から除く場合も、全入力数を分母とした件数を必ず表示する。有限な通常値は勝手に0–1へ切り詰めない。

論文の位置づけは、変調する雑音に遮られた音声の明瞭性予測である。今回の日本語・英語やささやき・裏声について、方式が知覚評定と対応することを改めて実証したわけではない。高品質ボコーダーの自然性保証や聴取実験の代替完了とは表示しない。

## レベル・低エネルギー区間・F0

RMSとピークは元の振幅尺度で測る。完全なゼロのdB値は負の無限大をJSONへ流さず `null` とし、`zero_energy` で区別する。クリップ候補の割合は入力と出力の両方を残す。

低エネルギー区間は、参照を重なりのない10 msブロックに分け、電力が `max(1e-6, 最大参照ブロック電力×1e-4)` 以下となるブロックとする。これは `max(-60 dBFS, 最大参照ブロックより40 dB下)` に相当する。対象ブロック数・サンプル数・未評価の末尾長、出力の電力・ピーク、その区間のエネルギーが出力全体に占める割合を保存する。対象がない場合と、対象内の出力が完全なゼロの場合を分ける。

F0は既存の80 ms窓・10 ms間隔・65–700 HzのYIN測定を使い、固定2 kHzの前処理と適用限界を引き継ぐ。両方が有声と推定されたフレームだけでcent差を出すため、参照側有声数、出力側有声数、両有声数、片方だけ有声の数を隣に表示する。これは自然音声の真値誤差ではなく推定整合性であり、人工刺激の既知F0評価と混ぜない。[既存の校正](F0_CALIBRATION.md)

## 時間包絡と変調

全帯域と300–1000、1000–3000、3000–6000 Hzで測る。帯域は4次Butterworthの前向き・後向き処理、偶対称の端点延長で取り出す。Nyquistに入らない帯域は適用外として残す。10/40 msの矩形窓・5 ms間隔で、入力に完全に収まる窓だけの二乗平均を求める。対数差のRMS床は `max(1e-7, 参照包絡の最大RMS×1e-3)` とし、出力を基準に変えない。

包絡の変動パワーは、1秒以上あるRMS包絡に平均除去とHann窓を適用し、SciPyの片側 `periodogram(..., scaling='density')` を周波数刻みで積分する。2–8、8–20、20–50 Hzは下端を含み上端を含まない。参照の総変動電力の `1e-6` または `1e-20` の大きい方を床とし、帯域別電力、dB差、参照有効帯域数を保存する。1秒未満は値を推定で埋めず不足として扱う。音量補正をしないため、純粋な形の変化と音量変化をレベル欄と併読する。[SciPyの定義](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.periodogram.html)

既知AM刺激には変調周波数と振幅包絡を別途渡せる。振幅変調を二乗すると2倍周波数も生じるため、パワー包絡をDC・基本・2倍周波数のsin/cosへ同時回帰する。有限長雑音の実現包絡との差と、同じ窓処理をした既知振幅二乗モデルとの差を分ける。モデルは相対変調の参照であり、帯域処理後の絶対電力を保証しない。時間倍率が `s` なら、変調周波数は元の `1/s`、既知イベント時刻は元の `s` 倍へ変換して測る。

## 過渡・反復・集約

インパルスの5/50/95%エネルギー時刻と90%幅、既知時刻±5 msより外側の前後エネルギーを測る。この欄は帯域フィルタ前の波形を使い、フィルタ由来のにじみを混ぜない。外側比の分母は各波形自身の総エネルギーである。イベントを弱くしただけで改善に見えないよう、出力対参照の総エネルギー比を併記する。完全無出力の分位時刻と比は未定義のまま残す。

乱数の影響は固定した各入力で8 seedを反復し、各値・平均・標準偏差・範囲を保存する。位相の集約は循環平均を使う。この反復を8発話・8話者と扱わない。WORLDの固定乱数出力を8回複製して8 seedと表示しない。

100音声以上の集約では発話・話者を単位にし、日本語・英語、発声様式を分け、各指標の有効数と欠測理由を表示する。フレームを独立話者として信頼区間を狭めない。既知刺激による校正記録は測定結果であり、テストコード・自動合否判定は作らない。
