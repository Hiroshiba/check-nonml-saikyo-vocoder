# 日本語12録音の補助評価手順

この文書は正式120録音比較を親とする補助研究の手順を記録する。`vocoderbench.supplement` に明示的な実行入口を実装し、2026年10月12日01:46:32〜01:48:46 JSTに、204合成・48予測MOSを全て測定した。結果は [補助研究の記録](../experiments/2026-10-12/jvs-supplement/README.md) に保存する。計画上の件数を測定済みの件数と混同しない。

正式比較は [固定した英語120録音](../data/clean_speech_v1.json)・40話者で行う。日本語12録音はその件数・集計・採否分母へ加えず、正式比較の採否閾値も変更しない。利用条件と選定経緯は [固定コーパスの説明](CORPUS.md)を参照する。

## 入力と確認できる範囲

入力は [jvs_available_v1.json](../data/jvs_available_v1.json) に固定済み。SHA-256 は `1ff7a449b5f44580d6b48c187209c9786522880a7630ebfacf081660b2df4520`、凍結日時は2026年10月11日15:38:34 UTCである。

| 項目 | 固定した内容 |
|---|---|
| 話者 | jvs004、jvs018、jvs066、jvs082の4話者 |
| 発声 | 通常・ささやき・裏声を各話者1録音ずつ、各4件、計12件 |
| 音声 | 24 kHz、整数PCM、モノラル。元音声の先頭から最大6秒 |
| 入力操作 | 無音除去・音量正規化・方式別の切出し変更を行わない |
| 不明な情報 | 性別タグ・転記は未取得。推測で補完しない |
| 取得できなかった音声 | 当初予定60件のうち48件。通信停止による未取得であり、品質による除外ではない |
| 公開音声 | 0件。原音・加工音とも公開しない |

12件は通信停止前に取得できた全録音であり、出力やMOSを見て選んだ集合ではない。ただし、取得できた4話者という範囲に偏るため、日本語一般や各発声様式全体の品質を保証しない。同じ話者でも発声間の文が同一とは限らず、発声間の差を発声様式だけの因果効果と解釈しない。

## 実行する順番と入口

1. 正式120件の比較を完了させ、結果・条件・実行状況を保存する。正式比較の実行中にコードや共有測定条件を変更しない。
2. 方式の採否・実装切替の前に、正式比較と同じベース・候補・WORLD（Harvest）を補助評価できる状態で固定する。既に実装が切り替わっている場合は同じ比較の続きとせず、実際に利用する版を明記した別研究として計画し直す。
3. 完成済みの正式比較を親として必ず確認する、明示的な補助研究の実行入口を実装する。正式比較の「100録音以上」という検査は維持する。12件だけを通常の比較として実行するために閾値を下げたり、低階層の関数呼出しで検査を回避したりしない。
4. 補助条件をJSONと説明文へ保存してから計算する。正式結果とは別の出力先を使い、再開時も同じ入力・方式・測定条件であることを照合する。
5. 入力は `corpus.load_cases('data/jvs_available_v1.json')` から読み、取得済みキャッシュのみを使う。欠落やハッシュ不一致を別の録音で埋めず、失敗と理由を記録する。追加通信は行わない。
6. 数値結果と日本語HTMLを保存し、正式比較から補助結果へリンクする。正式集計や採否判定に12件を混ぜず、次の改善課題と適用範囲の判断材料として扱う。

入口では、親の正式manifestが120件・40話者の固定集合であること、親の条件ファイルがそのmanifestのSHAを参照すること、親結果の予定・完了・失敗件数を確認する。未完了の親比較を完了扱いせず、失敗を含めて確定した結果と計算待ちを区別する。親結果・親条件のSHAと参照先を補助条件へ残す。

共有する合成器・測定器・依存関係の版が親条件と一致することも確認する。補助研究用に追加した入口や集計処理の版は別途記録し、親条件ファイルを後から書き換えない。入力・方式・測定条件が変わった場合は、既存出力への継ぎ足しを拒否して別研究にする。

## 計算前に固定する情報

- 補助manifestのID・SHA、12入力のID、元ファイルと復号PCMのSHA、サンプルレート、固定切出し範囲。
- 親となる正式比較の結果・条件への参照とSHA、当時のベース、比較する3方式の実装・WORLDバイナリー・依存関係の版。
- HNMと候補の雑音seed `0〜7`、WORLDの1回合成、波形の位置合わせ・音量正規化を行わない条件。
- UTMOSv2のコード・重み・設定のSHA、合成seed `0`、抽出seed `20261012`、1反復。原音も同条件で測定する。
- 測定項目、予定件数、失敗・欠測の記録方法、発声別集計、公開音声0件という条件。

予定は3方式×12件の再合成36行と原音12行。HNMと候補の8seed、WORLDの1回を含む再合成診断は合計204回、自動MOSは原音を含め48値である。予定数を成功数として先に記録せず、開始前は未実施の状態を保存する。

MOSは既に取得済みの重み・設定だけを使い、欠けている場合は追加取得せず未測定理由を残す。MOS内部の16 kHz変換、eSTOI内部の10 kHz変換と無音処理などは評価器の前処理として記録し、24 kHzの符号化・合成入力を変更したことと混同しない。

## 発声別の集計と解釈

現在の正式比較集計は英語通常発声・男女別の表示に合わせているため、そのまま補助結果の表示へ流用しない。補助では「通常4件」「ささやき4件」「裏声4件」と全12件を表示する。方式比較は同じ録音の出力間で対応を取り、原音との差とベースとの差を別に残す。

各指標は予定数・有効数・失敗数・評価不能の理由を併記する。個々の12録音の結果と方式差を読めるようにし、4話者という小標本で強い一般化をしない。反復seedや音声フレームを独立話者として数えない。区間推定を載せる場合も話者単位で扱い、4話者に限定した不確かさであることを示す。

- スペクトル・帯域・レベル・時間包絡・変調・振幅上限などの音響測定、eSTOI、固定MOSを別々に報告し、総合点に潰さない。
- 自然音声のF0真値はない。F0は独立測定器による入出力推定の整合性として報告する。ささやきなどで参照有声推定が0件なら、分母0を0点や成功へ変換せず評価不能とする。
- 自動MOSは日本語・ささやき・裏声に対する未校正の探索的予測である。原音の予測値も示し、低い予測値だけでその発声を劣化と決めない。
- 性別が不明なので男女別集計は行わない。転記がないためCER/WERは計測しない。

補助結果で破綻が見つかった場合は、その入力・発声での制限と次の改善課題を残す。結果を見た後で入力を除いたり、正式120件の採否閾値を調整したりしない。

## 保存物と公開範囲

補助研究のグループ内に、事前条件、説明、数値JSON、レビュー、結果HTML、実行状況を保存する。HTMLの冒頭ではベース・候補・WORLD（Harvest）の比較を示し、その直後に「日本語12録音の補助診断・正式120件と別集計」と明記する。全JVS音声は非公開とし、音声を含むキャッシュや配列をGitへ追加しない。音声例を確認する導線には、親の正式比較で公開済みの英語例へのリンクを使い、日本語の音声例と誤認させない。

JVSの利用条件は、研究・個人利用を認める一方で原音の再配布を原則認めず、少数のウェブ音声例に例外を設けている。継続する実験で加工例が増えることも踏まえ、本プロジェクトでは今回のJVS原音・加工音を公開しない方針とした。元の条件の確認範囲と出典は [CORPUS.md](CORPUS.md)に記録済みで、この手順の作成時に追加通信による再確認は行っていない。

## 初回実行で確認した結果

12録音の全体では候補の包絡誤差が3.74%減少し、予測MOSは平均+0.0244だった。ささやき4録音ではeSTOIが約0.00304低下し、すべての発声で改善したとは扱わない。振幅1以上の出力は全方式0。音高差はささやきの一部で評価不能だった。詳細は [数値・HTML](../experiments/2026-10-12/jvs-supplement/results/run-001/index.html) と [結果の解釈](../experiments/2026-10-12/jvs-supplement/reviews/results.md) を参照する。

## ベース更新後の扱い

初回補助はHNM v1と当時の候補で測定した。現在のv2へ更新されたcheckoutから同じ初回研究を再開しようとすると、共有ソースの不一致として拒否する。再表示には保存済み結果と `supplement_report.render` を使う。科学条件を変える次の補助研究は、対応する新しい正式比較を親にして別の条件・出力先を固定する。初回を最新ベースの測定へ読み替えない。

今回のv2採用は、元の正式比較に対する事後の判断見直しとして[別文書](../experiments/2026-10-12/jvs-supplement/reviews/adoption.md)に残した。補助の12件を使って正式120件の平均や元の条件を上書きしていない。
